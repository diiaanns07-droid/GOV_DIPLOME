**E6b (новый прогон K09, тот же метод, n = 300 на уровень, seeds 101/102/103, 513.9 с).** Файл `repro/E6b_n300_seeds101-103.json` содержит сырые выборки.

| σ = a | Номинальный топ-1 остаётся топ-1: n = 60 (ДИ Уилсона 95 %) | То же, n = 300 (ДИ Уилсона 95 %) | В топ-10: n = 60 → n = 300 | Регрет, медиана / p95: n = 60 → n = 300 | Разных топ-1: n = 60 → n = 300 |
|---|---|---|---|---|---|

Во всех шести прогонах самым частым победителем остаётся номинальный план.

**Вывод (derived, о учебной модели).**
- Для доли «остаётся топ-1» точечные оценки n = 300 лежат внутри ДИ n = 60 при всех σ. Для доли «в топ-10» при σ = a = 0.3 — нет: 0.533 вне ДИ n = 60 (0.541–0.773).
- Вывод «номинальный топ-1 хрупок при допущенных диапазонах» воспроизводится на независимых seeds.
- Медианный регрет мал: от 0.01 до 0.17 единиц Score.

**Методическая находка.**
- Число «разных топ-1» растёт с n: при σ = 0.3 оно 23 при n = 60 и 59 при n = 300. Это свойство размера выборки, а не модели.
- Утверждение AST-A13 «16 разных победителей на 60 прогонов» нельзя использовать как характеристику устойчивости.
- Для Т2 нужны метрики, не зависящие от n: доля побед и её ДИ, энтропия распределения победителей, регрет.

**Ограничения.**
- Диапазоны возмущений не откалиброваны. Веса и эффекты возмущаются одновременно, вклад каждого не разделён; для этого нужны индексы Соболя.
- Отложенной проверки нет: это описательная статистика, а не сравнение правил выбора. Сравнение правил — задача Т2.

## 4. AST-A13-E5 и K09-E8: числительные и топонимы на казахском

**E5 (фильтр чисел советника).**
- `run_pilots.py E5`: stdout **побайтно равен** `kk_numeral_filter_result.json`.
- kk: 4 утечки из 6 числовых предложений («бес», «он екі», «үш», «жартысын»).
- ru: 1 из 4 («десятки процентов»). Ложных удалений нет.

Как фильтр работает (`agent/evidence.py`, `qualitative_comment`): предложение удаляется, если в нём есть цифра, `{{`/`}}`, слово из русско-английского списка `_NUMERAL_FORMS` или (при `saray_shyk_modeled=False`) упоминание Сарайшыка. Казахских форм в списке нет. Тест измеряет именно это. 12 фраз синтетические, поэтому долю утечек на реальных ответах он **не оценивает**.

**K09-E8 (новое): распознаёт ли словарь районов парсера A13-E4 русские и казахские названия районов Астаны.**
- Входы:
  - названия из `data/astana_districts.geojson` → `osm_names` (OSM, ODbL, `osm_base_timestamp` 2026-09-22) — **observed**;
  - словарь `DIST` извлечён из `constraints_eval.py` через `ast`, код A13 не исполнялся;
  - правило совпадения то же: `stem in text.lower()`.
- Команда: `python3 research/next-round/K09/scripts/e8_toponym_stems.py`, выход в `repro/E8_toponym_stems.json`.

| Поле OSM | Районов в словаре | Распознано правильно |
|---|---|---|
| `name:ru` («район Есиль» …) | 5 | **4**. «район Байконур» даёт `baikonur` и `nura` |

## 6. Следствия для тем

1. **Т1.**
   - Харнесс E4 годится как основа, но требует метрики регрета и класса «невыполнимые».
   - Нужен **усиленный baseline B2**: E8 показывает, что B1 не видит kk-орфографию.
   - Набор поручений должны писать не авторы парсера.
2. **Т2.**
   - Доля «остаётся топ-1» устойчива к seed и объёму выборки; доля «в топ-10» при σ = 0.3 — нет (0.667 → 0.533).
   - Для отчёта нужен n ≥ 300 на уровень: ДИ ±5–6 п.п.
   - Число «разных победителей» как метрику не использовать.
   - Нужна отложенная проверка правил выбора.
3. **Резервная Т4 (объяснения).** E5 — воспроизводимый регрессионный тест. Решение — казахский словарь числительных или проверка «число ↔ поле evidence».
