## 2. Сценарий

- **Пользователь.** Специалист по энергосбережению (энергоменеджер) управления образования либо
  управления энергетики и ЖКХ акимата Шымкента. Он готовит список школ для энергоаудита на
  следующий бюджетный год. Роль — **гипотеза** (A09-Q002). Существование такой должности и
  отдела не проверено: gov.kz закрыт.
- **Задача сайта.** Ответить «какие N школ обследовать первыми и почему». Пользователь загружает
  таблицу по шаблону. Сайт:
  1. делает проверки качества;
  2. ранжирует школы по EUI внутри группы однотипных объектов;
  3. показывает вероятность попасть в топ-N с учётом неточной площади;
  4. объясняет позицию каждой школы текстом, который формирует код;
  5. выгружает CSV.
- **Чего сайт не делает.** Не оценивает экономию, причинный эффект модернизации и деньги
  (тарифы не проверены). Это отдельные задачи (A09 §5).

## 3. Реальные входы

| Вход | Ожидаемый источник для Шымкента | Статус | Поле в примере BDG1 |
|---|---|---|---|
| Потребление электроэнергии по зданию, ≥12 месяцев, факт или норматив | энергоснабжающая организация, бухгалтерия школ | **не проверено**, данные оператора (A09-D004) | часовые kWh → суммы по месяцам |
| Покрытие учёта: часы или месяцы с показаниями | счётчик или ведомость | неизвестно | `hours_observed / hours_expected` |
| Площадь и её источник (техпаспорт / OSM × этажи) | балансодержатель, управление образования | неизвестно | `sqm`; источник площади в BDG1 не описан |
| Тип объекта | реестр организаций образования (A09-D005) | недоступен в среде | `subindustry` |
| Тип отопления | паспорт здания | неизвестно | `heatingtype` (72 из 74 британских — газ) |
| Учебный календарь РК | Минпросвещения (adilet.zan.kz, gov.kz) | **заблокировано** (K12-S006, S007) | для годового EUI по полным 12 месяцам не нужен |

Для Астаны вход тот же. AST-A09 сообщает, что в снимке каталога data.egov.kz за февраль 2026
наборов потребления зданий нет (по отчёту, не перепроверено). Там основная нагрузка — тепло, поэтому
электрический EUI покрывает меньшую часть затрат.

## 5. Baseline: рейтинг по EUI

**Определение.** EUI = годовое потребление электроэнергии, кВт·ч / площадь, м². В топ-N попадают
20% зданий с наибольшим EUI. Это «честный конкурент без AI» из A09 §7.

**Пример.** 74 британские школы с одним погодным файлом и одним периодом. Это аналог «школьной
сети одного города», N = 15. Файлы: `data/K12_bdg1_schools_monthly.csv` (здание × месяц),
`data/K12_bdg1_schools_meta.csv`, `data/K12_bdg1_schools_qc.csv`. Код:
`scripts/k12_eui_baseline.py`. Результаты: `results/K12_baseline_results.json` и
`results/K12_uk_schools_eui_ranking.csv`. Все числа ниже — **derived**.

|---|---|
| C1. Покрытие часов | медиана 0,954; у 27 из 74 ниже 0,95; у 62 из 74 есть месяц с покрытием < 80% |
| C1. Где пропуски | доля пропусков в будни 09–15 — медиана 0,31 при ожидаемых 0,21 (×1,48); у 37 из 74 ≥ ×1,5. У 31 не-британского здания ×2,4 |

## 6. Правила для сайта, которые следуют из проверки

1. Показывать «вероятность попасть в топ-N» и три зоны: уверенно / граница / вне. Одно место в
   рейтинге — только вместе с ними.
2. Поле `area_source` обязательно. Без техпаспорта ставится метка «низкое доверие».
3. Годовой итог считать с подстановкой пропусков по профилю или по месяцам. Если пропусков в
   учебные часы ≥ ×1,5 от ожидаемого, ставить флаг. Равномерная экстраполяция систематически
   занижает потребление.
4. EUI ниже P10 своей группы — флаг «проверить, какую часть здания покрывает счётчик»,
   а не «образцовая школа».
5. Электрический EUI не описывает тепло. Ресурсы ранжируются раздельно; при электроотоплении
   сравнение с другими школами некорректно.

## 7. Ограничения

- Данные иностранные: Великобритания, 2014/15, газовое отопление. Ни одно число не является
  оценкой Шымкента или Астаны. Казахстанские данные в этой работе **не использовались**.
- Модель ошибки площади (лог-нормальная, σ_log = 0,1–0,5) — допущение. Реальное распределение
  ошибок площади школ Шымкента неизвестно.
- Профиль подстановки пропусков не учитывает каникулы и праздники внутри месяца.
- Почему пропуски сгущаются днём (сбой связи, фильтрация выбросов в BDG1 или что-то иное),
  не установлено. Это **гипотеза**.
- Не проверено: календарные выводы A09 (E1b, M3 «16% → 6,8%»), ночное правило (E2), BDG2,
  единицы по статье, сама статья.
- Роль пользователя и наличие у оператора выгрузки по школам — гипотезы.
- Сеть: `adilet.zan.kz:443` и `www.gov.kz:443` отклонены прокси (CONNECT 403, policy denial),
  2026-10-05 05:22 UTC. Повторных попыток не было. Это ограничение среды, а не доказательство,
  что источников нет.

## 9. Следующий конкретный шаг

Получить от владельца проекта или оператора обезличенную выгрузку по 10–20 школам Шымкента:
12 месяцев счетов за электроэнергию с типом показания (факт или норматив) и площадь с указанием
