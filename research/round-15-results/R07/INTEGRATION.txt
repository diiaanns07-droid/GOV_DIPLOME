1.1 Маршрут GET /api/civic/v2/heat/replay — у R01 УЖЕ есть ("heat.replay", V2Handler R07 ui.civic_heat.api.handle_get,
    kind="raw"). Модуль сам проверяет и параметры, которых нет в правилах шлюза: last (1…92), days (окно карты 1…365),
    format (compact | full). Можно дописать в query правила: "last": "days", "days": "days", "format": "word".
    Ответ: {generated_at, params{from,to,step,days,category,district,format}, legend, targets{"kind:id": {target,
    geometry, anchor, district, approximate, cat}}, frames[{date, at, totals{people, active, hot, fixed, verified,
    reopened, districts_active}, items | changed+removed, districts | districts_changed+districts_removed}],
    events[{id, kind, title_ru, title_kk, district, district_ru, district_kk, start, end, started_at, ended_at,
    status, source world|incident|scene, incident, scene, demo}], demo, district_zoom_max, compute_ms}.
    Ошибка параметра — 400 {error: bad_request, field}. Сбой — 500 без падения сервера.

1.3 Где открывается (место — схема R11 IA_ROUND15; по умолчанию — кнопка у кнопок карты). Один вызов после монтажа R07:
      window.BirgeReplay.attach({ map: currentMap(), heat: S.mounted.heat, tools: document.querySelector(".map-tools") });
    attach: кнопка 44 px «Хроника города · Неделя за 10 секунд» в колонке кнопок карты (класс .rp-open; при открытой
    хронике тёмная), адрес ?replay=7|30 (&autoplay=0) — открыть сразу (сцена 9, ролик R10), событие
    document.dispatchEvent(new CustomEvent("birge:replay-open", {detail: {days: 7}})).
    Ctrl+K: heat.commands() уже отдаёт «Хроника города: неделя за 10 секунд» и «… месяц» (id heat:replay:7 / :30).
    Программно: BirgeReplay.open({ map, heat, days: 7, autoplay: true, container? }) → ручка {play, pause, seek,
    setPeriod, setLang, close, destroy, state(), stats()}; BirgeReplay.active — открытая хроника.

1.4 Полоса хроники — внизу карты, по центру свободной части. Оболочка задаёт отступы от своих панелей на .rp-host
    (контейнер open() — карта, или opts.container):
      .rp-host { --rp-left: 408px; }   /* открыта карточка слева 388 + поля 20 */
    Пока хроника открыта, у body класс birge-replay-open. Предлагаемый CSS оболочки (R01 решает):
      body.birge-replay-open #birge-legend { display: none; }            /* легенда-строка под полосой */
      @media (max-width: 760px) { body.birge-replay-open #civic-panel { transform: translateY(calc(100% - 64px)); } }
    Значки карты сами обходят полосу (heat.js учитывает .rp-bar в раскладке).

1.5 Демо-мир (CONTRACT §11): R01 уже зовёт ui.civic_heat.world.seed_world(db_path, world, now) — R07 берёт из мира
    только отметки шкалы: events (§2.1) + incidents (§2.8, связь event) + scenes; хранит в своей таблице
    heat_replay_marks_v1 той же базы (идемпотентно, время первого засева не сдвигается). Жалобы R07 не сеет: карта

    Необязательно: heat.configure(source=…, metoo_times=…, db_path=self.db_path) — тогда отметки ищутся в базе
    шлюза и без seed_world (без него — путь из seed_world, CIVIC_DB_PATH или .runtime/civic.sqlite3).

2. R09 — время «Я тоже» из мира (патч patches/R09_world_seed_metoo_times.patch)
================================================================================================================
ui/civic_feedback/v2/world_seed.py читает «Я тоже» из metoo_ago, а мир R02 (SCHEMA §2.3) пишет metoo_times
(после materialize — ISO-строки). Сейчас время каждого «Я тоже» раскладывается равномерно «от подачи до сейчас» —
и карта, «Картина дня», хроника расходятся с EXPECTED.json R02 (Нура за 7 дней: 79 человек / 39 мест вместо 74 / 35).
Патч берёт metoo_times (ISO или {"ago_hours"}), прежний metoo_ago тоже. Проверено во временной сборке
(R02 08bb57a1 + R09 eed6393f + R17 72676e3d + R07): с патчем R09 и окном R07 (п. 4) числа районов карты за 7 / 14 /
30 дней = EXPECTED.json R02 во всех 6 районах (0 расхождений), без патча — 9 районов расходятся.

3. R17 — отметки кризисов
================================================================================================================
Хроника читает ui.civic_agencies.incident_marks(start, end) (запасной путь — list_incidents(status="all"), затем
make_service(db).handle GET incidents). Кризис о событии мира (тот же район и время, вид «буран / снег») — ссылка
отметки события («Буран в Нуре», incident: inc-w15-buran), а не вторая отметка; новый кризис, открытый на показе, —
своя отметка. Просьба (необязательно): добавить в incident_marks поле "event" (связь SCHEMA §2.8) — склейка будет
точной без сравнения района и времени.

4. Окно выборки /heat (поведение R07 изменилось — для R08 и R10)
================================================================================================================
/heat и хроника берут у источника жалобы, поданные не раньше now − (max(days, days + 7) + 60) дней
(HeatService.window). Раньше было now − (days + 7): место, где давнюю жалобу исправили на днях, теряло зелёный
«исправлено», а старая открытая жалоба со свежим «Я тоже» — свежие голоса. Числа «Картины дня» R08 берут записи
у того же сервиса (records()) — тесты R08 263/0 после правки.

================================================================================================================
4а. Карта: что изменилось на экране (задача R07 №4) — для R10 и R11
================================================================================================================
- Число на кружке-кластере — люди только ОТКРЫТЫХ мест (как число района и «Обращения»); кластер из одних исправленных
  мест — «✓ N» (N — мест), а не сумма старых жалоб. Подсказка: «Исправлено: 4 места». Ключи heat.cluster.fixed_label,
  heat.cluster.fixed_tip (ru/kk) — R11.
- Легенда «?»: рядом с пунктиром «сообщили об устранении» сплошной зелёный подписан «проверено жителями»
  (heat_states.verified_fixed), без пунктира — короткое «исправлено», как в строке легенды оболочки.
- Скрытые значки (в кластере, вне места) не держатся в DOM: при 1 000 целей на масштабе 12,6 в документе ~50 значков
  вместо ~1 000. Проверки, которые ищут .r07-badge[hidden], найдут только скрытые с прошлой раскладки — считайте видимые
  через CivicHeat.current.badges() / CivicShell.heat.badges(), как раньше.
