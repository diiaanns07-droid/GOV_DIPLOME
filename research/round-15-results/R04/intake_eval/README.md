# Оценка «ИИ-разбора пачки» (R04, П3) на наборе R02 «обращения за ночь»

Набор и эталон — R02 (`data/civic/astana/demo-world/intake_night_v1.json`, `intake_night_v1.gold.json`, 301 текст,
115 групп), оценщик — R02 `ml/datasets/demo_intake_eval.py`. Всё синтетическое (один автор, повторы похожи сильнее,
чем в жизни): в FACTS и дипломе — с пометкой «синтетический набор R02».

| Файл | Что |
|---|---|
| `r02_night_blind_a2e004c9.json` | **слепая** оценка: код R04 написан до знакомства с набором (7867fada / a2e004c9), весь набор |
| `r02_night_halves_blind.json` | те же слепые числа по половинам: dev — чётные группы, отложенная — нечётные |
| `r02_night_halves_after_dev_fixes.json` | **после разбора ошибок** — только на dev-половине; отложенная половина не просматривалась |
| `r02_night_halves_after_dev_fixes_gold_cfcccf70.json` | то же «после разбора ошибок» на эталоне R02 **cfcccf70** (16 окт 19:27): перекрёсток засчитывается по любому светофору того же узла (просьба R04 9.8) |
| `eval_halves.py`, `err_analysis_dev.py` | как считали: R04_EVAL_DIR — папка с `r02/` (файлы набора) и `r02wt/` (дерево R02) |

Протокол: ошибки смотрелись только на dev (чётные группы `g-002, g-004 …`); правки — общие правила (перекрёсток
«A и B» по светофорам R12, улицы-двойники OSM, слово «улица» вплотную важнее далёкой «остановки», «тас жолы», «ш.»,
«қ → х» в именах, «ЖК» вплотную, опечатка в слове-подсказке, «не вывозят» ≈ «переполнены», сигналы маршрутизации:
нет света в подъезде, нет автобуса, ночная стройка, машины на газоне, колесо ≠ труба). Честная оценка обобщения —
отложенная половина: ведущая служба 0,799 → 0,836, весь набор служб 0,784 → 0,821, повторы F1 0,610 → 0,651,
групп собрано точно 0,54 → 0,58, места 0,921 → 0,969; срочные и «адрес уточнить» — без изменений.

Оценщик R02 считает место перекрёстка верным только для светофора эталона: разбор находит тот же светофорный узел
(4 светофора у Коргалжинского ш. и пр. Туран), но выбирает центральный — это засчитывается как ошибка места.

С эталоном R02 cfcccf70 (16 окт 19:27 по Астане) перекрёсток засчитывается по любому светофору того же узла: места
после разбора ошибок — весь набор 0,933 → 0,979, dev 0,904 → 0,987, отложенная половина без изменений (0,969: групп
с перекрёстками в ней нет). Остальные числа те же. Слепой код a2e004c9 на новом эталоне — те же слепые числа (правила
перекрёстков у него не было). Код R04 для расчёта — 9c16e868 (ответы разбора те же, что у D3: после неё менялись только
казахские тексты и скорость модерации S53).
