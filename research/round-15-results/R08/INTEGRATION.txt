═══ 1. R01 (ui/web_server.py, оболочка) ═══
1.1 Маршруты (CONTRACT §7). Ситуационный центр и «Картина недели» — только для сотрудника. Модуль raw проверяет это сам
    по флагу staff, который шлюз передаёт только при staff_view=True (как у heat.target R07):

    V2_ROUTES += (
        ("GET", ("akim", "board"), "akim.board"),
        ("GET", ("akim", "week"), "akim.week"),
    )
    V2_HANDLERS += {
        "akim.board": V2Handler("R08", ("ui.civic_akim.api",), "handle_get", kind="raw", staff_view=True),
        "akim.week": V2Handler("R08", ("ui.civic_akim.api",), "handle_get", kind="raw", staff_view=True),
    }
    Без staff_view функция не получит staff=True и честно ответит 403 forbidden («только для сотрудников акимата»).
    Ответы: 200 JSON; 400 bad_request (district, date); 403 forbidden; 500 akim_failed (сервер не падает).

1.2 В CivicV2Gateway.wire() (где сейчас akim.configure(demo_build=...)) передать путь к той же SQLite и флаг демо-мира:
        kwargs = {"demo_build": True} if self.demo else {}
        kwargs["db_path"] = str(self.db_path) if self.db_path else None
        kwargs["demo_world"] = os.environ.get("CIVIC_DEMO_WORLD") == "1"
        akim.configure(**kwargs)
    Нужен, чтобы читать сервисы соседей (R17, R16, R13), если у них нет функции чтения (§5). Без него R08 берёт
    CIVIC_DB_PATH / CIVIC_DB из окружения. Старый вызов configure(demo_build=True) продолжает работать.

1.3 CIVIC_ASSETS (будет уточнено к B1): "board/index.html", "board/board.js", "board/board.css",
    "akim/week.html", "akim/week.js", "akim/week.css".
1.4 Меню: «Ситуационный центр» — отдельная страница на весь экран (/civic/board/index.html); место — по IA_ROUND15 R11.
    Если R11 оставит «Ещё»: BirgeShell.registerScreen({id: "board", href: "/civic/board/index.html", modes: ["akimat"],
    titleKey: "board.title"}) — ссылка в «Ещё». Палитра Ctrl+K: «Ситуационный центр».

═══ 2. R17 (ui/civic_agencies) — что читает Ситуационный центр и «Картина дня» ═══
2.1 Табло служб (только чтение, без пересчёта у R08 — R08 только показывает):
    board_for_akim(db_path=None, *, days=7, district=None, now=None) -> dict   — то же тело, что GET agencies/board
    Поля, которые R08 показывает (имена можно свои — R08 понимает и синонимы, но лучше так):
      {"days": 7, "demo": true|false,
       "items": [{"service": "water", "open": 12, "overdue": 3, "median_answer_days": 2.5,
                  "verified_share": 0.4, "returned": 1, "handoffs_in": 2, "handoffs_out": 1, "joint": 3}],
       "joint": {"open": 4, "week": 6},            # совместных обращений: открытых сейчас / новых за days
       "handoffs": {"week": 9}}                    # передач между службами за days
    «3 самые отстающие службы» на «Картине дня»: если в ответе есть "lagging": ["water", …] — беру ваш порядок;
    нет — по убыванию overdue, затем median_answer_days (числа ваши, порядок — только для показа).
2.2 Кризисы: incidents_for_akim(db_path=None, *, district=None, now=None) -> list[dict] — записи CONTRACT §5.5
    (активные первыми), с задачами (вид сотрудника). R08 показывает: название, зону, задачи по службам (сделано/всего),
    последнее обновление ru/kk.
2.3 Ссылка «Открыть кризисный штаб» (кнопка у тревоги пульса и в блоке кризиса). R08 по умолчанию ставит:
      активный кризис → "/#agencies/<incident id>";   нет кризиса → "/#agencies/new?kind=blizzard&district=nura"
    (kind по теме тревоги: snow_ice → blizzard, utilities/no_heating → heat_outage, utilities/no_water → water_outage).
    Если у вас другой адрес — поле "link" в записи кризиса и строка в вашем INTEGRATION: R08 возьмёт его.

═══ 3. R16 (ui/civic_together) — блок «Жители вместе» ═══
    together_for_akim(db_path=None, *, days=7, district=None, now=None) -> dict
      {"initiatives": [записи CONTRACT §5.2 — только публичные поля, без author_device],
       "yards": [записи §5.3 — members только числом],
       "counts": {"published": n, "joined": n, "done": n, "supported": n}}   # за days; нет counts — R08 сосчитает по записям
    «Двор недели» — двор с самой живой инициативой недели (больше всего «Я приду» / «Сделано вместе»); если у вас есть свой
    выбор — поле "yard_of_week": {"id": "yard-…"}.

═══ 4. R13 ═══
4.1 ui/civic_meetings: meetings_for_akim(db_path=None, *, district=None, now=None) -> list[dict] — записи §5.7 с orders
    (поручения: text_ru/kk, service, due, status). R08 показывает поручения со сроком: просроченные, на этой неделе, сделано.
4.2 Прогноз на неделю: ui.civic_forecast.week_forecast(district=None, k=5, now=None) -> dict

       "items": [{"target": {kind,id,label_ru,label_kk}, "district", "main_category", "level",
                  "reason_ru": "…одной строкой…", "reason_kk": "…"}],
       "method_ru": "…", "method_kk": "…"}   # «Как считаем» (числа backtest из ваших результатов)
    Пока функции нет — R08 показывает attention_next_month() (FINAL-4) с честным заголовком «на месяц», пометка «прототип».
4.3 Пульс считает R08 (ui/civic_akim/pulse.py); ссылку «Открыть кризисный штаб» к тревоге добавляет R08 (§2.3).

═══ 5. Запасной путь чтения (если функции из §2–4 нет) ═══
R08 создаёт один экземпляр make_service(db_path) соседа на процесс и вызывает .handle("GET", "/api/civic/v2/<маршрут>",
query, None, principal, {}) только для чтения: agencies/board?days=7, incidents, together/initiatives?status=published,
meetings. principal — служебный {"username": "situation-center", "role": "staff"} (сам маршрут akim/board — только
сотруднику, §1.1). Конверт {"ok": true, "data": …} и голое тело понимаются оба. Ошибка соседа — блок «пока нет данных»,
не ошибка всего ответа.

═══ 6. Демо-мир (CONTRACT §11) ═══
CIVIC_DEMO_WORLD=1 → фикстуры R08 (ui/civic_akim/fixtures/) не подмешиваются: числа только из модулей. Своих записей
в демо-мире у R08 нет (R08 только читает) — seed_world не нужен.
