ИИ-аналитика. Уровни: **высокий** — утечка ПДн многих или обход прав сотрудника; **средний** — ПДн одного, доступность,

## 6. Что сделано хорошо (проверено тестами)

- **Двор и «Я приду» — только числа.** Ни id устройства, ни его хэша, ни времени вступления в ответах; в файле SQLite —
  только солёный хэш (R16, R13). «Моё» видит только своё устройство; сводки для R08/R17 — тоже только числа и свои дворы.
- **Сотрудник — сессия + CSRF + свой сайт, в модуле и в шлюзе.** 6–7 видов отказа на каждое действие штаба, встреч,
  инициатив и передач (аноним, житель, автор, без CSRF, чужой CSRF, чужой Origin, роль «житель»).
- **Публичное — белым списком полей.** Кризис жителю — без задач служб, внутренних обновлений и журнала; жалоба — без
  причины передачи и логина; инициатива — без автора; «на проверке» — 404 всем, кроме автора и сотрудника.
- **Тексты жителей — через модерацию R04 до публикации**; на экранах — только текст (браузер: нагрузка видна как текст,
  0 вставленных элементов, 0 нарушений CSP); R06 не принимает HTML в работах; обновления кризиса R17 блокируют все 11
  проверенных форм ПДн (телефон в 4 записях, ИИН в 2, карта, IBAN, квартира, ник, e-mail), а список маршрутов — нет.
- **ИИ-аналитик:** вопрос — данные, а не инструкция; любой флаг безопасности — без модели; числа модели вычёркиваются;
  наружу — только вопрос сотрудника и заголовки блоков без цифр; ключ — только из окружения.
- **Тяжёлые публичные запросы ограничены:** хроника — не длиннее квартала и не старше года; фильтр ПДн — единицы мс на
  враждебных 5000 символах; GET страницы двора ничего не пишет; кэши — с пределом.

## 7. Остаточный риск (честно)

- Житель без учётной записи: id устройства сбрасывается, лимиты держатся на адресе; в общей сети Wi-Fi все — один адрес.
- Права сотрудника не разделены по службам: любой редактор действует за любую службу; журнал пишет роль, не имя.
- Регулярные выражения обходятся словами («восемь семьсот один…») — последний барьер — проверка человеком (инициативы и
  вопросы публикуются после неё, обновления кризиса пишет сотрудник).
- Голосовой ввод (если включат): распознаёт браузер (в Chrome — серверы Google) — нужна подсказка у кнопки.
- Хранение ПДн в РК и согласие на обработку — вопрос пилота [ПРОВЕРИТЬ ИСТОЧНИК: Закон РК «О персональных данных и их
  защите»].
