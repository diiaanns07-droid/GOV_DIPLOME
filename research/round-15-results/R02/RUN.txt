R02 · РАУНД 15 · ДЕМО-МИР — КОМАНДЫ ЗАПУСКА И ПРОВЕРКИ

Что теперь можно: поднять стенд Birge, где карта, «Обращения», «Картина дня», табло служб и «Мой двор» показывают
числа по ОДНИМ синтетическим записям (743 жалобы за 60 дней, «Буран в Нуре», работы с конфликтами, дворы, инициативы,
кризис, встречи) — без противоречий FINAL-4 («Нура · 80» на карте и 2 записи в «Обращениях»).

1. Пересобрать мир и проверить (Python 3.11+, без сети, ~5 с каждая команда)
     python3 -m ml.datasets.demo_world              # world_v1.json + world_v1.sample.json, печатает сводку и sha256
     python3 -m ml.datasets.demo_world --check      # воспроизводимость: тот же sha256, что в файле (на тех же файлах карты
                                                    # R12, что в шапке мира inputs; на других — код 2 и причина)
     python3 -m ml.datasets.demo_world_expected     # EXPECTED.json — числа экранов кодом R07/R08/R09 (опорный момент)
     python3 -m ml.datasets.demo_world_expected --now 2026-10-17T18:00:00+05:00 --print   # на свой момент
     python3 -m ml.datasets.demo_world_check        # форматы, id, цели R12, люди = жалобы + «Я тоже», ПДн, demo: true
   Тесты: python3 -m pytest -q tests/civic/R02/round15 tests/civic/R02/test_r02_schema.py      (39 passed)

2. Стенд с демо-миром (облако или ноутбук; пока R01 не взял patch — применить его локально, файл R01 не коммитить)
     git apply research/round-15-results/R02/patches/R01_demo_world.patch
     mkdir -p /tmp/birge && D=/tmp/birge/world.sqlite3
     python3 -B -m ui.civic_store --db $D init
     python3 -B -m ui.civic_store --db $D seed-demo --package data/civic/astana/demo_synthetic.json
     python3 -B -m ui.civic_store --db $D seed-r14-demo
     python3 -B -m ui.civic_store --db $D create-editor operator --password-stdin      # пароль 12+ символов
     CIVIC_DB_PATH=$D CIVIC_DEMO=1 CIVIC_DEMO_WORLD=1 python3 -B app.py --port 8656
   В консоли: «civic-demo-world: R09: inserted 743, …; R06: …» (у модулей без seed_world — «нет seed_world»).
   Повторный запуск: «R09: … reset 743» — демо-записи возвращаются в исходный вид от нового «сейчас» (репетиция не
   съедает показ). Без CIVIC_DEMO_WORLD=1 — демо как в FINAL-4.
   Windows (ноутбук): set CIVIC_DEMO_WORLD=1 перед run-city.bat (когда R01 включит patch в сборку).

3. Сверка живого стенда с миром (то, что рисует интерфейс, против EXPECTED на тот же момент)
     printf '<пароль>' > /tmp/birge/pw.txt
     python3 tests/civic/R02/round15/stand_numbers.py --base http://127.0.0.1:8656 --password-file /tmp/birge/pw.txt \
         --out research/round-15-results/R02/stand_numbers_world.json
   Ожидается «OK» в 14 строках (карта 7/14/30 дней, «Картина дня», «Обращения», список R09) и код выхода 0.

4. Засев жалоб мира без сервера (R09 / отладка)
     python3 -c "from ml.datasets.demo_world_seed import seed_world; print(seed_world('/tmp/birge/c.sqlite3'))"

5. LOCAL-14 · живые тексты людей (ноутбук владельца; тексты в Git не попадают никогда)
     python -m ml.labeling.import_form private/form.csv          # → private/form_<дата>.jsonl + .review.txt
     (открыть .review.txt, вычеркнуть то, что похоже на личные данные; обезличивание — регулярные выражения)
     web/labeling/index.html — двойной щелчок, разметка 300 текстов без мыши (~2 ч), Ctrl+S — экспорт JSONL
     python -m ml.labeling.agreement private/labels_A.jsonl private/labels_B.jsonl   # согласие разметчиков (kappa)
   Дальше — оценка модели по RUN.txt R03 (результаты без текстов — в ветку R03). В демо-мир живые тексты не идут.
