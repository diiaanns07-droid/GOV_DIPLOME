# K08 R7 — шаблон полей происхождения: сценарий «Если добавить объект» и карточка результата

Спецификация: `research/round-7/FEATURE_SPEC.txt` @ codex/research-import-2026-10-05. Закреплённые входы: BUILD `claude/beautiful-clarke-sbzomj` @ `c58a3b2b175cf978ad785fef7f88d8fd9b1338f2` (`prototypes/city-evidence/`, код = b3e4dc4).
Это **не интеграция**: модуль, фикстуры и шаблон для сборщика. Новый формат не вводится. Сценарий содержит только поля контракта `city-whatif-v1`. Карточка — выводимое представление: при импорте она не принимается и пересчитывается.

## Классы полей
| Класс | Смысл |
|---|---|
| **user_input** | ввёл пользователь. Не наблюдение о городе |
| **observed_secondary** | скопировано из записи Overture/K10 как есть: вторичные открытые данные, не официальный реестр |
| **derived** | вычислено приложением по правилам FEATURE_SPEC из user_input и observed. При импорте пересчитывается |
| **config** | фиксированный параметр расчёта или текст ограничения |

## Сценарий `city-whatif-v1` (только поля контракта)
| Поле | Класс | Примечание |
|---|---|---|
| `schema_version` | config | `city-whatif-v1` |
| `city_id` | user_input | `shymkent` \| `astana` |
| `source_snapshot` | derived | `sha256:` от канонического JSON: city_id, release, bbox, `places_file{path, sha256, bytes}` (sha256 фактических байтов, сверенный с `inputs/k10/package_manifest.json`), K10 SHA, параметры расчёта. Имя файла версией не считается |
| `category` | user_input | `school` \| `outpatient_clinic` |
| `control_points[] {id, lon, lat}` | user_input | 1..10, id уникальны (≤64 символов, `[A-Za-z0-9_.:-]`), координаты конечные, внутри bbox |
| `proposed_object` | user_input | `null` или один `{id, lon, lat, category = category}` |
| `proposed_object.kind` | config | всегда `"hypothetical"`; в UI — «условный объект (гипотеза пользователя)» |

## Карточка результата (что показывать)
```
[Статус]       Гипотетический сценарий. Не решение акимата и не доказательство пользы строительства   (config)
[Источник]     Overture <release> · пакет K10 <branch@sha> · выгрузка <retrieved_utc>                     (observed_secondary)
               Отпечаток среза sha256:… · файл мест <path> sha256 …                                       (derived / observed)
[Охват]        Квадрат <bbox lon/lat> — не граница города · записей категории в срезе: N                  (observed / derived)
               «Срез — не полный реестр города»                                                           (config)
[Таблица]      Точка | До, м | После, м | Разница, м | Ближайшая запись                                   (user_input | derived ×3 | derived)
               «Разница — уменьшение расстояния по прямой, не время и не качество услуги»                 (config)
[Ближайшая]    название · категория Overture · lon/lat · confidence · v<overture_version>                  (observed_secondary)
               источник: dataset · лицензия · record_id · дата обновления                                 (observed_secondary)
               QA: <флаги> | «флагов нет ≠ проверено»                                                     (derived, правила сборки)
               Если ближайший — проект: «условный объект proj1 (гипотеза)», плюс ближайшая исходная запись до проекта с источником и QA
[Атрибуция]    поставщики и лицензии из data.js                                                           (observed_secondary)
[Ограничения]  6 строк, см. whatif_provenance.LIMITATIONS                                                 (config)
```
Нет исходных записей: `before = null`, `after = расстояние до проекта`, `delta = null`, подпись «В срезе нет исходных записей; улучшение не вычисляется».

Нельзя показывать и утверждать: время пешком, минуты, изохроны, обеспеченность, население, экономию бюджета, эффект пробок, улучшение здоровья или образования. Нельзя писать, что сценарий доказывает пользу строительства.

## Экспорт и импорт
- Экспорт: поля контракта плюс (необязательно) `report` = карточка. `report` и любые distances/delta при импорте **игнорируются** и пересчитываются.
- Импорт отклоняется, если:
  - чужой `source_snapshot` (пересчитан из текущих данных);
  - NaN, Infinity, 1e999 или дубликаты ключей;
  - больше 1 проекта;
  - дубликаты id;
  - точки вне bbox;
  - JSON больше 256 KiB.
- Строки выводятся как текст (`textContent`). URL из импорта не загружаются.
