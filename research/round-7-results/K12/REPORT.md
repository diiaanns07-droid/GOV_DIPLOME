## Инвариант «состояние не изменилось»

Для каждой негативной фикстуры стартовое состояние — принятый сценарий P01. После отказа должны
выполняться все условия:

- `ok === false` без исключения;
- возвращённое состояние побайтно (JSON) равно состоянию до импорта;
- переданный объект не мутирован. Импортёру передаётся копия, мутация обнаруживается сравнением;
- `currentState()` и `compute()` не изменились;
- 0 сетевых попыток (`http`, `https`, `net`, `tls`, `fetch`, `XMLHttpRequest` перехвачены);
- `Object.prototype` не изменён, новых глобальных переменных нет.

Для позитивных: `compute()` совпадает с **независимым** оракулом модуля (гаверсинус по
спецификации, R = 6371008,8 м, промежуточное значение зажато в [0, 1]) с допуском 1e-6 м.
Опционально E01: экспорт ≤ 256 KiB, строгий JSON без локальных путей и токенов, повторный импорт
даёт то же состояние.

## Что предлагается BUILD

`reference/whatif_import_ref.cjs` — предложение, не интеграция.

1. **Порядок проверок:**
   - размер в **байтах** UTF-8 — до разбора;
   - строгий разбор: свой парсер, потому что `JSON.parse` молча берёт последний повтор ключа и
     превращает `1e999` в Infinity;
   - белый список полей;
   - версия → город → категория → отпечаток → точки → проект → уникальность ID.
2. **`results` в импорте игнорируется**, всё пересчитывается. Экспорт держит входы и выводимые
   значения раздельно (`results.derived = true`).
3. **Отпечаток:** sha256 канонического JSON из `{city, category, release, bbox, sha256 файла
   объектов, формула, радиус}`. Имя файла и URL отпечатком не считаются.
4. **Отказ возвращает прежнее состояние:** импортёр ничего не применяет до полной валидации.

## Ограничения

- **Не проверено отображение строк в DOM** («показывать как текст»): тест безголовый. Эталон
  отклоняет HTML в ID и неизвестные поля, но безопасный показ — задача UI и smoke-теста BUILD.
- Коды отказов в спецификации не названы. Совпадение кодов — advisory (`--strict-codes` делает их
  обязательными). Словарь эталона — в `ADAPTER.md` и индексе.
- N15 (отпечаток другой категории) и N42 (BOM) — advisory, их ожидание зависит от решения BUILD.
- Граница bbox считается включительной. Спецификация это прямо не оговаривает.
- Windows и браузерный запуск модуля не проверялись.
