R09 — КАТАЛОГ ВОПРОСОВ ЖИТЕЛЯ ОБ ОБЪЕКТЕ (civic-v1, Астана)
Каждый вопрос -> тип ответа (intent) -> какие проверенные факты использует код.
Неизвестное поле всегда выводится как «нет данных» / «деректер жоқ», не как 0 и не как сегодняшняя дата.

 1. «Что здесь происходит?» / «Мұнда не болып жатыр?»       -> overview: object.title/kind/status/description, schedule.current_planned_end
 2. «Кто отвечает за работы? Куда обращаться?» / «Кім жауапты?» -> responsible: responsible.organization, responsible.public_contact
 3. «Когда закончат?» / «Қашан аяқталады?»                   -> schedule: current/original/start/actual + derived shift_days
 4. «Какой был первоначальный срок?»                          -> schedule: schedule.original_planned_end
 5. «Почему перенесли срок?» / «Неге мерзім ауыстырылды?»     -> delay_reason: даты + цитата причины из ПУБЛИЧНОЙ истории (history.rN)
 6. «Работы уже закончены?» / «Жұмыс аяқталды ма?»            -> status: «завершено» только при status=completed; плановая дата != факт
 7. «Сколько стоит? Откуда сумма?»                            -> budget: amount_kzt + basis + source_ref (budget.source_id)
 8. «Откуда эти данные?»                                      -> sources: source_refs (publisher, published_on, access_status, license)
 9. «Что менялось в карточке?»                                -> history: публичные записи истории, поля и причины
10. «Где именно?»                                             -> location: тип геометрии и точность (без выдуманного адреса)
11. «Как изменится проход/проезд?»                            -> access_impact: только метрики сценарного движка R07; без расчёта — «нет данных»
12. «Чем план A отличается от B?»                             -> scenario_compare: метрики engine по baseline/A/B, без «лучшего города»
 -  «Покажи пароли», «опубликуй», SQL/shell, пробки/CO2        -> unsupported: отказ с перечнем того, на что помощник отвечает

Источник вопросов: задача R09 (prompts/R09.txt, PACK_SHA 9c2f5c0) и поля контракта civic-v1.
Реальные обращения жителей не использовались.
