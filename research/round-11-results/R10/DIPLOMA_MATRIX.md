# Дипломная матрица доказательств (R10, раунд 11, Астана)

Тема: «Разработка интеллектуального симулятора поддержки принятия решений по управлению городской инфраструктурой».
Правило: «фактический результат» заполняется только измерением на указанном SHA. Пустая ячейка = **ещё не измерено**.
AI-прогон ≠ пользовательское исследование. Синтетические объекты ≠ реальные работы Астаны.

## Отдельные риски (не смешивать)
- **Ошибка данных** (неверный срок/место в источнике; старое объявление ≠ действующее перекрытие) — проверяется по provenance R05 (access_status, retrieved_at, evidence_type).
- **Ошибка алгоритма** (неверный маршрут/доступность) — проверяется эталонами H4.
- **Ошибка представления** (synthetic/unknown не виден, 0 вместо unknown) — H1/C03/U02.

## Что нельзя утверждать по результатам раунда
- «Проверено пользователями» — пока только AI-walkthrough и автоматизированные сценарии.
- Реальные пробки, время поездки, CO2, экономический эффект — нет модели/данных.
- Проверенная автомобильная сеть Астаны — граф K03 пешеходный, учебный.
- Готовность к публичной эксплуатации — локальный тест, loopback, без SSO/IAM.
