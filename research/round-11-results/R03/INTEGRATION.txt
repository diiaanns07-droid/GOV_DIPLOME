4. HOOK — R01 shell already calls it correctly (origin/claude/affectionate-ride-bol5v8 @ f639a4b, shell.js mountPublic):
     mount("map", $c("civic-map-root"), { map: currentMap(), onSelect, onFeedback })
   -> CivicMap.mount({ root, map, api, onSelect, onFeedback }) returns { refresh, selectObject, destroy }
   plus optional extras: setMap(map) (late binding when the map was null), fitAll(), getState(), getLayout(),
   layerIds(), sourceId, setFilters(f).
   Layout is automatic: root is not a direct child of <body> -> "embedded" (no own positioning, no own scroll,
   own heading hidden; R01's panel/sheet/heading stay in charge). Root directly in <body> -> "overlay"
   (own desktop side panel + mobile bottom sheet; used by the stand). Force with option layout:"embedded"|"overlay".
   Other options (all optional): mapPadding {top,right,bottom,left} (overrides computed camera padding),
   persistFilters (default true; localStorage key civic-r03:filters:v1 with kinds/statuses/period/from/to/area only),
   permalink (default false — R01 owns #object=), fitOnLoad (default false), title, now() (clock for tests),
   pathPrefix (default "" — paths are relative to /api/civic/v1 as in R01 api.request), autoload (default true).

5. EVENTS / CALLBACKS
   onSelect(obj | null, { source })   once per selection change. obj = frozen {id,title,kind,status,geometry,
                                      precision,evidence,schedule}; null when the card is closed (source "close").
                                      source: "list" | "map" | "api" | "permalink" | "close".
                                      Compatible with R01 onSelect(item) -> item.id.
   onFeedback({ objectId, title, geometry, object })   from the card button «Задать вопрос по объекту».
                                      Compatible with R01 openFeedback(target) -> target.objectId / target.geometry
                                      and with CivicFeedback.mount({root, api, objectId, geometry}).
   DOM CustomEvent "civic-r03:layout" on root (non-bubbling): {mobile, sheet, view, rect} — for hosts that place
                                      the attribution/toasts relative to the overlay sheet.
   No other globals are written. document.body, other modules' state and the hash are not touched (permalink off).

6. API USE (public, GET only; never /staff)
   GET /objects            then GET /objects?cursor=<next_cursor> until null (max 20 pages; truncation is shown)
   GET /objects/{id}       card details + public history
   Called as api.request("GET", path, undefined, { signal }) — the 4th argument (R01 api.request option) aborts
   superseded requests; implementations without it are fine (stale responses are also dropped by a sequence guard).
   Envelope {ok,data} is unwrapped defensively if an api returns it raw. Errors read {status, code}:
   network/timeout/aborted/404/429/503/5xx have distinct Russian texts and a «Повторить» button.
   Filtering (kind, status, planned period, search, visible area) is client-side over the published list, so facet
   counts and the honest «без плановых дат / неполный интервал / без места на карте» notes are exact.

7. MAP (the one MapLibre instance; never creates a map)
   Source  civic-r03-objects (GeoJSON, promoteId cid)
   Layers  civic-r03-area-fill, -area-line, -area-line-approx, -line-casing, -line, -line-approx,
           -synthetic-outline, -selected-line           (inserted before the first basemap label layer)
           civic-r03-point-halo, -point-synthetic, -point, -selected-point   (on top)
   Handlers map.on: click (one handler, queryRenderedFeatures on R03 layers), mousemove, mouseout, styledata
           (re-adds R03 layers after setStyle, e.g. map.js offline fallback), moveend (visible-area filter).
   destroy() removes all of the above, the tooltip popup, the cursor change, timers/rAF, root listeners and restores
   the root element (children, class, role, aria-label) exactly. Verified twice in a row in the browser suite.
   Null geometry -> list only. Approximate geometry -> dashed line/halo, never mixed with source geometry.
   Synthetic -> grey dotted ring/outline on the map, «Демо» badge in the list, banner in the card, note in tooltip.
   Camera: selection fits the object into the part of the map not covered by the host panel (outermost
   absolute/fixed ancestor of root), keeps the user's pitch/bearing (2D/3D), duration 0 with prefers-reduced-motion.
   No extrusions, heights or traffic are drawn.
