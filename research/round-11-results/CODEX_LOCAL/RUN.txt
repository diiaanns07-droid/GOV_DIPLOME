ЗАПУСК
Двойной щелчок по run-city.bat из корня проекта.
Он использует обычный run.bat, порт 8611 и отдельную постоянную базу
.runtime/round11-local.sqlite3. Демо-импорт повторяемый: существующие
отредактированные записи не перезаписываются. Все демо-объекты синтетические.
При уже работающем сервере откройте адрес; второй процесс не нужен.

КАБИНЕТ СОТРУДНИКА
Публичная карта не требует входа. Общего пароля нет.
Чтобы создать собственную локальную учётную запись, после первого запуска
откройте PowerShell в корне проекта и выполните:
  .venv\Scripts\python.exe -X utf8 -B -m ui.civic_store --db .runtime/round11-local.sqlite3 create-editor editor
Пароль вводится скрыто. После создания: кнопка «Для сотрудников», логин editor.
Эта команда не меняет пароль существующей учётной записи.

ПРОВЕРКИ
Python (без стороннего браузерного раннера):
  .venv\Scripts\python.exe -X utf8 -B -m pytest -q -p no:cacheprovider tests --deselect tests/civic/R09/test_r09_ui.py::test_ui_in_real_chromium --basetemp=.runtime/pytest-local
  .venv\Scripts\python.exe -X utf8 -B -m ui.web_check
JavaScript:
  node --test tests/civic/R03/core.test.mjs tests/civic/R04/core.test.cjs tests/civic/R04/contract_mock.test.cjs
Браузер проверяется отдельно в Codex Browser. Фактические результаты — CHECKS.json.

ОГРАНИЧЕНИЯ
В срезе пока нет подтверждённых реальных городских работ; 9 демо-записей,
7 опубликованных. Это не официальная система акимата, сообщения не отправляются
в iKOMEK/eOtinish. R08 не поставлен, помощник использует проверенные факты и
шаблоны. Сценарии сравнивают пешеходные пути, не прогнозируют пробки.
Доступность 3D зависит от сети и покрытия OpenFreeMap/OSM.
