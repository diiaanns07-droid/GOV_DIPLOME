ТРЕБОВАНИЯ
- Python 3.11–3.14 (проверено на 3.13.16). Городская платформа использует только стандартную библиотеку;
  requirements*.txt не менялись. Node 22 + Playwright нужны только для браузерных проверок.
- Интернет не нужен: без OpenFreeMap карта работает на упрощённом светлом фоне (без улиц и 3D-зданий).

ЗАПУСК С ЧИСТОЙ КОПИИ (Linux/macOS; на Windows те же команды с python вместо python3)
  git fetch origin claude/affectionate-ride-bol5v8
  git checkout <CODE_SHA>
  # 1) по желанию — синтетический демо-срез Астаны (R05, evidence_type=synthetic, не реальные работы):
  python3 -B -m ui.civic_store seed-demo --package data/civic/astana/demo_synthetic.json
  # 2) учётная запись редактора: пароль вводится скрыто (getpass), в Git и аргументах его нет:
  python3 -B -m ui.civic_store create-editor <логин>
  # 3) сервер (один процесс, loopback):
  python3 -B app.py --port 8611
  # откройте http://127.0.0.1:8611/
База: .runtime/civic.sqlite3 (вне web/, права 0600, в .gitignore и .dockerignore). Другой файл:
  CIVIC_DB_PATH=/путь/civic.sqlite3 python3 -B app.py --port 8611
Одной командой с установкой окружения: CIVIC_DEMO=1 PORT=8611 bash run.sh  (Windows: set CIVIC_DEMO=1 & run.bat)
При старте сервер печатает строку статуса модулей, ожидаемо:
  civic-v1: store=ready, feedback=ready, scenarios=ready, assistant=ready

ЧТО НА СТРАНИЦЕ
- По умолчанию режим «Город» (Астана): опубликованные работы/события на одной карте MapLibre, карточки,
  история сроков, сообщения жителей, помощник по фактам карточки, сравнение ограничений (пешеходный граф).
- «Школы» — прежний кейс доступности школ (GOVTECH, без изменений); «Учебная модель» — прежний
  симулятор «Аким на 5 часов» (Score 52,56, условные показатели). Переключатель режимов вверху.
