# R05 — план получения реальных записей при открытой сети

Это очередь проверки, а не факты. Ни один пункт ниже не подтверждён в раунде 11 (egress 403).

## Что нужно от среды
Разрешить исходящий HTTPS хотя бы к `www.gov.kz` (и при желании `astana.gov.kz`, `data.egov.kz`) в настройках
сетевого доступа облачного окружения. Без этого R05 не может добавить ни одной реальной записи честно.

## Очередь (по приоритету)
1. `src-govkz-astana-news-1193903`, `src-govkz-astana-article-99399` (BRIEF.txt) — прочитать заново, записать
   `published_on`, `retrieved_at`, sha256 (`tools/probe_sources.py`), выбрать только работы/события в Астане
   со сроками. Старая публикация → максимум `status=unknown` или historical.
2. Лента новостей того же ведомства на gov.kz за последние 30–45 дней: объявления о ремонте дорог,
   благоустройстве, перекрытиях и городских мероприятиях. Цель 8–15 записей; если подтверждено 3 — ставить 3.
3. Для каждой записи — intake по `data/civic/astana/templates/intake_record.template.json`:
   - сроки: «планируется/завершат до» → `current_planned_end` (`expected`), не `actual_end`;
   - «завершены/сдан» → `reported_actual` только если дата ≤ даты публикации;
   - сумма — только с basis (выделено → planned, контракт → contract, освоено → spent), и только если она
     относится именно к этому объекту, а не ко всей программе;
   - организация — только названная в тексте; подрядчика по тендеру с похожим названием не выводить;
   - место — улица/участок из текста → approximate point с `geometry_basis` по открытым данным OSM,
     либо `geometry=null`. Не копировать 2GIS/Google/Yandex.
4. Повторное получение тех же страниц через 1–2 недели → `tools/schedule_diff.py snapshot/diff`
   → находки только редактору.
5. LRT Астаны (лид из AST_A06, низкая уверенность: косвенный README UCL 2025) — проверять только по
   официальным материалам оператора/акимата; без них в пакет не попадает.

## Чего не делать
- Не брать частные/утёкшие базы обращений, телефоны/адреса авторов, подрядные документы без разрешения.
- Не скачивать фотобиблиотеки и полные тексты статей; хранить факты + ссылку + короткую выдержку ≤300 символов.
- Не трактовать недоступность сайта как отсутствие работ.
