РАУНД 12 — 10 ОТДЕЛЬНЫХ ЗАДАНИЙ ДЛЯ CLAUDE CODE

Каждому Claude отправить целиком только ОДИН файл из prompts/. Общие правила уже включены в каждый файл — ничего дополнительно склеивать не нужно.
Если продолжаешь старую сессию той же роли, сначала убедись, что в ней не идёт прежняя работа. Старые результаты сначала сохранить, затем новое задание. Не назначать одну роль двум активным агентам.

Если агентов осталось меньше: сначала R05 (реальные объекты), R02 (импорт/реестр), R03 (карта), R08 (модель для диплома), R07 (симулятор). Остальные роли запускать по мере доступности. R10 может проверять базу сразу; итоговую интеграцию проверяем после поставок.

Пять часов — ориентир, не требование бессмысленно расходовать лимит. Ранний рабочий checkpoint важнее длинного незавершённого ответа.
Каждый сохраняется примерно раз в 25–40 минут: свои файлы + handoff -> commit -> push собственной ветки.
После завершения нужны branch + SHA + push OK/FAILED. Create PR — при необходимости draft в codex/govtech-main-interface; merge не нажимать.

Codex в этом раунде — координатор приёмки и сборки. Пока Claude выполняют роли, координатор не редактирует принадлежащие им модули. Результаты не появляются в приложении автоматически: после их доставки требуется проверка и интеграция по собственным путям.
