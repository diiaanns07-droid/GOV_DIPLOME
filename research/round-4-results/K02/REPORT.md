## 2. Что меняет `fix.patch`

248 строк diff. Он «маленький» по смыслу, но не по объёму: основную часть занимает адаптер K05.

1. Грамматика ID: город с точками (`kz.shymkent`), период с дефисами (`2026-09-23`). Интервальный период `2025/2026` явно отклоняется: «/» — разделитель ID.
2. `Fact`:
   - единица только из `_UNITS`, добавлены `records` и `schools`;
   - подписи ru/kk обязательны и без цифр;
   - неконечные числа запрещены;
   - новые поля `coverage_complete` и `missing_reason`;
   - вид `hypothesis` (есть в контракте K05).
3. `catalog_from_observations` отклоняет повтор ID. Новый `catalog_from_k05` принимает записи `k05-obs-v1.1` напрямую. Подписи берутся из закрытой таблицы, `source` = `obs_id | data_version | boundary_version`.
4. `catalog_digest` — отпечаток каталога: ID, значение, вид, охват. В плане он обязателен (`PLAN_SCHEMA.required`). Если отпечаток не совпадает, план отклоняется с `stale_catalog`.
5. Повтор ID между секциями → `duplicate_id`.
6. `build_catalog` принимает только `astana_hackathon`.
7. В рендере для `coverage_complete=False` добавляется «неполный охват» / «толық емес қамту».

**Несовместимость:** планы без `catalog_digest` теперь отклоняются. Тесты раунда 3 написаны под старый API. Они по-прежнему проходят на неизменённом файле раунда 3, на fixed их гарантии перепроверены в `test_fix.py::KeptGuarantees`.

## 4. Граница гарантий после исправления

**Гарантируется:**
- число в проверяемой части — значение каталога. Подписи без цифр, единицы из таблицы кода;
- неполный охват виден в тексте;
- пропуск не печатается как 0;
- план по другому каталогу (смена плана, города, сценария) отклоняется.

**Не гарантируется:**
- **выбор снимка.** При двух снимках адаптер отказывает, а не выбирает. Вытеснение и давность решает контракт K05 (`k05r3_contract.py`) до вызова;
- **смысл «записей Overture».** Это вторичный источник и выборка, не реестр города. Подпись говорит «записей», а не «школ в городе». Пометка «расчёт, неполный охват» берётся из полей K05, полноту она не проверяет;
- **защиту от ошибки интегратора.** Отпечаток ловит переиспользование старого плана, но не ошибку в данных самого каталога;
- **качество выбора LLM** — не проверялось без настоящего вызова;
- **казахские подписи** (новые `жазба`, `мектептер`, «толық емес қамту» и др.) — черновик для носителя;
- **названия районов в подписях K05** — пока slug (`район abai`), а не официальное имя. Реестр названий — у K03.
