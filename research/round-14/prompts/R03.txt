ЗАЧЕМ
Это ядро дипломной работы AI-инженера. Нужна настоящая модель и честный эксперимент: три режима обучения (только синтетика / только тексты людей / смесь) × три модели (словарная эвристика, v1 логрегрессия, v2 трансформер), оценка на одном наборе текстов людей с доверительными интервалами.

Видеокарта владельца: RTX 4060 Laptop, 8 ГБ. Локальное окружение ГОТОВО (LOCAL-3, отчёт research/round-14-results/LOCAL/ENV.md):
venv C:\Users\LEGION\venvs\birge-ml (Python 3.12.10, torch 2.14.1+cu126, transformers 5.19.0, onnxruntime 1.31.0), CUDA работает.
Модели уже в локальном кэше HuggingFace: FacebookAI/xlm-roberta-base (используй ЭТО имя, старый алиас даёт 404) и intfloat/multilingual-e5-base. В облаке модели с HuggingFace, скорее всего, не скачаются — проверяй код на крошечной случайной модели (конфиг transformers без загрузки весов); если transformers не ставится — NOT_RUN с причиной.

ЗАДАЧИ ПО ПОРЯДКУ
1. ml/civic_classifier_v2/: config (модель по умолчанию xlm-roberta-base; длина 128; fp16; batch под 8 ГБ), data.py (читает корпус v3 от R02 и JSONL разметки людей; категории из categories_v2.json), train.py (взвешенные классы, ранняя остановка по macro-F1 на validation, seed, логи), evaluate.py (macro-F1, P/R/F1 по классам, матрица ошибок, бутстрэп 95%, таблица сравнения с v1 и эвристикой), predict.py.
2. experiments.py — режимы обучения: шаблонная синтетика v3 / LLM-синтетика llm_v1 (от R02) / только люди / смесь. Дополнительная базовая модель: LLM без обучения (zero-shot через OpenAI-совместимый API, ключ из переменной окружения, запуск только локально) — её точность на людях тоже в таблицу.
   Для «только люди» при малом наборе — стратифицированная k-fold. Результаты в ml/civic_classifier_v2/results/*.json + RESULTS.md (таблица, которую можно вставить в диплом).
3. export_onnx.py — ONNX + динамическое квантование int8 (onnxruntime); проверка, что предсказания ONNX совпадают с PyTorch на 200 текстах; замер скорости на CPU. Это то, что подключает R04.
4. RUN.txt с ТОЧНЫМИ командами для ноутбука владельца: создать venv, поставить зависимости (requirements-gpu.txt), обучить, оценить, экспортировать; ожидаемое время и пиковая память. Большие файлы (веса, ONNX > 50 МБ) — в ml/civic_classifier_v2/artifacts/ (в .gitignore через INTEGRATION для R01); метрики и RESULTS.md — в Git.
5. MODEL_CARD.md v2: данные, метрики, ограничения, что синтетика, что люди, честно.
