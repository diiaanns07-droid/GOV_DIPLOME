ЗАЧЕМ
Ядро диплома владельца — научный вопрос: «можно ли обучить классификатор обращений на казахском и русском на синтетике и сколько он теряет на текстах живых людей». Для этого нужны: хорошая синтетика, удобная разметка и честный набор от людей. Владелец размечает один — инструмент должен быть быстрым.

ЗАДАЧИ ПО ПОРЯДКУ
1. ИНСТРУМЕНТ РАЗМЕТКИ — ПЕРВЫМ, к вечеру 11 октября (владелец начнёт размечать сразу).
   web/labeling/index.html — одна офлайн-страница без сервера: открыть файл CSV/JSONL с текстами → крупно показывается один текст → 12 кнопок категорий с иконками и подписями (ru/kk), горячие клавиши, «Не жалоба», «Пропустить», «Отменить», прогресс «57 / 300», автосохранение в localStorage, экспорт JSONL. Режим «второй разметчик»: тот же поднабор без показа первых меток. Крупно, светло, удобно для долгой работы (UX_BRIEF).
2. ml/labeling/anonymize.py — убирает телефоны, e-mail, ИИН, ссылки, номера домов/квартир → [телефон], [адрес] и т. п.; отчёт, что заменено. ml/labeling/import_form.py — CSV из Google-формы → JSONL с обезличиванием. Выходные файлы с реальными текстами пишутся в private/ (добавь private/ в .gitignore через INTEGRATION.txt для R01).
3. ml/labeling/agreement.py — Cohen's kappa и матрица несогласий для двух файлов разметки (человек–человек или человек–LLM).
4. ml/datasets/LABELING_GUIDE_v2.md — правила для 12 категорий: что считается чем, спорные случаи (снег на тротуаре → snow_ice; яма во дворе → roads; нет света на остановке → lighting), 5+ примеров на категорию на ru и kk.
5. Синтетика v3: ml/datasets/synth_v3/ — генератор с фиксированным seed: 4000–6000 сообщений по 12 категориям; стили: разговорный, официальный, короткий, длинный, с опечатками, сленг, транслит латиницей, смешанный kk/ru, благодарность/вопрос (→ other); обезличено; дубли удалены; split по шаблонам train/val/test. Плюс пары перефразов для проверки поиска дублей (R04). Старый корпус v1 перевести в v2 по v1_to_v2.
6. LLM-синтетика и LLM-разметчик (запускаются ЛОКАЛЬНО у владельца; у него есть кредиты OpenAI API и NVIDIA API, оба до 23 октября; NVIDIA API совместим с OpenAI-клиентом, base_url https://integrate.api.nvidia.com/v1).
   ml/datasets/llm_synth.py — генерирует 3000–5000 жалоб по 12 категориям и стилям из п. 5 через OpenAI-совместимый API; провайдер, модель и base_url — аргументы; ключ только из переменной окружения (OPENAI_API_KEY / NVIDIA_API_KEY), никогда из файлов репозитория; кэш ответов, повтор при ошибке, лимит бюджета (--max-usd), обезличивание и удаление дублей; результат — отдельный корпус llm_v1 (не смешивать с шаблонным v3). Это даёт диплому сравнение «шаблонная синтетика против LLM-синтетики».
   ml/labeling/llm_label.py — LLM размечает тот же набор, что и владелец (по LABELING_GUIDE_v2, ответ строго одной меткой из 12) → файл для agreement.py (согласие «человек–LLM»).
   В облаке проверь оба скрипта на подставном клиенте без сети; команды для ноутбука — в RUN.txt с оценкой стоимости.
7. ml/datasets/README.md — откуда что, лицензии, как пересобрать, что синтетика (шаблонная / LLM), что люди.
