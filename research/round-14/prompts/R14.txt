ЗАДАЧИ ПО ПОРЯДКУ
1. docs/birge/ — документация продукта по фактическому коду веток ролей (не по планам):
   ARCHITECTURE.md (модули, кто с кем говорит, поток данных «жалоба → модель → тепловая карта → картина дня → решение → статус», схема в Mermaid);
   MODULES.md (для каждого модуля: назначение, файлы, функции и маршруты API, данные, как запустить тесты, известные ограничения, ветка и SHA);
   RUNBOOK.md (запуск на Windows с нуля: run-city.bat, venv для ML, где лежат модели и данные, частые ошибки);
   DATA.md (все данные: OSM, синтетика, корпуса, погода — источник, лицензия, что реальное, что синтетическое);
   CONTINUE_WITH_GPT.md — как продолжать с Codex/ChatGPT: правила (из CLAUDE.md и COMMON.txt), открытые задачи по модулям из STATUS.md ролей, готовые короткие промпты-шаблоны для типовых задач (исправить баг, добавить экран, переобучить модель, обновить данные).
2. docs/diploma/ — черновик дипломной работы на русском, в формате Markdown, по разделам (точные требования вуза владелец пришлёт позже — оставь места [ТРЕБОВАНИЕ ВУЗА]):
   00_vvedenie.md — актуальность (обращения граждан, 109, eOtinish, цифровизация акиматов), цель, задачи, объект и предмет, научная новизна (классификация казахско-русских обращений при нехватке реальных данных; синтетика шаблонная и LLM против текстов людей; привязка жалоб к объектам городской инфраструктуры), практическая значимость (Gton 2026, задачи акиматов);
   01_analiz.md — обзор предметной области и аналогов (iKomek 109, eOtinish, Smart Astana, FixMyStreet, SeeClickFix, 311-системы) и методов (классические модели текста, трансформеры, мультиязычные модели для казахского, поиск дублей эмбеддингами, прогноз по пространству и времени). Ссылки, которые ты не можешь проверить из облака, помечай [ПРОВЕРИТЬ ИСТОЧНИК] — их проверит ChatGPT с поиском;
   02_proektirovanie.md — требования, роли пользователей, архитектура, данные, API, UX-решения (тепловая карта объектов, смысловой зум, два языка);
   03_realizatsiya.md — модули и ключевые решения по фактическому коду (точность геометрии, классификатор v2, дубли, тепловая карта, 3D-превью, картина дня, прогноз);
   04_eksperimenty.md — постановка экспериментов R03 (режимы обучения × модели, метрики, бутстрэп) и R13 (backtest precision@K); таблицы результатов — из RESULTS.md ролей, пока их нет — заготовки с [РЕЗУЛЬТАТ R03];
   05_testirovanie.md — тесты и приёмка (числа из DELIVERY.json ролей), точность карты;
   06_zaklyuchenie.md, 99_literatura.md (ГОСТ-оформление, с пометками [ПРОВЕРИТЬ ИСТОЧНИК]).
   Только факты из кода и отчётов; ничего не выдумывай, синтетику называй синтетикой.
3. research/round-14-results/R14/FACTS.md — таблица ключевых цифр проекта с источником каждой (файл, ветка, SHA): для диплома, презентации и заявки Gton.
