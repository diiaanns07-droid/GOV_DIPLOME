ЗАЧЕМ (слова владельца)
«Всё должно работать очень чётко, важна точность на карте. Сейчас перекрытая улица очень кривая». Причина найдена: демо-объекты нарисованы от руки 2–3 точками и режут дома. А точная форма улиц уже есть: в engine/civic_scenarios/graphs/osm-astana-walking-20260506.graph.json 94 089 рёбер с настоящей геометрией OSM.

ЗАДАЧИ ПО ПОРЯДКУ
1. engine/civic_geo/ (только стандартная библиотека): загрузка рёбер графа с геометрией; сеточный пространственный индекс; ближайшее ребро к точке (расстояние в метрах); участок улицы между двумя точками — кратчайший путь по рёбрам, по возможности по одной улице (одно имя); targets(lon, lat, category) — 1–3 кандидата по target_kinds из categories_v2.json (CONTRACT §4); функции проверки точности (CONTRACT §8) и CLI-отчёт по всем объектам на карте.
2. data/civic/astana/geo/: из сырых OSM-объектов (задача LOCAL-1 кладёт их в data/civic/astana/osm-objects/) — компактные objects.json (остановки, площадки, спортплощадки, парки: id, имя ru/kk, координаты), yards.json (дворы — landuse=residential, упрощённые полигоны), ячейки ~150 м там, где дворов нет; SOURCE.json и атрибуция ODbL. Пока LOCAL-1 нет — каркас и тесты на маленькой фикстуре.
3. Исправить кривые линии: все линейные объекты на карте строятся из рёбер графа (скрипт привязки старых демо-геометрий → data/civic/astana/geo/demo_snapped.json, карта берёт его). Отрисовка в web/civic/map/: скруглённые стыки, правильный порядок слоёв относительно 3D-зданий, подписи без наложений, «примерное место» — областью.
4. Редактор (web/civic/editor/): вместо рисования линии от руки — инструмент «Участок улицы»: клик по улице (прилипает к оси) → клик по концу → точный предпросмотр по форме улицы → «Готово». Точка — с привязкой к ближайшему объекту OSM; двор — выбором полигона. Примени patch полей этапа от R06 (их INTEGRATION.txt).
5. API /targets (CONTRACT §7) — функция для R01; кандидаты нужны R09 (форма жалобы) и R05 (освещение вдоль участка).

ГОТОВО, КОГДА
- На карте ни одной линии «от руки»; отчёт проверки точности — 100% PASS; есть скриншоты «было/стало» для кривой улицы.
- Сотрудник создаёт точный участок улицы двумя кликами; /targets отвечает быстрее 50 мс.

НЕ ДЕЛАЙ
- Не меняй граф и engine/civic_scenarios/ — только читай.
- Не придумывай объекты, которых нет в OSM. Фонарей в OSM почти нет — освещение привязывается к участку улицы.
