## Ограничения

- Fuzz проверяет свойства и равенство с оракулом на случайных синтетических сценариях. Это не доказательство
  для всех входов.
  - Генератор не создаёт точек без данных категории: `unknown_count > 0` у победителя не встречался.
  - Unicode-ID (BUILD разрешает) проверяются только тестами BUILD.
- Оракул K12 и BUILD-оракул `tools/plan_oracle.py` написаны независимо. K12 не сравнивал их между собой
  напрямую — только через ответы `plan.js`.
- Тексты мутаций (`repro/mutants/*/mutation_*.txt`) не сжимаются: это одна мутация валидного сценария плюс
  команда `--replay`.
- Время зависит от машины; пороги (импорт < 200 мс, API-отказ < 200 мс, кусок < 50 мс, разрыв UI < 200 мс)
  выбраны K12, CORE_SPEC чисел не задаёт.
- Коды отказов и имена причин — словарь эталона. FAIL только с `--strict-codes`.
- Браузерная проверка опирается на страничный API `CITY_PLAN_UI` @ `d865dd4`. Если BUILD переименует его,
  проверку нужно обновить: тогда это ошибка теста, не продукта.
