ЗАЧЕМ
Обращение «яма после раскопок» гоняют между Водоканалом и Дорожной службой, а в буран каждая служба видит только своё. Аким
не видит, кто тянет. Ты делаешь общий штаб служб: одно табло, совместные обращения, журнал передач и кризисный штаб, где
службы работают по одной зоне и одному плану, а жители зоны видят обновления.

ТВОИ ПУТИ: ui/civic_agencies/, web/civic/agencies/, tests/civic/R17/; research/round-15-results/R17/, свой handoff round15.

ЗАДАЧИ ПО ПОРЯДКУ
1. ui/civic_agencies/: профили служб поверх существующих id (CONTRACT §5.4; названия ru/kk — из таблицы R08, не дублировать);
   свои таблицы кризисов с миграцией в той же SQLite; make_service(db_path) по CONTRACT §7; updates(device, since) для ленты
   R06 (обновления кризиса жителям зоны, на которую они подписаны или где их двор); seed_world из демо-мира R02 (до него —
   фикстура по §5.5).
2. Табло служб (GET agencies/board?days&district): по каждой службе — открытые, просроченные, медиана ответа (рабочие дни
   R09), доля «проверено жителями», «вернули жители», передачи из/в. Данные — функции R09 (части служб и передачи §5.1,
   только чтение); пока R09 не поставил — фикстура в формате §5.1. Метод расчёта — комментарием в коде и в DELIVERY.
3. Совместные (GET agencies/joint) и журнал передач (GET agencies/handoffs) — для сотрудника.
4. Кризисный штаб (incidents/*): создать кризис из шаблона (буран, авария теплосети, прорыв водопровода), зона — район,
   дворы или цели (без полигонов «от руки»), задачи по службам (чек-лист), обновления ru/kk (модерация R04), закрыть с итогом;
   публичная часть — баннер жителям зоны.
5. web/civic/agencies/ (window.BirgeAgencies.mount(root, {apiBase})): «Штаб ведомств» — вкладки «Табло · Совместные ·
   Передачи · Кризис»; строки как в Linear (ui-kit R11), полоса срока, сортировка, клик — список обращений службы (ссылка в
   «Обращения» R09 с фильтром — INTEGRATION); кризис — карточка, зона на карте мягко пульсирует (слой «Кризис» через
   registerLayer), чипы служб с прогрессом задач, лента обновлений. Кнопка «Открыть кризисный штаб» для пульса R08 — INTEGRATION.
6. Тесты: расчёт табло на фикстурах (крайние случаи: нет данных, одна служба, передачи по кругу), права (публичная часть
   кризиса без внутренних задач), браузер 1366 / 1024 / 375 × ru / kk; сцены 8 (табло) и 9 (кризис) проходят.
