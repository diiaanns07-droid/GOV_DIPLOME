Ты — роль R16 в проекте Birge (репозиторий GOV_DIPLOME). Основа — ветка пакета claude/clever-hypatia-q6ts4g (код FINAL-4),

Образцы устройства модуля: ui/civic_qa/ (R13 — свой сервис на той же SQLite, make_service) и ui/civic_feedback/v2/ (R09).

ЗАЧЕМ
Birge — «вместе». Сейчас житель говорит только с акиматом. Соседи по двору пишут об одном и том же поодиночке и не знают,
что многое могут сделать сами: субботник, посадка деревьев, расчистка снега, ремонт лавочек, помощь пожилым. Ты делаешь
место двора и инициативы, которые объединяют людей, а акимат их поддерживает.

ТВОИ ПУТИ: ui/civic_together/, web/civic/together/, tests/civic/R16/; research/round-15-results/R16/, свой handoff round15.

ЗАДАЧИ ПО ПОРЯДКУ
1. ui/civic_together/: свои таблицы (инициативы, «Я приду», члены дворов, отчёты) с собственной миграцией в той же SQLite
   (CIVIC_DB_PATH), make_service(db_path).handle(...) по CONTRACT §7; житель — заголовок X-Birge-Device; лимиты частоты;
   модерация текстов через ui.civic_ml_api.moderate (R04; нет функции — статус «на проверке» всегда); updates(device, since)
   для ленты R06 (CONTRACT §5.8); seed_world(db_path, records) из демо-мира R02 (до его выхода — своя фикстура по §5).
2. «Мой двор» — GET together/yards/{id}: название, район, соседей в Birge (число), проблемы двора (функции R09/R07, только
   чтение), идеи (R06), инициативы, работы рядом (R06/R12); «Я живу здесь» / «Больше не живу». Соседа нет — блок «пока нет
   данных», не ошибка. Двор по точке — API R12 /yard.
3. web/civic/together/ (window.BirgeTogether.mount(root, {apiBase, mode})): экран «Мой двор» — шапка (название, 3 числа:
   соседей · проблем · инициатив), вкладки «Обзор · Проблемы · Инициативы · Работы», лента событий двора, пустое состояние
   с иллюстрацией и кнопкой «Предложить дело для двора»; экран «Сделаем вместе» — список и карточки инициатив (как в App Store),
   счётчик «Я приду» с анимацией, «Поддержано акиматом», фото «после» и «Сделано вместе: N соседей».
4. Мастер инициативы (3 шага): что (вид и название) → где и когда (двор/место на карте, дата) → что взять; экран проверки
   «Это увидят все» и подсказка убрать личное; после — «на проверке». Похожая инициатива рядом (R04 similar_initiatives,
   если есть) → «Присоединиться к существующей».
5. Акимат: очередь модерации, «Поддержать» (инвентарь, вывоз мусора — служба waste), отметка «сделано» с отчётом.
6. Слой карты «Инициативы» через BirgeShell.registerLayer — выключен по умолчанию; значок — капсула ui-kit, не спорит с
   тепловой картой. Регистрация экранов — BirgeShell.registerScreen (место в меню — схема R11 IA_ROUND15).
7. Тесты: API (создание, модерация, «Я приду» один раз с устройства, лимиты, приватность — в ответах нет id устройств и
   времени вступления), браузер 375 / 1366 × ru / kk; сцена 7 демо проходит руками и скриптом.

ГОТОВО, КОГДА
- Сцена 7 «Двор вместе» проходит: «Мой двор» → инициатива → «Я приду» (14 → 15) → «Поддержать» → фото «после».
- Тексты ru/kk через ключи R11 (запасной текст в модуле), все состояния экранов, кадры 1366 / 1024 / 375.
