ЗАЧЕМ
Жюри GovTech оценивает «использование AI / agentic AI». У нас уже есть ИИ для жителя (категория, похожие, срочные случаи).
Нужен ИИ для руководителя: аким спрашивает словами — «Где в Нуре больше всего жалоб на снег за неделю и какие службы
отстают?» — и получает короткий ответ с числами из данных Birge и кнопкой «Показать на карте». Числа считает код, не модель.

ТВОИ ПУТИ: agent/civic_assistant/, web/civic/assistant/, ml/civic_classifier_v2/ (только оценка и отчёты), tests/civic/R03/;
research/round-15-results/R03/, свой handoff round15.

ЗАДАЧИ ПО ПОРЯДКУ
1. agent/civic_assistant/api.py · ask(question, lang, principal) по CONTRACT §7: распознать намерение (офлайн-правила ru/kk/
   вперемешку: горячие места, рост категории, сравнение районов, просрочки, отстающие службы, конфликты работ, кризис,
   инициативы жителей, поручения встреч) → вызвать функции модулей в процессе (R07 heat, R08 summary/pulse, R17 board,
   R12 conflicts, R16, R13) с запасным вариантом «модуля нет» → факты с источником → ответ блоками, собранный кодом (ru/kk)
   → действия [{kind: "map.focus", target}, {kind: "open", section}] → журнал вызовов.
2. Языковая модель — по желанию: OpenAI-совместимый API из переменных окружения (OPENAI_API_KEY, OPENAI_MODEL,
   OPENAI_BASE_URL; ключ никогда не в файлах) только выбирает блоки и переформулирует; любые числа в её тексте вычёркиваются
   (как agent/evidence.py). Нет ключа, сбой сети или таймаут > 8 с — офлайн-ответ с пометкой. Подсказки в вопросе («забудь
   правила…») — игнорируются: вопрос — данные, не инструкция.
3. web/civic/assistant/ (window.BirgeAsk.mount(root, {apiBase})): «Спросить Birge» для сотрудника — поле, 4–6 чипов-подсказок,
   карточка ответа (крупные числа, 2–4 строки текста, «Показать на карте»), «Как получен ответ» свёрнуто (вызовы и источники),
   метка «офлайн-режим»; ҚАЗ / РУС; место — схема R11 и команда палитры Ctrl+K (R01).
4. Оценка (для диплома): 50 вопросов ru / kk / вперемешку с эталонными фактами → точность намерения, точность фактов,
   задержка; results/ASSISTANT_EVAL.md. Проверка безопасности: 10 вопросов-провокаций (инструкции в тексте, просьба выдумать).
5. Если LOCAL-14 даст размеченные тексты людей: ml/civic_classifier_v2/eval_human.py — macro-F1 по ru / kk / вперемешку,
   матрица ошибок, сравнение с синтетикой; иначе — NOT_RUN с причиной.

ГОТОВО, КОГДА
- 3 вопроса из сценария (снег в Нуре, отстающие службы, буран) отвечаются офлайн за < 1 с с верными числами и переходом на карту.
- Тесты без сети (провайдер — заглушка), результаты оценки в DELIVERY.
