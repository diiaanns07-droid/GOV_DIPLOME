# K06, раунд 3 — корректные метрики интервалов автобусов (Астана)

Город: **Астана**. Данные: 3 маршрута (10, 12, 46, оператор CTS), исторический период 2024-07-29 — 2024-09-21.
Источник: Mansurova et al., Zenodo 15769359, через зеркало `Mrithula742/Bussure` @ `0356bb5`; лицензия CC BY 4.0 только по README зеркала.
Статус чисел: derived из реальных исторических наблюдений (старты рейсов восстановлены авторами по GPS). Шымкенту не приписывать.

## Файлы
- `headway_calc.py` — вычислитель (stdlib). Ключи: маршрут, направление, дата обслуживания, окно `[начало, конец)`.
  Правила R1–R6: дубли, почти-дубли < 60 с, разрывы > 3 ч, полночь (≥ 24:00 остаётся в дате; конец < начала → +24 ч),
  границы наблюдения (приход до первого/после последнего отправления дня не считается, даты не связываются),
  неполные даты (< 0,5 медианы) исключаются. Всё считается в `counters`/`excluded_days`.
- `test_headway_calc.py` — 11 тестов: ручной пример двух дней, обрезка окном, полночь, разрыв, границы, неполная дата.
- `make_report.py` → `report.html` — сравнение методов, разложение ожидания, длительность рейса с пометкой «включая отстой, не пробка».
- `out/headways.json` (по датам и сводка), `out/summary.csv` (сводка).

## Методы (на маршрут × направление × окно × тип дня)
| Метод | Что это |
|---|---|
| PTAL | H/2 + 2 мин |
| Объединение формулой (AST-A06) | H/2·(1+CV²) по интервалам всех дат; равно Σh²/(2Σh) |
| Медиана дневных | медиана H_d/2·(1+CV_d²); «типичный день», **не ожидание пассажира** |
| Среднее дней | каждая дата с весом 1 |
| Взвешенное по времени (рекомендовано) | Σ∫ожидание dt / Σ покрытое время: пассажир приходит в случайный момент наблюдённого обслуживания |
| Разложение | рекомендованное − H/2 = между днями + внутри дня |

Допущения формулы ожидания: равномерно случайный приход без знания расписания/табло, посадка в первый автобус,
интервал на старте рейса переносится на остановку. Это оценка сверху, не прогноз.

## Результат на реальном входе (будни, 24 комбинации)
- Вклад различий между днями: 0,0–2,1 мин (медиана 0,6). Вклад нерегулярности внутри дня: 1,7–9,3 мин (медиана 4,8).
- Объединение формулой отличается от рекомендованного не более чем на 1,9 мин (будни): эффект отнесения интервала к окну по началу.
- Медиана дневных ожиданий ниже рекомендованного на 0,4–7,2 мин (медиана 1,9).
- Рекомендованное ожидание выше PTAL в 23 из 24 комбинаций.
- Очистка: 546 точных дублей, 789 почти-дублей, 11 разрывов > 3 ч, 20 неполных дат исключено.

## Поправки к прежним выводам
1. **AST-A06 F011/F018.** CV 0,56–1,08 — CV объединённой выборки; как мера регулярности одного дня он завышен
   (медиана дневного CV ниже, например 12/1/16–19: 0,91 → 0,50). Оценка ожидания объединением при этом близка к
   корректной, потому что формула на объединении равна взвешенному по времени среднему дневных ожиданий.
2. **AST-A06 таблица 7.2.** «В салоне + трафик» → «длительность рейса, включая отстой; не пробка».
3. **K06 next-round, K06-F009 — отменяется.** «Избыток 1,4–7,8 мин» получен смешением среднего H из объединения с
   медианой дневного CV; это несогласованно и занижает ожидание. Вывод «объединение дней раздувает избыток ожидания»
   неверен: раздувается CV, но не ожидание. Корректно — рекомендованный метод и разложение из `report.html`.
