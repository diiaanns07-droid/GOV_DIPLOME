# K10, раунд 3: компактный геопакет двух городов

Для каждого города сюда входит один небольшой участок (квадрат 2×2 км). По нему лежит полный результат заданного запроса к Overture Maps, выпуск `2026-09-23.1`:
- **соцобъекты** — точки внутри квадрата, отобранные по правилу K10;
- **сегменты** — все сегменты транспортной сети, геометрия которых пересекает квадрат;
- **соединители** — все соединители (connectors), на которые ссылаются эти сегменты.

«Полный» здесь означает полный ответ на этот запрос, а **не полный реестр города**.

## Что это и чем не является

- **Вид данных:** `observed_secondary` — вторичные открытые данные. Геометрия и классы дорог взяты из OpenStreetMap, места — из агрегата Overture (Meta, Microsoft, Foursquare, AllThePlaces и др.).
- **Это не официальный реестр.** Пакет не содержит официального состава районов, мощностей школ или населения.
- **Соцобъекты** выбраны правилом K10 поверх таксономии Overture (`scripts/k10_rules.py: social_group`). Это производная классификация.
- **Пешеходная проходимость не установлена.** У сегмента есть поле `k10_foot_access` со значениями:
  - `denied` — явный запрет для пешеходов или для всех режимов;
  - `allowed` — явное разрешение с `mode: foot`;
  - `conditional` — есть правила с условиями;
  - `unknown` — правил нет. **Отсутствие тега не означает разрешения.**

  Если сегмент `unknown`, заявления о реальной проходимости им не подкрепляются. Это лишь «связь в графе OSM».
- **Связность строится только по `connector_id`.** Соседние соединители одного сегмента образуют ребро; сегменты, имеющие общий `connector_id`, соединены. Пересечение линий без общего соединителя (эстакада над дорогой, тоннель) связью **не является**. Строить граф пересечением геометрий нельзя.
- **Объекты на краю квадрата.**
  - Сегменты, пересекающие границу, сохранены целиком, у них `k10_crosses_bbox_edge = true`.
  - Их соединители вне квадрата — с `k10_inside_bbox = false`.
  - Граф обрезан по краю. Объект у границы может быть достижим по пути через внешнюю территорию, поэтому «недостижим» у края заявлять нельзя.
  - Число мест ближе 100 м к краю приводится в отчёте проверки.
- **Направления.** Ограничения с `heading` (forward/backward) сохранены в `access_restrictions`. Для пешеходов они обычно не применяются, но это не проверялось.

## Структура

| Путь | Что |
|---|---|
| `selection/<city>_bbox_selection.json` | правило выбора квадрата, сетка, топ-5 ячеек, SHA входов |
| `selection/select_bbox.py` | выбор квадрата (shapely), использует закоммиченный полигон города раунда 2 и сырую выгрузку мест раунда 2 |
| `selection/crosscheck_round2.py` | независимая сверка ID с выгрузками раунда 2 (нужны сырые файлы) |
| `data/<city>/places_social.geojson` | соцобъекты в квадрате |
| `data/<city>/segments.geojson` | сегменты, пересекающие квадрат, полная геометрия и все поля пригодности |
| `data/<city>/connectors.geojson` | все соединители, на которые ссылаются сегменты |
| `package_manifest.json` | выпуск, S3-ключи и row groups, колонки, запросы, SHA256, байты и число объектов в каждом файле |
| `scripts/download.py` | **сеть**: пересобирает `data/` и манифест (pyarrow, shapely, requests; см. `scripts/requirements-download.txt`) |
| `scripts/offline_check.py` | **без сети**, только stdlib: проверка закоммиченных файлов |
| `tests/test_package.py`, `tests/expected_counts.json` | контрольные количества, дубликаты, ссылочная целостность, связность, край, подмена байта |
| `results/` | отчёты проверок и доказательство запуска на чистом клоне |
| `INPUT_FOR_K07.md` | точные пути и команды для K07 |

## Команды

```bash
# офлайн-проверка (только Python 3 stdlib, сеть блокируется внутри)
python3 research/round-3-results/K10/scripts/offline_check.py
cd research/round-3-results/K10 && python3 -m unittest discover -s tests -v

# пересборка из сети (не нужна для использования пакета)
pip install -r research/round-3-results/K10/scripts/requirements-download.txt
python3 research/round-3-results/K10/scripts/download.py
```
