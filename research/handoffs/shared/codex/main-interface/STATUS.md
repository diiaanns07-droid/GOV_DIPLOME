# Перенос в исходный светлый интерфейс

Ветка: `codex/govtech-main-interface`. Вход BUILD: `d18847f9e7c18fcfae3349c0b223b023d359a838`.
Пользователь явно потребовал сохранить первоначальный светлый дизайн и 3D, затем разрешил перенос новых возможностей в него.

Реализовано:

- Основной `run.bat` / порт 8501 открывает исходный симулятор с переключателем «Городское планирование».
- Одна существующая MapLibre-карта: участки Шымкента/Астаны, исходные объекты, проектные точки, линии расстояний и условные исключения.
- План, три оптимума, Парето, бюджет, устойчивость, JSON/HTML, источники/QA в отдельных вкладках нового режима.
- Старые учебные данные/движок/состояние проекта не заменяются данными среза. Возврат восстанавливает камеру и скрывает слои нового режима.
- Данные и расчёты закреплены хэшами. Адаптация UI: свёрнутые пояснения, корректная подсказка Enter, понятный отказ импорта вместо undefined.

Проверка на Windows:

- Исходные 112 pytest-тестов PASS (с отдельным basetemp внутри .venv: системный pytest temp был недоступен в sandbox).
- HTTP ui.web_check: 14 PASS, включая ресурсы страницы и защиту закрытых путей.
- Node: plan 164 PASS, resilience 112 PASS, whatif 71 PASS — против независимых expected JSON; пути адаптированы к основной сборке.
- Браузер: демо → 256 наборов / 49 допустимых → применение; устойчивость после условного исключения; оба города; смена города сбрасывает случаи; импорт synthetic файла Астаны из режима Шымкента; неверный файл не меняет город/случаи; возврат показывает исходные 52.56 и скрывает новые слои.
- Клавиатурная постановка точки: Enter — центр участка; Escape — остановка. Исправлено позиционирование поверх canvas и кадрирование после resize.
- Визуальная проверка на 390 и 1440 px; один canvas. Полная проверка всех сочетаний браузера/скринридера не выполнялась.
- Экспорт JSON: UI подтвердил сохранение; событие скачивания в Browser-инструменте не завершилось (timeout), фактический файл на диске через этот инструмент не подтверждён. Сериализация/импорт проверены Node и импортом fixture через UI.

Ограничения прежние: два небольших среза, не целые города; условные бюджеты; расстояния по прямой; объяснения шаблонные. Подложка/3D-здания требуют сети OpenFreeMap.
