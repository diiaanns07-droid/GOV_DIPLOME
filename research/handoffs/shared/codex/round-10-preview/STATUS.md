## Ошибка переноса строк на Windows

Первая распаковка git archive преобразовала LF в CRLF в 63 файлах. Браузер отклонил подготовленный кейс по SHA-256 и показал fallback с 25 точками.
Все 99 файлов приложения/тестов восстановлены побайтно через git show из закреплённого SHA, с проверкой, что различались только окончания строк. Манифесты не изменялись и проверка хэшей не отключалась.
В координаторской .gitattributes добавлены `web/govtech/school/cases/** -text` и `web/govtech/k03/** -text`, аналогично прежнему pinned core. Этот небольшой fix нужно перенести в последующую интеграцию/BUILD: в ветке сборщика его пока нет.
