1. ЗАПУСК
Нужен только Python 3 (python.org). Интернет, ключи и установка пакетов не нужны.

Windows (не проверялось автором — проверено только в Linux):
  - двойной щелчок по prototypes\city-evidence\run-demo.bat
    (откроет браузер на http://127.0.0.1:8765/; окно консоли не закрывать до конца показа);
  - или в консоли:  cd prototypes\city-evidence  →  py -3 serve.py 8765 --open
Linux / macOS:
  cd prototypes/city-evidence
  python3 serve.py 8765 --open        (или просто python3 serve.py и открыть http://127.0.0.1:8765/)
Без сервера: открыть файл prototypes/city-evidence/web/index.html в браузере.
Остановить сервер: Ctrl+C.

Проверка перед показом (по желанию, ~10 с): python3 tools/check_all.py → «0 failed»
(без shapely одна строка SKIP — это нормально).

3. ЧТО РЕАЛЬНО ПОКАЗАНО
- Реальные вторичные данные Overture 2026-09-23.1 (OSM, Meta, Foursquare, TomTom) по двум квадратам,
  с хэшами и атрибуцией по записям; 55 + 65 записей соцобъектов, 1 084 + 1 326 сегментов дорог.
- Районы по правилу K03 (v2.1 копия): неоднозначный район не присваивается; привязка проверяется
  на актуальность (check_evidence_fresh) и в браузере (evidence.js другой версии → предупреждение).
- Контракт данных k05-obs-v1.2+k12r4+k05r5: строгий JSON, «неизвестно» ≠ 0, счётчики целые ≥ 0;
  неверный вход отклоняется до записи файлов.
- QA: совпадающие координаты, возможные дубликаты, сомнение в категории — по воспроизводимым правилам.
- Шаблонное объяснение: числа только из каталога фактов, старый ответ отклоняется по отпечатку каталога.

4. ЧЕГО ПОКА НЕТ (говорить прямо)
- Не весь город: два квадрата ~2×2 км, выбраны по числу объектов — не выборка и не сравнение городов.
- Нет официального реестра, мощностей школ, численности детей; районы юридически не проверены.
- Нет пешеходной доступности и маршрутов: права прохода у большинства дорог неизвестны.
- Нет LLM: объяснение — шаблон; казахские подписи — черновик.
- Не проверено на Windows; не проверено средством чтения экрана.
- Открытое замечание K10 (низкое): флаг группы координат передаётся в evidence.js, а не в data.js.
- K08 F5: у 26 источников Астаны ссылка на колонку routes, которой нет в сохранённом пакете.
