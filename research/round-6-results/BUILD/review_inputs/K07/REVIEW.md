## Как запустить тест на другой версии

```bash
# извлечь нужный коммит BUILD (побайтно, со сверкой SHA-256) и проверить
python3 research/round-5-results/K07/scripts/extract_build.py /tmp/ce-new --sha <NEW_SHA>
node research/round-5-results/K07/tests/k07r5_regressions.cjs --app-root /tmp/ce-new --label build-new --sha <NEW_SHA>
# или по адресу работающего сервера (python3 serve.py)
node research/round-5-results/K07/tests/k07r5_regressions.cjs --url http://127.0.0.1:8765/ --label served --sha <NEW_SHA>
# всё сразу (baseline, baseline+patch, тесты сборщика на копии с патчем)
bash research/round-5-results/K07/scripts/run_review.sh            # или: run_review.sh <NEW_SHA>
```

У каждой проверки в `result.json` есть поле `baseline_expectation`; оно относится **только** к `0bf27de`. Раздел `vs_baseline_expectation` делит провалы на ожидаемые и неожиданные. Провал на другой версии — дефект этой версии только при запуске на ней (поле `sha`).

Применение патча (решает сборщик):

```bash
git apply --check -p1 research/round-5-results/K07/patch/city_evidence_web.patch
git apply -p1 research/round-5-results/K07/patch/city_evidence_web.patch   # меняет web/index.html, web/app.js, web/facts.js
```

Патч проверен на чистом извлечении `0bf27de`: `git apply --check` прошёл, SHA-256 трёх изменённых файлов совпали с проверенной копией. `data.js` и `evidence.js` не меняются.

## Не проверено

- Режим `--url` на работающем `serve.py`. Перехват запросов для повреждённых входов в этом режиме использует `route.fetch()`; реализован, но не запускался.
- Браузеры, кроме Chromium (Playwright 1.56.1); сенсорный ввод (390 px — только эмуляция ширины); средство чтения с экрана; forced-colors; печать.
- Тёмная тема в этих сценариях.

## Остаточные замечания (патч их не касается)

- На 390 px кнопки масштаба закрывают конец подписи «Квадрат K10 (…) — не весь город».
- Дороги в патче недоступны с клавиатуры. Лучше было бы перемещаться по карте стрелками между объектами, но это больше, чем точечная правка.
- Подсказка появляется только при наведении. С клавиатуры те же сведения открываются карточкой по Enter, так что доступ к ним подсказкой не ограничен.

Данные во всех проверках — срез K10 (два квадрата ~2×2 км, Overture 2026-09-23.1), а не реестр города. Повреждённые входы подставлялись перехватом запросов; синтетических городских данных нет.
