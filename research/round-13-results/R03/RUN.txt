R03 · раунд 13 — как запустить и проверить (из корня репозитория, ветка claude/zen-mendel-e79iiv)
Нужны: python3 (stdlib), Node 22, Playwright 1.56 + Chromium (локально или `npm root -g`). Без Playwright браузерные
проверки пропускаются и считаются NOT_RUN. Все проверки работают на временных БД и ничего не пишут в репозиторий.

1. ПРОВЕРКИ МОДУЛЯ
   node --test tests/civic/R03/core.test.mjs
   node --test --test-concurrency=1 tests/civic/R03/browser.test.mjs
       стенд с mock API; тесты раунда 13 называются «r13: …» (камера хоста, отмена отложенного перелёта,
       редактор забирает ввод, смена стиля + 3D, onDetail)
   node --test --test-concurrency=1 tests/civic/R03/r02_readonly.test.mjs     (R02 раунда 11, 6a28de2)
   node --test --test-concurrency=1 tests/civic/R03/r02_contract.test.mjs     (R02 раунда 12, bd7a911; R03_R02_SHA=<sha>
       чтобы взять другой коммит R02; код R02 достаётся через git archive во временную папку)

2. ПРИЁМКА НА НАСТОЯЩЕМ ПРИЛОЖЕНИИ (app.py + оболочка R01 + R02 + редактор R04)
   NODE_PATH=$(npm root -g) node tests/civic/R03/app_acceptance.mjs /tmp/r03-acc
   -> /tmp/r03-acc/acceptance.json (PASS/FAIL/NOT_RUN) и скриншоты. Редактор создаётся через CLI R02 со случайным
   паролем через stdin; пароль нигде не сохраняется.
   Общий сценарий R01: NODE_PATH=$(npm root -g) node tests/civic/R01/browser/p0_flow.cjs /tmp/r03-p0

3. ПРИЛОЖЕНИЕ РУКАМИ (Windows: run-city.bat, http://127.0.0.1:8611/). run-city.bat прочитан: PORT=8611,
   CIVIC_DEMO=1 -> run.bat делает `ui.civic_store init` и `seed-demo` синтетического среза в отдельную БД, затем
   app.py. Эквивалент в облаке (без venv/pip — нужен только stdlib), на временной БД:
   DB=$(mktemp -d)/civic.sqlite3
   CIVIC_DB_PATH=$DB python3 -B -m ui.civic_store --db "$DB" init
   CIVIC_DB_PATH=$DB python3 -B -m ui.civic_store --db "$DB" seed-demo --package data/civic/astana/demo_synthetic.json
   CIVIC_DB_PATH=$DB python3 -B app.py --host 127.0.0.1 --port 8611   ->  http://127.0.0.1:8611/
   (OpenFreeMap в облачной среде заблокирован: видна офлайн-подложка R01, 3D-здания не загружаются — NOT_RUN.)

4. ЧТО ТЕПЕРЬ МОЖЕТ ПОЛЬЗОВАТЕЛЬ
   Житель: свободно двигает карту — список не перезагружается с сервера при каждом движении; выбирает улицу или
   район — модуль дожидается, пока камера долетит, и честно говорит «в видимой части нет опубликованных записей,
   это не значит, что работ нет»; открывает карточку (сейчас / когда закончат / перенос и причина / кто отвечает
   и стоимость только по источнику / откуда сведения); ссылка #object= открывает ту же карточку после
   перезагрузки, а снятая с публикации — «Объект не найден … сняли с публикации»; в одной точке нескольких
   объектов — список выбора (для одинаковых координат без ложного «приблизьте карту»); в 3D выбор и перелёты
   сохраняют наклон.
   Сотрудник: пока в кабинете R04 ставит точку или рисует линию/область, щелчки по публичным объектам не
   открывают их карточки, не меняют адрес и не сбивают перекрестие; после «Отмена»/Esc карта снова отвечает.
   Хост (R01): может передать свою свободную область и задуманный наклон, и модуль сам кладёт объект туда,
   не перебивая перелёт к выбранной улице.
