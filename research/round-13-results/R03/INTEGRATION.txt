2. КАМЕРА ХОСТА (вместо подмены map.fitBounds в R01)
   options.getPadding() -> {top,right,bottom,left}; options.getPitch() -> 0..85; options.getBearing() -> -360..360.
   Вызываются прямо перед каждым программным движением камеры модуля и при измерении «видимой части карты».
   Неверное значение (не объект, NaN, отрицательное, исключение) игнорируется целиком, одно предупреждение в консоль.
   Модуль не перелетает поверх чужого движения: любой movestart без eventData {civicR03:true} (жест жителя,
   fitBounds хоста к улице/району) отменяет отложенные перелёты модуля и поздний fitOnLoad.
   options.onDetail(obj) — НОВОЕ: замороженная публичная копия загруженной карточки (с геометрией) — для ссылки
   #object=, открытой раньше списка; onSelect при этом пришёл только с {id}. Повторного onSelect нет (R01 закрывает
   по нему форму обращения).

3. ВЛАДЕНИЕ ВВОДОМ КАРТЫ (R04 редактор, R07 симулятор)
   handle.setInteractionEnabled(enabled, owner="host") -> boolean. Ввод публичной карты включён, только когда ни
   один владелец его не держит. Пока выключен: нет выбора по щелчку, нет списка «Здесь N объектов», нет onSelect
   (значит, R01 не меняет #object=), нет подсказки, курсор остаётся у владельца (перекрестие R04).
   Встроенно слушается document: "civic-editor:tool" (R04, уже отправляет {active, mode}) и "civic-scenarios:tool"
   (ПРЕДЛОЖЕНИЕ для R07, та же форма {active:boolean, mode?}). Опция inputEvents:false отключает встроенную
   подписку, если хост хочет решать сам и вызывать API.
   Возврат: active:false; destroy(); страховка — владелец, чей элемент удалён из DOM без active:false (кабинет
   закрыт/упал во время рисования), снимается при следующем вводе на карте. Слушатели не множатся (проверено
   тремя повторными mount/destroy).
   R04: менять ничего не нужно. R01: менять ничего не нужно (его слушатель S.editorTool можно оставить).
   R07: если симулятор берёт щелчки по карте — отправлять "civic-scenarios:tool" {active:true/false} с корня
   своего модуля (всплывающее) или вызывать handle.setInteractionEnabled(false/true, "civic-scenarios").
