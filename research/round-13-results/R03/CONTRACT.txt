R03 · раунд 13 · КОНТРАКТ (зафиксирован до реализации) — камера хоста и владение вводом карты
Модуль: window.CivicMap.mount(options) -> handle (web/civic/map/civic-map.js). Всё ниже — НЕОБЯЗАТЕЛЬНОЕ
дополнение civic-v1-mount: без новых опций и вызовов поведение прежнее (раунд 12, b83df89).

А. КАМЕРА: getPadding / getPitch / getBearing (опции mount)
  getPadding() -> {top, right, bottom, left}   пиксели свободной части карты, которую хост НЕ закрывает
                                                (шапка, блок навигации, лист/панель, ящики редактора/симулятора).
  getPitch()   -> number (0..85)               задуманный хостом наклон (3D) — вместо map.getPitch() посреди анимации.
  getBearing() -> number (-180..180)           задуманный поворот.
  Когда вызываются: синхронно, прямо перед КАЖДЫМ программным движением камеры модуля (выбор из списка/по API,
    перелёт после загрузки карточки по ссылке, «Приблизить все» в выборе, fitAll(), сдвиг точки из-под листа
    после щелчка по карте) и при измерении «видимой части карты» (фильтр «видимая часть»). На телефоне — после
    того, как лист модуля закончил анимацию (≈320 мс), т.е. при актуальной раскладке.
  Проверка: результат должен быть объектом с четырьмя конечными числами >= 0 (getPitch/getBearing — конечное
    число в диапазоне). Иначе (исключение, NaN, отрицательное, не тот тип) значение игнорируется целиком,
    используется собственный расчёт модуля, в консоль — одно предупреждение на экземпляр.
  Ограничение: если сумма отступов не оставляет карте хотя бы 60 px по ширине/высоте (низкий экран, телефон
    в альбомной ориентации), отступы пропорционально уменьшаются — камера не «ломается» о нулевую область.
  Приоритет: getPadding() > options.mapPadding (статический, как раньше) > собственный расчёт (панель/лист).

Б. НЕ ПЕРЕБИВАТЬ ЧУЖОЙ ПЕРЕЛЁТ («житель не теряет выбранную улицу»)
  Свои движения камеры модуль помечает eventData {civicR03: true}. Любое другое начало движения (жест жителя
  или fitBounds/flyTo хоста, например к улице/району) отменяет ещё не выполненные отложенные движения модуля
  (перелёт к карточке после анимации листа, перелёт после загрузки карточки по ссылке, сдвиг точки после
  выбора на карте) и запрещает поздний автоматический fitOnLoad. Уже начатое движение модуля MapLibre сам
  прерывает новым движением хоста. Модуль никогда не делает второй автоматический перелёт поверх перелёта хоста.

В. ВЛАДЕНИЕ ВВОДОМ КАРТЫ (общая граница с R04 редактором и R07 симулятором)
  handle.setInteractionEnabled(enabled: boolean, owner?: string = "host") -> boolean (итог: включено ли)
    Модуль хранит множество владельцев, которые сейчас забрали ввод. Публичный ввод карты ВКЛЮЧЁН, только
    когда множество пусто. Вызов идемпотентен для одного владельца; разные владельцы не мешают друг другу
    (редактор закончил рисовать, а симулятор ещё выбирает — ввод остаётся у симулятора).
  Пока ввод выключен, модуль на карте НЕ: выбирает объект по щелчку/касанию, открывает выбор среди
    перекрывающихся, вызывает onSelect (значит, R01 не меняет #object=), показывает подсказку при наведении,
    меняет курсор (курсор принадлежит владельцу ввода; модуль сбрасывает лишь свой флаг, не стиль), не
    сдвигает камеру из-за щелчка. Список, карточка, фильтры, клавиатура в панели модуля работают как обычно;
    текущее выделение не меняется.
  handle.getState().interaction = {enabled: boolean, owners: string[]}.
  Встроенная подписка (можно выключить опцией inputEvents:false, если хост сам вызывает API):
    document, всплывающее "civic-editor:tool"    detail {active:boolean, mode?}   -> владелец "civic-editor" (R04, уже есть)
    document, всплывающее "civic-scenarios:tool" detail {active:boolean, mode?}   -> владелец "civic-scenarios" (предложение R07)
  Возврат управления: active:false; destroy() модуля (снимает всё и забывает владельцев); и страховка —
    если элемент, отправивший active:true, удалён из DOM (кабинет закрыт/упал без active:false), владелец
    снимается при следующем вводе на карте. Слушатели вешаются один раз на экземпляр и снимаются в destroy;
    повторные mount/destroy их не умножают.
