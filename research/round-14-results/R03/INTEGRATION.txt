Код:
    from ml.civic_classifier_v2.predict import ModelUnavailable, get_default
    try:
        clf = get_default()          # загрузить при старте сервера (~1–2 с), не в первом запросе
        res = clf.classify(text)     # {category, score, needs_review, model_version, top3:[{category, score}]}
    except ModelUnavailable:

- Модель: папка ml/civic_classifier_v2/artifacts/onnx/ (model.int8.onnx ≈ 266 МБ, tokenizer.json, birge_meta.json)
  после RUN.txt шаг 8 на ноутбуке; другой путь — переменная окружения BIRGE_CLF_V2_DIR.
- Пакеты на сервере: ml/civic_classifier_v2/requirements-runtime.txt (onnxruntime, tokenizers, numpy). torch не нужен.
- get_default(): при одновременных первых запросах без модели все потоки получают ModelUnavailable (исправлена гонка,
  раньше второй поток мог получить KeyError). В режиме auto, если onnxruntime/токенизатор недоступны, загрузка
  переходит к PyTorch-папке (artifacts/final), а не падает.
- Потоки: predict по умолчанию берёт min(4, ядер) потоков onnxruntime (переменная BIRGE_CLF_V2_THREADS меняет число).
  Не ставить «все потоки»: на ноутбуке владельца (24 потока, гибридный Intel) это 103 мс на текст, 4 потока — 21–23 мс.
  Один поток — 76–92 мс на ноутбуке, 58 мс в облаке при 128 токенах.
- Модель: итоговая civic-clf-v2-xlm-roberta-base-synth_all-daaa6dae4-s20261011 (только синтетика, probe_v2 0.828,
  needs_review всегда true). Брать artifacts/onnx ПОСЛЕ повторного экспорта (RUN.txt шаг 8, per-channel). До этого —
  artifacts/onnx_per_channel из диагностики Codex (BIRGE_CLF_V2_DIR указать на неё).
- Потокобезопасно: сессия onnxruntime и tokenizers можно вызывать из нескольких потоков; объект один на процесс.
  Нагрузка (bench.py, облако 4 vCPU, модель того же размера): 5000 знаков — 35–37 мс; 8 одновременных запросов —
  2300–2900 в минуту, p95 одного запроса до 290 мс; память процесса ≈ 510 МБ. Очередь или пул не нужны.
- Текст > 5000 символов обрезается, токенов ≤ 128; пусто/меньше 3 букв -> {"category":"other","score":0.0,
  "needs_review":true,"top3":[]} без вызова модели. Не строка -> TypeError (вернуть 400).
- needs_review — для сотрудника, не для жителя. Пока модель без проверки на людях — всегда true.
- suggest (R04: не other и score ≥ v2.threshold = 0.3): на probe_v2 у логрегрессии при 0.3 предвыбор у 88 % текстов
  с точностью 81 %, при 0.7 — 75 % и 89 % (results/ERROR_ANALYSIS.md, раздел 6). Для трансформера таблица появится
  после утреннего шага 8б. Если R09 нужен более осторожный предвыбор — порог в R04 можно поднять (решение R04/R09).
- Категории — id из research/round-14/categories_v2.json; модель отказывается загружаться, если список изменился.
- Входной текст можно предварительно обезличить ml.labeling.anonymize (R02): модель видела маркеры [телефон], [адрес].
