Как применить (из корня рабочей копии сборки R01):
  git fetch origin claude/r14-R15
  for p in P-R01 P-R09 P-R07 P-R04 P-R02; do
      git show origin/claude/r14-R15:research/round-14-results/R15/patches/$p.diff | git apply --check - && \
      git show origin/claude/r14-R15:research/round-14-results/R15/patches/$p.diff | git apply -
  done
  # проверка: тесты R15 должны стать XPASS (strict -> «failed» с пометкой XPASS) — значит, исправлено
  git checkout origin/claude/r14-R15 -- tests/civic/R15
  python -m pytest tests/civic/R15 -q -rxX
  # затем R01 переносит ID в FIXED (tests/civic/R15/r15_common.py) и снимает xfail — или пишет R15, сделаю я.

Порядок не важен: patch не пересекаются по строкам. Каждый можно применить отдельно (P-R09 без P-R01 работает:
без подключения из P-R01 R09 просто не сохраняет подписи жителя, а цель не сверяет с картой).

P-R01  ui/web_server.py  (R01)
--------------------------------------------------------------------------------
S01  Строгая CSP для HTML (send_bytes -> csp_for_html):
     default-src 'self'; script-src 'self' + sha256 встроенных <script> (ui-kit/index.html, akim/index.html);
     style-src 'self' 'unsafe-inline'; img-src 'self' data: blob: https://tiles.openfreemap.org; font-src 'self' data:;
     connect-src 'self' https://tiles.openfreemap.org; worker-src 'self' blob:; child-src 'self' blob:;
     object-src 'none'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'.
     Хэши считаются при отдаче страницы: правка встроенного скрипта не ломает CSP. Ответы JSON — как раньше.
     Если R01 добавит внешний источник подложки — дописать его в CSP_TILES.
S02  Лимиты API v2 по адресу клиента (CivicV2Gateway._rate_limited, класс RateLimiter, таблица V2_RATE_LIMITS):
       complaints.create  5 в минуту и 30 в час;   classify, similar  60 в минуту;
       complaints.metoo   30 в минуту и 20 в сутки на одну жалобу;   proposals.vote  20 в сутки на одно предложение.
     Ответ 429 {"error":"too_many_requests","retry_after":N} + заголовок Retry-After.
     Для тестов ролей, которым нужен «залп» с 127.0.0.1: CivicV2Gateway(..., rate_limits=None).
     Прогон tests/ (2430) с лимитами — ни одного нового падения.
S08  (владельцы R06/R09) — тот же механизм: «20 в сутки на одну цель с одного адреса».
S10  Handler.log_request: в журнал — метод и путь без строки запроса (точки жителя, device_id).
S04/S12 (подключение для P-R09): в wire() — store.target_lookup = engine.civic_geo.target_geometry.

P-R09  ui/civic_feedback/v2  (R09)
--------------------------------------------------------------------------------
S03  record.public_view: точка — 3 знака (PUBLIC_POINT_DIGITS); author_view — точная точка (автор видит своё место).
     R07 берёт записи из store.list (полные), карта не меняется.
S04  record.checked_target: подписи цели — только с карты R12 (lookup), подписи из запроса жителя не сохраняются.

S05  api._require_staff: нет principal.check_csrf -> 403 csrf_failed (а не пропуск проверки).

для жителя подписи не меняются; демо-путь B1/B2 в браузере со всеми patch — PASS.

P-R04  ui/civic_ml_api/similar_search.py  (R04)
--------------------------------------------------------------------------------
S13  similar(): чужие жалобы ищутся и меряются от огрублённой точки (3 знака, как публичная выдача R09).
     bbox предварительного отбора расширен на COARSE_MARGIN_M = 70 м (огрубление сдвигает точку до ~66 м).
     Почему не «огрубить distance_m»: точку запроса можно двигать, пока ступень расстояния или граница радиуса
     200 м не переключится, — это снова даёт точную окружность. Тест R15 это различает.
     Интерфейс R09 distance_m из /similar не показывает (complaint.js показывает расстояние из R12 /targets).

P-R02  ml/labeling  (R02)
--------------------------------------------------------------------------------
S07  anonymize.py: ФИО с отчеством (…вич/…вна/…ична/…ұлы/…улы/…қызы/…кызы, 1–2 слова с большой буквы перед ним)

     Вне кода (владельцу): в форме согласия прямо написать, что тексты без имён и телефонов могут обрабатываться
     внешним сервисом ИИ за пределами РК, — или не запускать llm_label на настоящих текстах.
