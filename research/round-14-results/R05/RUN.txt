R05 · раунд 14 · 3D-превью предложений — как запустить и что можно сделать (поставка 2)

1. ДЕМО БЕЗ ИНТЕРНЕТА (сразу, без сборки R01)
   Из корня репозитория:
     Windows:  py -m http.server 8765 -d web
     Linux/Mac: python3 -m http.server 8765 -d web
   Открыть: http://127.0.0.1:8765/civic/build3d/demo.html
   Подложка — настоящие улицы и дворы OSM фокус-области Нуры (без зданий: LOCAL-R05-3). Камера сразу у проектов
   (масштаб 17.4). Полезные параметры адреса:
     ?lang=kk                казахский (или кнопки ҚАЗ / РУС в шапке; выбор запоминается)
     ?role=resident          вид жителя (только просмотр и голос; подсказка «Нажмите на проект, чтобы проголосовать»)
     ?pitch=0 | ?pitch=60    наклон; ?bearing=-20 поворот; ?zoom=17.5; ?center=71.4008,51.1272 (без center — к проектам)
     ?reset=1                стереть поставленное на этом устройстве (вернутся 4 примера)
     ?store=local            не спрашивать сервер предложений (для статического сервера это и так происходит)
     ?r06=1                  подключить карточку R06 (/civic/proposals/proposals.js) — нужен сервер R06 (п. 3)

2. ЧТО МОЖЕТ СДЕЛАТЬ ПОЛЬЗОВАТЕЛЬ
   Акимат (ноутбук 1366 px):
   - внизу «Что построить?» — 5 карточек: Сквер, Детская площадка, Спортплощадка, Остановка, Освещение улицы;
     выбор карточки плавно приближает карту до 17.5, если она дальше;
   - полупрозрачный зелёный «призрак» идёт за курсором; щелчок по карте ставит его в точку;
   - ↺ / ↻ (или клавиша R, Shift+R) — поворот на 15°; остановка сама встаёт вдоль ближайшей улицы;
   - «Поставить» → объект вырастает снизу вверх за ~1.2 с → табличка «Проект · 2027»; тост «Проект поставлен» с
     «Отменить» (закрывается сам через 6 с, при открытии карточки и при переходе в «Житель»);
   - освещение: щелчок по улице — начало участка, второй щелчок по той же улице — конец; «улица Сыганак, 187 м ·
     7 фонарей»; в Нуре — без сервера, по всему городу — через маршруты улиц R12 (в сборке R01 или на стенде п. 3);
   - «Рядом уже есть остановка: «БЦ Саад», 60 м · по данным OpenStreetMap»; объект во дворе — «Двор: Evolution»;
   - нельзя поставить поверх другого проекта и за пределами Астаны — красная подсказка, «Поставить» неактивна;
   - щелчок по самой модели или по табличке → карточка (справа на ноутбуке, снизу на телефоне); камера сдвигает
     объект так, чтобы он был виден рядом с карточкой; «За · N», «Против · M», «Удалить» (после — «Отменить»);
     с сервером R06 — карточка R06 (у акимата голоса числами и «Одобрить / Отклонить») + «Рядом / Двор / Удалить»;
   - Escape — отменить размещение; не больше 20 объектов.
   Житель (телефон 375 px): видит объекты с табличками «Проект», подсказку «Нажмите на проект, чтобы проголосовать»,
   открывает карточку и голосует (один голос с устройства). После перезагрузки всё на месте, без повторной анимации.

5. В КОДЕ (для следующего ИИ)
   web/civic/build3d/build3d-core.js    — без DOM: каталог, меркатор как в MapLibre, улицы, районы, объекты OSM,
                                          проверка места, хранилища (клиент API R06 обеих поставок / заглушка)
   web/civic/build3d/build3d-models.js  — процедурные модели (слитые геометрии с цветом в вершинах)
   web/civic/build3d/build3d.js         — custom layer MapLibre + three.js, интерфейс, подписи, анимации,
                                          карточка (своя или R06), освещение через R12, вид акимата/жителя
   web/civic/build3d/build3d.css        — панель, карточка, подписи (токены ui-kit с запасными значениями)
   Комментарии по-русски в сложных местах: привязка сцены к карте, «постройка» шейдером, подписи над объектами,
   свободная часть карты для объекта открытой карточки (freeArea/cutBest), запасной путь к R06 поставки 1.
