R05 · раунд 14 · 3D-превью предложений — как запустить и что можно сделать

1. ДЕМО БЕЗ ИНТЕРНЕТА (сразу, без сборки R01)
   Из корня репозитория:
     Windows:  py -m http.server 8765 -d web
     Linux/Mac: python3 -m http.server 8765 -d web
   Открыть: http://127.0.0.1:8765/civic/build3d/demo.html
   Подложка — настоящие улицы OSM фокус-области Нуры (без зданий). Полезные параметры адреса:
     ?lang=kk                казахский (или кнопки ҚАЗ / РУС в шапке; выбор запоминается)
     ?role=resident          вид жителя (только просмотр и голос)
     ?pitch=0 | ?pitch=60    наклон; ?bearing=-20 поворот; ?zoom=17.5; ?center=71.4008,51.1272
     ?reset=1                стереть поставленное на этом устройстве (вернутся 2 примера)
     ?store=local            не спрашивать сервер предложений (для статического сервера это и так происходит)

2. ЧТО МОЖЕТ СДЕЛАТЬ ПОЛЬЗОВАТЕЛЬ
   Акимат (ноутбук 1366 px):
   - внизу «Что построить?» — 5 карточек: Сквер, Детская площадка, Спортплощадка, Остановка, Освещение улицы;
   - выбрать карточку → полупрозрачный зелёный «призрак» идёт за курсором; щелчок по карте ставит его в точку;
   - ↺ / ↻ (или клавиша R, Shift+R) — поворот на 15°; остановка сама встаёт вдоль ближайшей улицы
     открытой стороной к дороге, пока её не повернули вручную;
   - «Поставить» → объект вырастает снизу вверх за ~1.2 с с лёгкой пылью → над ним табличка «Проект · 2027»;
     внизу тост «Проект поставлен…» с кнопкой «Отменить»;
   - освещение: щелчок по улице — начало участка, второй щелчок по той же улице — конец; подсказка
     «улица Сыганак, 187 м · 7 фонарей»; опоры через ~30 м вдоль настоящей формы улицы;
   - если рядом уже есть такой объект в OpenStreetMap — синяя подсказка «Рядом уже есть остановка: «БЦ Саад», 35 м»
     (не мешает поставить); объект во дворе получает привязку «Двор: Evolution»;
   - нельзя поставить поверх другого проекта и за пределами Астаны — красная подсказка, «Поставить» неактивна;
   - щелчок по объекту или табличке → карточка: «За · N», «Против · M», «Один голос с устройства», «Удалить»
     (после удаления — «Отменить»); Escape — отменить размещение; не больше 20 объектов.
   Житель (телефон 375 px): видит объекты с табличками «Проект», открывает карточку и голосует.
   На телефоне призрак стоит в центре карты: двигайте карту пальцем или коснитесь места, затем «Поставить».
   После перезагрузки страницы всё поставленное на месте, без повторной анимации.

3. ТЕСТЫ (из корня репозитория)
   node --test tests/civic/R05/build3d/test_core.mjs tests/civic/R05/build3d/test_models.mjs
   python -m unittest discover -s tests/civic/R05/build3d -p "test_*.py"
   node tests/civic/R05/build3d/browser_check.mjs            (нужен пакет playwright и Chromium; --no-shots — быстрее)
     → research/round-14-results/R05/runs/browser_check.json и screens/*.png
   Приложение R01 + патчи (см. INTEGRATION.txt §1):
     git worktree add --detach ../r05-app HEAD && cd ../r05-app
     git apply <репозиторий>/research/round-14-results/R05/proposed_r01.patch
     git apply <репозиторий>/research/round-14-results/R05/proposed_r01_uikit.patch   (если ui-kit ещё не подключён)
     python -m ui.web_server --port 8799
     (в первом окне, из этой ветки) node tests/civic/R05/build3d/app_smoke.mjs http://127.0.0.1:8799/

4. ПЕРЕСОБРАТЬ ДАННЫЕ МОДУЛЯ (детерминированно, без сети)
   python tests/civic/R05/build3d/make_fixtures.py
   Источники: engine/civic_scenarios/graphs/osm-astana-walking-20260506.graph.json (улицы),
   data/civic/astana/geofence.json (районы), data/civic/astana/osm-objects/ (LOCAL-1: реальные объекты).
   Тест test_regeneration_is_byte_identical проверяет, что файлы в web/civic/build3d/data/ совпадают с генератором.

5. В КОДЕ (для следующего ИИ)
   web/civic/build3d/build3d-core.js    — без DOM: каталог, меркатор как в MapLibre, улицы, районы, объекты OSM,
                                          проверка места, хранилища (API R06 / заглушка)
   web/civic/build3d/build3d-models.js  — процедурные модели (слитые геометрии с цветом в вершинах)
   web/civic/build3d/build3d.js         — custom layer MapLibre + three.js, интерфейс, подписи, анимации
   web/civic/build3d/build3d.css        — панель, карточка, подписи (токены ui-kit с запасными значениями)
   Комментарии по-русски в сложных местах: привязка сцены к карте, «постройка» шейдером, подписи над объектами.
