## Поведение и интеграция

При установленном архиве карта выбирается локально сразу, без ожидания внешнего
сервера. Это принятое решение для финала. `?offline=1` или navigator offline
также запрещают выбор удалённого стиля. Если архива нет, принудительный офлайн
показывает прежние оси улиц и предупреждение; этот отрицательный случай проверен.
Без архива в обычном online-режиме остаётся прежний OpenFreeMap.

Светлая палитра согласована с существующей картой. Здания используют `height`
и `min_height` Protomaps; upstream получает высоту из высоты/этажности OSM.
Есть запасной расчёт `building:levels × 3`, без сведений — 6 м.
РУС: `name:ru → name → name:kk`; ҚАЗ: `name:kk → name → name:ru`.
Переключение подписей живое, вместе с интерфейсом. Все 18 прописных/строчных
глифов Қ Ғ Ү Ұ Ә Ө Һ І Ң проверены, включая непустые битовые карты.

В [INTEGRATION.txt](INTEGRATION.txt) — минимальный patch для R01: подключение
двух локальных скриптов, выбор стиля, схема зданий, локальный HTTP-обработчик
и `.gitignore`. В своей ветке patch применён. Действующие слои R07/R05/R12
сохранены. Архив раздаётся частями: HTTP 206/Content-Range, HEAD, ETag/If-Range,
416; произвольные пути и Python-исходник обработчика по HTTP недоступны.

## Что осталось и почему

1. **R09, P2:** после «похожие → отправить отдельное → закрыть» на телефоне
   отложенная классификация читает `state.text`, когда state уже null. Стек:
   `complaint.js:534:52`. Обращение сохранено, карта и дальнейшая постановка
   3D работают. Ошибка отдельно воспроизведена с browser offline и online;
   файл R09 идентичен базе R01, здесь не менялся. [Шаги и стек](R09_ISSUE.md).
   Исправление владельцу R09/R01: отменять таймер и устаревшие ответы при
   закрытии/уничтожении мастера, проверять state в отложенной функции.
2. Protomaps 4.15.2 не сохраняет отдельный `name:kk`. Казахские местные `name`
   отображаются, но полного казахского перевода всех POI/улиц нет. Русские
   названия и бренды не переводились искусственно.
3. Покрытие ограничено указанным bbox; z16–18 увеличивают векторы z15.
   Высоты неполны в OSM. Это не геодезическая 3D-модель. Ежедневный исходный
   архив может быть удалён Protomaps: для точной копии сохраните локальный файл;
   `-Latest` получает новую карту с другим SHA, что явно описано в RUN.txt.
4. Полный PWA/offline без локального сервера **не реализован и не заявляется**.
   Веб-сервер, глифы, спрайты и PMTiles должны быть на ноутбуке до отключения интернета.
5. Остались общие UX-замечания R10: мелкие тексты/зоны нажатия (R01/R11),
   русский кабинет сотрудника при ҚАЗ (R12/R11). Часть подписей объектов в
   heat/day остаётся русской или общей «Нысан» (R07/R08/R12); улицы подложки
   переключаются отдельно и проверены. Эти чужие модули здесь не редактировались.
6. Не все сырые FAIL R10 означают дефект: поиск каталога не нажимает кнопку
   раскрытия, поэтому 4 постановки там NOT_RUN; отдельный реальный UI-тест
   открыл каталог и успешно поставил проекты на всех экранах. Проверка 40 Tab
   пропускает новый skip-link: проверено **Tab → «Перейти к главной кнопке» → Enter →
   кнопка жалобы**. Поиск русских строк захватывает скрытые блоки; мобильная
   легенда скрывается при полной шторке, но видна на наших кадрах карты.

Все тексты и голоса созданы для приёмки, людей не привлекали. R15 не доверяет
переданному клиентом `demo:true`, поэтому у новых публичных тестовых обращений
API возвращает `demo:false`; от этого они не становятся реальными наблюдениями.
Приёмочную `.runtime/offline-final.sqlite3` не использовать на показе как реальные
данные. Для показа — свежая демо-база с `seed-demo`/`seed-r14-demo` (RUN.txt).
Базы, учётные данные, веса, .env и архив тайлов не входят в Git.
