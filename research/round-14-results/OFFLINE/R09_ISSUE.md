Воспроизведение на 375×812 (РУС/ҚАЗ):

1. Житель → сообщить → выбрать остановку «Хан Шатыр».
2. Ввести «Аялдамада жарық жоқ, вечером на остановке темно».
3. «Отправить» → в списке похожих «Это другая проблема» / отдельное обращение.
4. Сразу после подтверждения отправки закрыть мастер (Escape).
5. Через задержку классификатора возникает TypeError: Cannot read properties
   of null (reading 'text'), complaint.js:534:52.

При возврате из шага похожих send() рисует шаг 3, который запускает debounce
scheduleClassify(). close() на шаге 5 очищает state, но не classifyTimer.
Проверка !state есть в then(), однако чтение state.text выполняется раньше,
в теле таймера. Успешная запись обращения не откатывается; карта работает.

В extra ошибка возникла по одному разу на двух телефонных профилях.
Целевой контроль воспроизвёл её дважды: context offline=true и offline=false.
[Полные стеки](screens/r09-repro/R09_REPRO.json).

Рекомендуемая правка R09: при close()/destroy() clearTimeout(classifyTimer),
инвалидировать classifySeq; в callback проверять актуальность state до
state.text. Аналогично проверить незавершённые send/metoo callbacks.
Правка не применяется этой поставкой: она относится к мастеру R09, не к карте.
