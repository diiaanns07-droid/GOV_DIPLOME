# R10 · дизайн-марафон — визуальный контроль (DESIGN_MARATHON.md, роль R10)

Задача R10: скриншоты всех экранов до/после марафона против `baseline_8e67c65` и FINAL-3; контраст на стекле (светлый и
пёстрый фон карты); FPS при перетаскивании карты на 1366 и 1024; список визуальных дефектов по ролям; повтор после каждой
сборки R01. R10 не правит чужой код — точные правки ролям в `DESIGN_REVIEW.md` и `BUGS.md`.

## Инструменты (tests/e2e/)
- `design_book.cjs --root <сборка> --out <папка>` — «книга экранов»: 27 состояний (житель, акимат, сотрудник, мастер
  жалобы до «отправлено», QR, «нет связи», медленная сеть, «уменьшить движение») × 1366/375 × ru/kk; кадр каждого
  состояния и автоматический замер чек-листа (иерархия, сетка 8 pt, шкала шрифтов и веса, строки > 70 знаков, обрезка,
  бежевые плашки и лишние краски, радиусы вне токенов и двойные тени, длительности анимаций, скелетон / пусто / ошибка,
  толщина линий иконок, фокус с клавиатуры, отклик и «прыжок» при нажатии, технические слова). Стекло держится включённым
  (`--glass keep`), как на ноутбуке с видеокартой; владелец замечания — по классу модуля.
- `design_compare.cjs --books 8e67c65=<папка>,FINAL-3=<папка>,сейчас=<папка> --out <папка>` — кадры рядом и таблица
  «лучше / хуже / так же» по экранам.
- `glass_check.cjs` — контраст текста на стекле по пикселям над фонами: карта, **светлый** (#f2efe9), **пёстрый** (парк,
  вода, дороги, кварталы, цвета жалоб), тёмно-зелёный, синий, красный (строго), чёрный и полосы (предельные); FPS — стекло
  против `html.bk-glass-off` (облако — программный WebGL, «ИНФО»; настоящий замер — ноутбук, Codex М9).

## Главное
- **`compare-final/`** — все экраны «до / после марафона»: эталон `8e67c65` | FINAL-3 `61be62e6` | марафон R01 `83010621`
  (1366-ru, 375-ru, 375-kk; `COMPARE.md` — лучше 112 / хуже 2 из 114). Отчёт и дефекты по ролям — `DESIGN_REVIEW.md`
  (таблица «Итог марафона в числах»: замечаний на экран 43,1 → 15,1 → 6,0).

## Папки
- `book-<sha>/BOOK.md` — экраны × варианты, замечания по ролям (кадры — в облаке; в Git — сравнения).
- `compare-r1…r6/` — круги (кадры — только изменившиеся экраны с круга 4); `accept-*` — сценарий и пять пунктов против
  эталона; `glass-*`, `fps-*`, `motion-*` — стекло, плавность, движение по сборкам.
- `glass-<sha>/` — контраст на стекле с новыми фонами.
