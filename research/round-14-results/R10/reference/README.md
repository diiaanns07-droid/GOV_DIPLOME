# R10 · «Дизайн по эталону — лучше 2ГИС»: сборка против варианта A

Задание владельца (13 окт): экраны один в один с вариантом A `research/round-14/design/REFERENCE.html` + 7 правил качества Linear.
Часть R10 по таблице README «Кто что делает»: **попиксельное сравнение каждого экрана сборки с эталоном (1366 и 375), список
расхождений по ролям; регресс сценария демо**; правило 4 (скелетон ≤ 150 мс) — **R10 замеряет**. R10 код ролей не правит.

## Как сравнивается

`tests/e2e/reference_check.cjs` (запуск — внизу). Четыре экрана эталона: «Главная акимата», «Выбран объект», «Проекты и идеи»
(1366×768, сотрудник акимата — вход через API той же сборки) и «Житель, телефон» (375×812).

- В эталоне элемент берётся по классу (`.search`, `.nav`, `.me`, `.ctl`, `.legend`, `.sum`, `.card`, `.sheet`, `.p-sheet`, `.fab`, `.pin`…),
  в сборке — по тексту, подписи и роли (поле с подсказкой «Улица…», «Карта» + «Картина дня», «ҚАЗ» + аватар, «Приблизить»/«Отдалить»,
  «мало», «Хан Шатыр», «Проекты и идеи»…). Сравнение: место и размер (±4 px), радиус (±2), фон и прозрачность, стекло (размытие),
  тень, рамка, шрифт (семейство, размер, вес, цвет), текст заголовков и кнопок, «за краем экрана».
- **Пиксели**: вырезка элемента сборки приводится к размеру эталона; доля пикселей, у которых каналы отличаются ≤ 24. Плюс карта
  разницы всего кадра (`-diff.jpg`, порог 32).
- «Лишнее» — то, чего в эталоне нет: постоянная панель на главной (правило 1 эталона), легенда и кнопки карты поверх карты телефона.
- Итоги: «совпадает» / «близко» (одно небольшое расхождение) / «расходится» / «НЕТ В СБОРКЕ» / «лишнее».
  **Счёт** — сколько элементов «совпадает или близко» из 47, и средняя доля совпадающих пикселей вырезок.

Кадры каждого прогона: `<экран>-pair.jpg` (эталон | сборка), `-boxes.jpg` (рамки: синие — эталон, красные — сборка, фиолетовые —
лишнее), `-crops.jpg` (вырезки элементов рядом с процентом), `-diff.jpg`, `-ref-was-now.jpg` (эталон / было / стало), `-build.jpg`.
Кадры эталона — `etalon/`.

## Главное по ролям (превью pv1; подробно — `pv1-preview/REFERENCE.md`, раздел «Расхождения по ролям»)

**R01 — хром экрана (1 из 22).** Самое заметное расхождение со 2ГИС-эталоном:
1. **Постоянная панель** «Карта жалоб» справа (`#civic-panel`, 954,84 400×672) — в эталоне её нет: слева только закрываемая карточка.
   Из-за неё кнопки карты стоят у края панели (x 894), а не у края экрана (эталон x 1300).
2. Шапка — одна сплошная полоса на всю ширину (`header.topbar.bk-glass` 12,12 1342×60). В эталоне — три отдельные стеклянные
   капсулы: поиск 20,20 388×52 (радиус 16, стекло 86 %, тень, логотип внутри), навигация-капсула 445,20 476×44 (выбранный пункт —
   тёмная таблетка #121A17 с белым текстом 14/500, у нас подчёркивание 15/600), «ҚАЗ · РУС» + лаймовый аватар 1217,20 129×44.
3. Нет чипов категорий под поиском (эталон 20,82: «Все · Снег · Остановки · Освещение · Ещё», выбранный — тёмный). В сборке —
   выпадающий «Все категории» в панели.
4. Легенда: 395×44 → эталон 303×36 (цветные квадраты, «✓ исправлено» зелёным, без «?»), шрифт Helvetica Neue вместо Inter.
5. Шрифт страницы — `14px/1.5 "Segoe UI", Inter, Arial` (`web/style.css`, `body`, стр. 22–28; попапы — стр. 1107): кнопки
   («Сообщить о проблеме», кнопки карты) наследуют его, легенда — `"Helvetica Neue", Arial`. На ноутбуке с Windows это Segoe UI,
   а не Inter; эталон — один шрифт Inter (в ui-kit он подключён как «Birge Sans» — им уже идут поле поиска и модули).
6. Телефон: поиск 159×48 между логотипом и «ҚАЗ · РУС» → эталон — во всю ширину 14,54 347×50; поверх карты лишние легенда и
   столбик кнопок карты (в эталоне их нет; «ҚАЗ · РУС» — в заголовке шторки).

**R07 — значки и карточка (4 из 12).** Значки 34 px, выбранный 44 px и бледнение остальных до 35 % — как в эталоне (было:
не бледнели). Карточка объекта уже с вкладками и большим числом, но: стоит справа (954) — место задаёт R01 (эталон — слева под

подпись, а не число).

**R09 — телефон (2 из 5).** Кнопка «Сообщить о проблеме» и лаймовая плитка — совпадают (пиксели 89 % / 85 %). Шторка: заголовок

## Неустранимое в облаке и в данных (не дефекты сборки)

- Подложка карты: в облаке нет сети до тайлов — на главной «Карта улиц не загрузилась — показан упрощённый фон» (на `obj` при
  zoom 16 улицы есть). Карта и данные эталона нарисованы (34 / 12 / 5, «Двор у ул. Коксенгир 11») — поэтому разница всего кадра
  (`-diff.jpg`) сравнима только между прогонами, а не с нулём.
- Место значков задают данные, не сравнивается (только размер, рамка, тень). Цвет значка — по уровню жалоб.
- Кабинет сотрудника показывает «Идеи на проверке / Проекты» с «Проверить», «Одобрить / Отклонить» — это функция акимата,
  эталон рисует вид жителя («Поддержать»). R10 сравнивает раскладку и стиль, текст кнопок — к сведению.
