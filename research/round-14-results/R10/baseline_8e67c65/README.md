## Как сравнить FINAL-2 с эталоном
    # 1. сборка FINAL-2 в отдельном worktree
    git worktree add --detach ../final2 <SHA FINAL-2 из research/handoffs/astana/R01/round14/STATUS.md>
    # 2. те же прогоны (≈ 11 + 8 мин)
    NODE_PATH="$(npm root -g)" node tests/e2e/demo_flow.cjs   --root ../final2 --out ../r10-final2/e2e
    NODE_PATH="$(npm root -g)" node tests/e2e/map_baseline.cjs --root ../final2 --out ../r10-final2/map --repeat 3
    # 3. контроль времени на ЭТОЙ ЖЕ машине (время из облака несравнимо с ноутбуком): 8e67c65 ещё раз
    git worktree add --detach ../b8e67c65 8e67c65
    NODE_PATH="$(npm root -g)" node tests/e2e/demo_flow.cjs   --root ../b8e67c65 --out ../r10-ctl/e2e
    NODE_PATH="$(npm root -g)" node tests/e2e/map_baseline.cjs --root ../b8e67c65 --out ../r10-ctl/map --repeat 3
    # 4. сравнение: вид и проверки — с эталоном, время — с контролем
    NODE_PATH="$(npm root -g)" node tests/e2e/compare_baseline.cjs --base research/round-14-results/R10/baseline_8e67c65 \
         --new ../r10-final2 --control ../r10-ctl --out ../r10-final2/compare
    # → COMPARE.md: «НЕ ХУЖЕ» или «ХУЖЕ» + список FAIL / СМОТРЕТЬ; кадры diff-*.jpg (эталон | новый | разница красным)

Без `--control` время сравнивается с эталоном только «для сведения», если машина другая (CPU, Chromium).

## Что считается «хуже» (FAIL) и что «посмотреть» (СМОТРЕТЬ)
- FAIL: PASS эталона стал не PASS; новая проверка сценария FAIL; шаг сценария медленнее > ×1.25 и > +2 с (вариант целиком
  > ×1.15 и > +5 с); загрузка карты медленнее > max(×1.25, +0.5 с) или событие не наступило; отклик интерфейса > max(×1.5, +0.7 с)
  или не дождались; **новый слой стиля виден по умолчанию** или **новый вид значков на карте по умолчанию** (правило 1);
  статус API изменился; первая отрисовка > 3 с на ноутбуке (правило 5), если эталон укладывался.
- СМОТРЕТЬ: кадр вида по умолчанию отличается > 2 % точек; новые кнопки поверх карты; пункты меню изменились
  (правило 2 — житель ≤ 5, акимат ≤ 5); новые запросы API при открытии карты (правило 5); камера по умолчанию сдвинута;
  число значков или нарисованных объектов слоя изменилось > 20–30 %; плавность хуже ×1.5; API медленнее ×2.
