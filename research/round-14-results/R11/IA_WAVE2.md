# Волна 2 · схемы экранов (R11 — информационная архитектура)

Основание: `research/round-14/POLISH_WAVE_2.md` (утверждено 11 октября), раздел «Защита интерфейса от перегруза», п. 6:
**до кода нового экрана R11 даёт схему, после — разбор; экран, который R11 отклонил, R01 в FINAL не берёт.**
База вида — FINAL-кандидат R01 **8e67c65** (`claude/sharp-dijkstra-0t87gl`). Компоненты — ui-kit `bk-*` (`claude/r14-R11`),
правила — `UX_SPEC.md` (§1–10). Тексты — только ключи словаря R11 (они уже в словаре, раздел «Ключи» у каждой схемы;
нужен новый ключ — пришлите в INTEGRATION.txt, R11 переведёт в тот же день).

Формат каждой схемы: **где в меню → что на экране (сверху вниз) → главная кнопка → что свёрнуто → чего НЕ должно быть →
ключи → что R11 проверит при разборе.** Размеры: телефон 375 × 812 и ноутбук 1366 × 768, ru и kk.

## 0. Правила для всех новых экранов (проверяю на каждом разборе)

1. **Карта по умолчанию не меняется.** Первый кадр акимата и жителя — как в 8e67c65: тепловая карта целей + работы
   города. Ни один пункт волны 2 не добавляет на карту по умолчанию слоёв, значков, баннеров и всплывающих окон.
2. **Дополнительный слой — один и по выбору.** «Работы рядом» и «Идеи жителей» включаются в уже существующем блоке
   «Қабаттар / Слои» (панель «Аймақ / Территория») переключателем-радио: `Тек шағымдар мен жұмыстар` (по умолчанию) ·
   `Маңайдағы жұмыстар` · `Тұрғындар идеялары`. Одновременно — максимум один. Данные слоя грузятся только при включении.
   Новой кнопки на карте нет.
3. **Новый раздел — свой экран**, как «Картина дня»: ноутбук — колонка контента до 960 px по центру, телефон — во весь
   экран; «Карта» в меню возвращает к карте. Новые разделы не открываются поверх карты шторкой.
4. **Карточка не растёт**: сверху — что, сколько людей, статус, одна главная кнопка; остальное — `<details class="bk-details">`
   «Подробнее» / «История».
5. **Одна главная кнопка** (`bk-btn--primary`) на экран и на открытую карточку.
6. **Пусто — значит не показываем блок** (кроме экранов-списков: там `BirgeUI.state(el, "empty")`). Нет «0 тревог».
7. Демо-данные — `demo: true` и метка `common.tag.demo` («Үлгі / Пример»). Нельзя: «подключено к 109»,
   «подтверждено акиматом», реальные названия организаций, личные данные, лица и номера машин на фото.
8. Язык: страница открывается на сохранённом языке устройства (`birge.lang`), иначе — языке браузера. **Ссылки и QR не
   несут `lang` и язык не переключают** (обязательная мелочь, R01 + R11).
9. Числа людей — формами `{n} адам` / «{n} человек», даты — только `BirgeI18n.formatDate`, сроки — `deadline.*`.

## 2. R09 — «Исправлено — проверьте», паспорт решения, один ответ всем, «Что изменилось» (п. 1, 2, 3, 10)

Новых пунктов меню нет: всё живёт в «Мои обращения» (житель), в карточке цели на карте (житель и акимат) и в «Обращения»
(акимат, §2.5).

### 2.1 Житель · «Мои обращения» = «моё участие» (п. 10 + п. 1)

```
375 ────────────────────────────────
 Менің өтініштерім
 ┌ Не өзгерді ─────────────────────┐   ← только если есть новое (≤ 3 строки, остальное — «Тағы N»)

   Жауапты: Жол қызметі · Жауап мерзімі: 16 қазан
   ▸ Толығырақ (паспорт целиком, история)
```

- Главная кнопка экрана — «Иә, түзетілді» в первом блоке проверки; если проверять нечего — главной кнопки нет.
- «Мәселе қалды» → карточка снова «в работе» с отметкой «вернули жители» (`heat.reopened_mark`), история сохраняется;
  «Тексере алмаймын» — статус не меняется, вопрос больше не показывается этому устройству.
- Уведомление (п. 4, мелочь) открывает **конкретное изменение**: `?section=mine&event=<id>` → прокрутка и подсветка строки.

  запрос разрешения на уведомления при открытии; фото «до» жителя кому-либо, кроме акимата (волна 1 п. 5); больше
  3 строк «Не өзгерді» без «Тағы».
- Ключи: `mine.changes.*`, `verify.*`, `mine.subscriptions`, `mine.unsubscribe`, `mine.waiting`, `status.reported_fixed |
  verified | reopened`, `passport.*`, `service.assigned`, `deadline.*`.

### 2.2 Карточка цели и обращения · паспорт решения (п. 2)

Сверху (всегда видно), не больше 4 строк:
1. статус (`bk-status` с новыми `reported_fixed | verified | reopened`);
2. `service.assigned` — «Жауапты: Жол қызметі»;
3. `passport.next` — «Келесі қадам: …» (одна строка, ≤ 80 знаков);
4. сроки: `passport.answer_due` и `passport.fix_eta` / `passport.fix_unknown`.

При задержке — баннер `.bk-banner--warn` (ui-kit): `passport.delay_reason` · `passport.temp_measure` ·
`passport.next_update`. Просроченное обновление (`passport.update_overdue`) видно **акимату** (красным словом), жителю —
нет. «История» (сообщили → передано → ответ → служба сообщила → проверили / вернули) — в `<details>`.

### 2.3 Сотрудник · «Исправлено» и паспорт за 3 поля (п. 1, 2)

- «Түзетілді деп белгілеу» открывает форму в той же карточке (не модальное окно): «Не істелді (бір жол)» — обязательно,
  ≤ 120 знаков; «„Кейін“ фотосы» — 1 фото, по желанию (те же правила, что фото жителя: EXIF/GPS удалить); главная
  кнопка «Тұрғындарға хабарлау» + строка `fix.will_see` («14 адам көреді»). Результат — статус `reported_fixed`, на карте
  светло-зелёный с пунктиром (`--reported-fixed`), **не** зелёный.
- Паспорт: «Өзгерту» в карточке → 3 поля: служба (список из таблицы п. 7, по умолчанию — по категории), следующий шаг,
  ориентир устранения (дата или «әзірге белгісіз»). При просрочке появляются ещё 3: причина, временная мера, следующее
  обновление (дата обязательна).
- **Нельзя:** больше 3 обязательных полей; чат с жителем; правка текста жителя; публикация фото «после» на общей
  карте (только автору и «Мен де» в их карточке; лица/номера — проверка R15); вторая главная кнопка.

### 2.4 Один ответ всем «Мен де» (п. 3)

- Житель: на кнопке «Мен де» подпись-подсказка `broadcast.metoo_hint` («Шешілу барысы туралы хабарлап отырамыз») —
  мелким текстом под кнопкой, не во всплывающем окне.
- Сотрудник: в карточке цели блок «Барлығына жаңарту» (`broadcast.title`): одно поле `broadcast.placeholder`, кнопка
  `broadcast.send`, строка `fix.will_see`. Обновление попадает каждому участнику в «Не өзгерді».
- **Нельзя:** ответы по одному; рассылка без предпросмотра числа людей; показ списка участников (имён нет вообще).

### 2.5 Акимат · «Обращения» (меню, п. 2 защиты) — предложение R11

Владелец экрана — решает координатор/R01; данные и карточка — R09 (записи), карточка цели — R07.
Список целей с открытыми обращениями, а не отдельных жалоб: вкладки-фильтры `inbox.tab.new | in_progress |
waiting_check | overdue | reopened` (Жаңа · Орындалуда · Тексеруді күтуде · Мерзімі өткен · Қайтарылған), строка:
место · категория · уточнение · `{n} адам` · срок (`deadline.*`). Тап — та же карточка, что на карте (§2.2–2.4).
**Нельзя:** вторая карта на экране; таблица с 10 колонками; массовые действия над разными целями.

## 3. R07 — цвета новых состояний на карте (п. 1, мелочь «нет свежих данных»)

- Ключи: `heat.legend.reported_fixed | verified | nodata`, `heat.reopened_mark`.

## 5. R08 — «Картина дня»: «Нужно решение акима», «Пульс района», счётчики проверки (п. 5, 8, 1)

Порядок сверху вниз (ничего прежнего не выпадает и не уезжает вниз больше чем на один блок):

1. Плитки KPI (как сейчас). Плитка «Апта ішінде түзетілді» получает вторую строку: `akim.verify.split` —
   «Қызмет хабарлады 12 · тұрғындар тексерді 8 · қайтарылды 2».
2. Күн туралы қысқаша (как сейчас).
3. **«Әкімнің шешімі керек»** (`akim.decision.title`) — 1–3 карточки; **нет случаев — блока нет.** Карточка:
   проблема (место · категория · «{n} күнге кешікті») → `akim.decision.blocker` → два варианта (`akim.decision.option`)
   → `akim.decision.needed`. Кнопки «Таңдау» у вариантов — второстепенные; главной кнопки в блоке нет.
   Критерий попадания — в коде с комментарием (просрочено и причина «нужно решение руководителя»).
4. **«Аудан пульсі»** (`akim.pulse.title`) — 1–5 строк, сверх 3 — «Тағы N» (`<details>`). Строка: что выросло · где ·
   во сколько раз к обычному · причина одной фразой · «Картадан көрсету». **Нет тревог — строка `akim.pulse.none`
   мелко, без пустой карточки.**
5. Шағымы көп орындар и остальное — как сейчас.

- **Нельзя:** новые графики; слова «z-оценка», «сигма», «аномалия» (говорим «әдеттегіден ×3»); тревога без причины;
  больше 3 решений и 5 тревог; красный цвет на всём блоке (красное — только число просрочки); автообновление, от которого
  прыгает экран; «подтверждено акиматом».
- Ключи: `akim.decision.*`, `akim.pulse.*`, `akim.verify.split`.
- R11 проверит: «10 секунд» — на 1366 без прокрутки видны KPI и первая карточка «Нужно решение»; на 375 — KPI 2×2 и
  заголовок блока решений.

## 6. R12 — QR-паспорт объекта (п. 6)

### 6.1 Ссылка `/?report=<target_id>` (житель, без входа)

- Открывается режим «Тұрғын», карта на объекте, **карточка объекта открыта** (телефон — шторка наполовину).
  Сверху: название места (`target.kind.*`), «{n} адам хабарлады», статус, **одна главная кнопка**: «Мен де», если есть
  открытая проблема; иначе «Осы жердегі мәселе туралы хабарлау» (`report.here`). Второстепенная — «Басқа мәселе туралы
  хабарлау» (`report.other`): открывает мастер R09 сразу на шаге «что случилось» с этим местом.
- «История» и текущие обращения — в `<details>`; паспорт решения — как §2.2.
- Неизвестный `target_id` — `map.card.not_found` + `map.card.not_found_hint` + кнопка «Картаға» (не пустая карта).
- **Нельзя:** переключать язык; автоматическое «Мен де» при сканировании; вход сотрудника; служебные кнопки; метки
  отслеживания в ссылке; ссылка на внешний домен (подмена — проверка R15).

### 6.2 Лист для печати (акимат: «Тағы → QR-тақтайшалар» и кнопка «QR басып шығару» в карточке цели)

A4 книжный, два языка на одном листе: QR ≥ 6 см; крупно (≥ 28 pt) короткий адрес/название; номер объекта
(`qr.object_no`); строка `qr.call` на kk и ru («Мәселе бар ма? Сканерлеңіз · Есть проблема? Сканируйте»); домен
текстом под QR. Печать — `@media print` без шапки и кнопок.
**Нельзя:** числа жалоб и статусы на листе (устареют), личные данные, логотипы организаций.

## 7. R13 — «Вопрос акиму» (п. 9) и метод пульса (п. 8)

**Житель: «Тағы → Әкімге сұрақ». Акимат: «Тағы → Тұрғындар сұрақтары».** На карте вопросов нет.

```
375 ────────────────────────────────
 Әкімге сұрақ
 Әкім аптасына бір рет ең көп дауыс жинаған 5 сұраққа жауап береді.   ← правило, всегда видно
 [ Сұрақ қою ]   ← главная кнопка
 [ Танымал | Жаңа | Жауап берілген ]
 ┌ Үлгі · Нұра ─────────────────────┐
 │ «Қашан Е-308 көшесіне бағдаршам  │
 │ қояды?»                          │
 │ 34 дауыс        [ Қолдау ]       │
 │ ▸ Әкімнің жауабы · 9 қазан       │  ← только у отвеченных
 └──────────────────────────────────┘
```

- Форма вопроса: текст ≤ 300, район (список), подсказка `ask.privacy`, строка `ask.moderation`; после отправки — экран
  «Сұрақ тексерілгеннен кейін жарияланады» + «Менің сұрақтарым» не нужен (вопрос виден в «Жаңа» после модерации).
- Акимат: вкладки `ask.staff.queue | top | answered`; модерация «Жариялау» / «Себебін көрсетіп қабылдамау»; топ-5 недели
  с формой ответа.
- Пульс (метод, п. 8): R13 отдаёт R08 строки уже готовыми к показу: `{kind, category, district, ratio, reason_key,
  params, target}` — без статистических терминов; `ratio` округлён до 0,5; причина — ключ словаря R11 (пришлите список).
- **Нельзя:** комментарии и ветки; имена жителей; голос без ограничения «одно устройство — один голос» (R15); «Әкімнің
  жауабы» в демо без метки «Үлгі»; рейтинги районов; вопросы на карте.
- Ключи: `ask.*`.

## 8. R06 (+ R05) — «Идеи» → голосование → проект в 3D (п. 7)

**Житель: пункт меню «Идеялар». Акимат: «Жобалар мен идеялар».** Слой «Тұрғындар идеялары» — по желанию (§0.2).

```
375 ────────────────────────────────
 Тұрғындар идеялары
 ┌ ⓘ Бұл тұжырымдаманы таңдауға арналған сауалнама, шешімді әкімдік қабылдайды ┐   ← всегда видно, не сворачивается
 [ Идея ұсыну ]   ← главная кнопка
 [ Дауыс беру | Жобаға айналды | Қабылданбады ]
 ┌ Үлгі · Есіл · Гүлзар ────────────┐
 │ Сығанақ көшесіндегі гүлзар        │
 │ 47 дауыс · Дауыс беру жүріп жатыр │
 │ [ Қолдау ]  [ Картада ]           │
 │ ▸ Толығырақ                       │  ← текст, «3D-де көру» (R05, по кнопке), чек-лист после проверки
 └──────────────────────────────────┘
```

- Новая идея — не больше 3 шагов: место на карте (тот же выбор места, что у мастера R09) → название ≤ 60 и описание
  ≤ 300 → по желанию объект из каталога 3D (5 чипов) → «Жіберу». Строка `idea.moderation`.
- Отклонённая: `idea.reason` + `idea.can_improve` всегда видны в карточке. Принятая: ссылка на проект с подписью
  `idea.by_residents` («Тұрғындар идеясы бойынша · 47 дауыс»), у проекта на карте — та же подпись.
- **Лёгкая карточка раньше 3D** (мелочь R05): «3D-де көру» — только по кнопке, 3D не открывается сам.
- Акимат: вкладки «Тексерудегі идеялар · Жобалар»; проверка реализуемости — 4 строки (`idea.check.land | networks |
  access | maintenance`: иә / жоқ / белгісіз); главная кнопка «Жобаға айналдыру», второстепенная «Себебін көрсетіп бас
  тарту» (причина обязательна, «Жетілдіруге болады» — по желанию).
- **Нельзя:** суммы денег и обещания сроков; «Бюджет народного участия» как подключённый сервис (только текстом);
  рейтинг жителей; комментарии; 3D, открывающееся само; голос без ограничения устройства (R15); идеи на карте по умолчанию.
- Ключи: `idea.*`.
