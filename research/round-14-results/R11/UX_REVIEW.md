### Для всех ролей с экраном

1. **Все → любой экран → тексты зашиты в код по-русски (≈ 1 350 строк) → казахского нет.** Только `BirgeI18n.t("ключ")`
   и `data-i18n`. Ключи из `ru.json` уже покрывают шесть экранов UX_SPEC — сначала ищите там. Не хватает — список
   «ключ | ru | где» в свой `INTEGRATION.txt`, R11 добавит и переведёт в тот же день.
2. **Все → любой экран → шрифт 11–13 px** (замеры выше) → минимум 14 px только для мета (дата, источник), основной текст 16 px,
   кнопки 18 px. Используйте `var(--fs-*)` из `tokens.css`, не числа.
3. **Все → сетки и flex-ряды → на 375 px казахский текст раздвигает страницу.** Найдено на витрине: колонка `display:grid`
   без `grid-template-columns: minmax(0, 1fr)` растягивается по самому длинному слову; элемент `flex: none` с
   `white-space: nowrap` не сжимается. Как надо: `minmax(0, 1fr)` у сеток, `min-width: 0` у flex-детей, перенос текста у
   кнопок (у `.bk-btn` уже есть). `overflow-wrap: anywhere` не использовать — рвёт казахские слова посередине.
4. **Все → записи `demo: true` → метка «Демо:» вписана в заголовок** («Демо: ремонт участка дороги…» на скриншоте) → заголовок
   без пометки, рядом метка `.bk-tag--demo` «Пример» / «Үлгі» с подсказкой `common.tag.demo_hint`.
5. **Все → проверка экрана** → `NODE_PATH="$(npm root -g)" node tests/civic/R11/browser_check.cjs --page /civic/<модуль>/<страница>.html`
   ловит горизонтальную прокрутку, ключи вместо текста, кнопки < 48 px и шрифт < 14 px на 375/1366 в ru и kk.
