Версия 1 · 2026-10-10 · автор R11 · основа `claude/round-14-package`.
Обязательна для всех ролей с экраном (R01, R05, R06, R07, R08, R09, R12, R02 — инструмент разметки).

## 1. Сетка

### Ноутбук (≥ 1024 px; эталон 1366×768)

```
┌──────────────────────────────────────────────────────────────────────────┐
│ [Birge]  [🔍 Поиск улицы, объекта…      ]  [Карта|Картина дня] [Акимат|Житель] [ҚАЗ|РУС] │ шапка 64
├──────────────────────────────────────────────────────────────┬───────────┤
│ [Категории ▾] [7 | 30 | 90 дней] [Район ▾] [Сбросить]        │           │ фильтры: top 76, left 12
│                                                              │  ПРАВАЯ   │
│                         КАРТА                                │  ПАНЕЛЬ   │
│                    (весь экран под шапкой)            [＋]   │  400 px   │ кнопки карты: 48×48,
│                                                       [－]   │           │ справа от карты,
│                                                       [◎]   │  top 76   │ right = 400+12+12
│ ┌ Легенда ───────────┐                                [3D]   │  right 12 │
│ │■1–2 ■3–5 ■6–9 ■10+ │                                       │ bottom 12 │
│ │■ исправлено        │                                       │           │
│ └────────────────────┘                     © OpenStreetMap   │           │
└──────────────────────────────────────────────────────────────┴───────────┘
```

- Шапка 64 px, белая, тень `--b-shadow-1`. Внутри — высота элементов 48 px.
- Правая панель: ширина **400 px**, отступ 12 px от краёв, радиус 20 px, фон `--b-surface`. Прокручивается только её тело; заголовок и нижняя полоса действий закреплены.
- Панель не закрывает кнопки карты: кнопки сдвигаются влево на ширину панели (`right: calc(400px + 24px)`), когда панель открыта.
- Фильтры — плавающая строка чипов поверх карты слева сверху; при узком окне переносится на 2 строки, без горизонтальной прокрутки страницы.
- Легенда — слева снизу, над атрибуцией OSM. Атрибуцию не закрывать.

### Телефон (≤ 760 px; эталон 375×812)

```
┌───────────────────────────────┐
│ [B] Birge          [ҚАЗ|РУС] [≡] │ шапка 56
│ [🔍 Поиск улицы, объекта…      ] │ поиск 48, отступ 8
│ [Снег] [Дороги] [Мусор] …  →     │ чипы — прокрутка ВНУТРИ строки
│                            [＋]  │
│            КАРТА           [－]  │ кнопки 48×48 справа
│                            [◎]  │
│ ╭─────────── ── ───────────╮    │
│ │ Остановка «Нура»   12 ●  │    │ шторка: свёрнута 96 px
│ ╰──────────────────────────╯    │
│ [ ⚠  Сообщить о проблеме      ] │ главная кнопка 56, отступ 12
└───────────────────────────────┘
```

- Нижняя шторка: 3 положения — **свёрнута 96 px** (ручка + заголовок), **половина 50 %**, **полная** `100dvh − 56 px`. Ручка 40×4 px в зоне нажатия 48 px. Свайп и нажатие на ручку; клавиша Esc сворачивает.
- Главная кнопка жителя «Сообщить о проблеме» — внизу во всю ширину (минус 12 px с каждой стороны), 56 px, над шторкой; при полной шторке прячется.
- Кнопки карты 48×48 справа, всегда выше шторки.
- Никакой горизонтальной прокрутки страницы. Горизонтально прокручивается только строка чипов (с градиентом-подсказкой справа).

### Планшет (761–1023 px)
Как ноутбук, правая панель 360 px; меню ролей и разделов прячется в «≡».

### Точки перелома
`--b-bp-phone: 760px`, `--b-bp-laptop: 1024px` (в CSS — числами в `@media`, переменные в media не работают).

### Тепловая карта (из `research/round-14/categories_v2.json`, не копировать руками)

| Уровень | Вес | Цвет | Иконка на кружке | Подпись ru / kk |
|---|---|---|---|---|
| 0 | < 1 | — (без подсветки) | — | нет жалоб / шағым жоқ |
| 1 | ≥ 1 | `#FAC775` | ink (9.5:1) | 1–2 |
| 2 | ≥ 3 | `#EF9F27` | ink (6.8:1) | 3–5 |
| 3 | ≥ 6 | `#E24B4A` | белая (3.9:1 — для графики норма 3:1) | 6–9 |
| 4 | ≥ 10 | `#A32D2D` | белая (7.1:1) | 10+ |
| исправлено | 7 дней | `#639922` | белая (3.4:1) | исправлено / жөнделді* |

**Число никогда не пишется на цветном фоне уровня 3** (белый на `#E24B4A` — только 3.9:1). Поэтому значок цели = цветной кружок с иконкой категории **+ белая плашка с числом** (ink на белом, 14.8:1). Так число читается на любом уровне.

В CSS уровни доступны как `--b-heat-1…4`, `--b-heat-fixed`; JS берёт их из categories_v2.json (R07). Тест сверяет tokens.css с JSON.

\* «түзетілді» в categories_v2.json — предлагаю «жөнделді» (о ремонте), см. KK_REVIEW.md.

### Шрифт

```css
--b-font: system-ui, -apple-system, "Segoe UI", Roboto, "Noto Sans", "Helvetica Neue", Arial, sans-serif;
--b-font-num: same + font-variant-numeric: tabular-nums;
```

Системный стек: на Windows — Segoe UI (есть все казахские буквы ә ғ қ ң ө ұ ү һ і), на Android — Roboto/Noto, на iOS — SF. Шрифты из интернета **не грузим**.
LOCAL-задача (для офлайн-финала, Codex на ноутбуке): положить в `web/civic/ui-kit/fonts/` шрифт с открытой лицензией OFL и полной кириллицей + казахскими буквами (рекомендация: Inter 4.x, woff2, начертания 400/600/700, ≤ 400 КБ всего) и подключить через `@font-face` первым в стеке с `font-display: swap`. Проверка — строка «Әә Ғғ Ққ Ңң Өө Ұұ Үү Һһ Іі» в витрине без «квадратиков».

| Роль текста | Размер / вес / межстрочный | Токен |
|---|---|---|
| Подпись мелкая (только метаданные, даты) | 14 / 400 / 1.4 | `--b-text-sm` |
| Основной текст | **16** / 400 / 1.5 | `--b-text-md` |
| Важное, кнопки | 16–18 / 600 | `--b-text-lg` (18) |
| Заголовок карточки | 20 / 700 / 1.25 | `--b-text-xl` |

Меньше 14 px не используем нигде (кроме атрибуции карты).

### Отступы, радиусы, тени, движение

- Отступы: 4 · 8 · 12 · 16 · 24 · 32 (`--b-space-1…6`).
- Радиусы: чип 999 (пилюля) · кнопка 12 · карточка 16 · панель/шторка 20.
- Тени: `--b-shadow-1` (шапка, кнопки карты), `--b-shadow-2` (панель, шторка, тост).
- Движение: быстро 200 мс (наведение, чипы) · средне 400 мс (шторка, панель) · медленно 800 мс (перетекание цвета на карте, пульс). Кривая `cubic-bezier(0.22, 1, 0.36, 1)`. При `prefers-reduced-motion` — без пульса и скелетон-блеска, переходы 0 мс.
- Слои (`z-index`): карта 0 · подсветка 1 · легенда/фильтры 10 · кнопки карты 20 · панель/шторка 30 · шапка 40 · тост 50 · модальное окно 60.

## 4. Тексты и язык (`web/civic/i18n/`)

- Весь видимый текст — через `Birge.i18n.t('ключ', {параметры})` или атрибут `data-i18n="ключ"`. В HTML и JS нет «голых» русских строк.
- Ключи: `<модуль>.<экран>.<элемент>`; общие ключи — `common.*`, категории — `category.<id>` (генерируются из categories_v2.json), уровни — `heat.level.<n>`, статусы — `status.<id>`, этапы — `stage.<id>`. Префиксы модулей: `shell` (R01), `heat` (R07), `akim` (R08), `feedback` (R09), `proposals` (R06), `build3d` (R05), `map`/`editor` (R12), `labeling` (R02).
- Новые ключи роль присылает в своём `INTEGRATION.txt` блоком `I18N_KEYS` (ключ | ru | контекст: где показывается, максимум символов). R11 переводит и добавляет в ru.json/kk.json.
- Числа: `1 666` (неразрывный пробел), десятичная запятая «4,5». Даты: ru «11 окт», kk «11 қазан»; время «10:00».
- Склонения: ru — формы one/few/many («1 человек / 2 человека / 5 человек»), kk — одна форма (после числа существительное в единственном числе: «12 адам»).
- Переключатель **ҚАЗ | РУС** — в шапке справа, всегда виден; выбор хранится в `localStorage['birge.lang']`; `<html lang>` меняется. Переключение без перезагрузки страницы.
- Отсутствующий казахский ключ → русский текст + предупреждение в консоли (один раз на ключ). Отсутствующий везде → показывается сам ключ (чтобы приёмка увидела).

## 5. Экраны

Обозначения: `[Кнопка]` — кнопка, `( )` — чип, `●` — цвет уровня, `▸` — прокрутка. Все тексты даны по-русски; казахские — в kk.json.

### 5.1 Карта акимата (R07 + R01), 1366×768 — главный экран демо

```
┌ шапка ──────────────────────────────────────────────────────────────────────────────┐
│ Birge   [🔍 Поиск улицы, объекта…]          [Карта|Картина дня] [Акимат|Житель] [ҚАЗ|РУС] │
└─────────────────────────────────────────────────────────────────────────────────────┘
 (Все категории ▾) (7 дн | 30 дн | 90 дн) (Район: Нура ▾) [Сбросить]
                                                          ┌ Горячие места · 30 дней ───┐
        ●12 Остановка «Нура»                               │ 1 ●12 Остановка «Нура»      │
   ━━━━━━━━━━━ (участок улицы, толщина по весу)            │      Остановки · 12 чел.    │
                     ▓▓▓ двор (заливка)                     │ 2 ● 8 ул. Е-10, от … до …   │
                                                   [＋][－]  │      Снег и гололёд · 8     │
 ┌ Легенда ────────────┐                           [◎][3D]  │ 3 ● 5 Двор на ул. Ұлы Дала  │
 │ ●1–2 ●3–5 ●6–9 ●10+ │                                    │ …                           │
 │ ● исправлено        │                                    │ [Показать все на карте]     │
 └─────────────────────┘                                    └─────────────────────────────┘
```

- По умолчанию в панели — «Горячие места» (топ по весу). Клик по строке или по значку на карте → карточка цели (5.2), карта плавно (600 мс) центрирует цель, не меняя наклон.
- Смысловой зум: z < 12 — районы (заливка + число в центре района); 12–15 — дворы и участки; ≥ 15 — значки объектов.
- Фильтры: чип «Все категории» открывает выпадающий список 12 категорий (иконка + подпись, множественный выбор), период — сегменты 7/30/90, район — выпадающий список. «Сбросить» видна, только если что-то выбрано.
- Состояния: загрузка — скелетон списка в панели, на карте ничего не мигает; пусто — «За 30 дней жалоб нет. Измените период или район»; ошибка — «Нет связи с сервером. Повторить».

### 5.2 Карточка цели (панель справа / шторка снизу)

```
┌───────────────────────────────────────┐
│ ← Горячие места                    ✕  │
│ ОСТАНОВКА                              │  14, ink-2, заглавные
│ Остановка «Нура»                       │  20/700
│ ●12  Высокий уровень · 10+             │  значок + слово
│ Сообщили 12 человек · за 14 дней       │  16

```

- Название цели по типу: «Остановка «…»», «Двор на ул. …», «Участок ул. … от … до …», «Примерное место» (если точного нет — с пометкой).
- Акимат видит сгруппированные жалобы по категориям и (только сотрудник) тексты без личных данных. **Житель видит только цель и число**: «Сообщили 12 человек», главная кнопка — **[Я тоже]**, после нажатия — «Вы с нами. Сообщили 13 человек» и кнопка неактивна («Вы уже отметились»).
- После «Отметить исправленным»: значок становится зелёным, слово «Исправлено», тост «Отмечено как исправленное. Отменить».

## 6. Состояния (у каждого блока все четыре)

| Состояние | Как выглядит | Пример текста ru |
|---|---|---|
| Загрузка | скелетон по форме содержимого, не спиннер на весь экран | — (`aria-label` «Загружаем…») |
| Пусто | `.b-empty`: иконка, заголовок, подсказка, действие | «Сегодня новых обращений нет» |
| Ошибка | `.b-error`: что случилось + действие | «Нет связи с сервером. Проверьте интернет» [Повторить] |
| Успех | тост 4 с | «Обращение отправлено» |
