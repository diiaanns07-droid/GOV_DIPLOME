## 1. Как раздел попадает в сборку (одинаково для R06 и R13)

```js
// web/civic/ideas/ideas.js (R06) или web/civic/ask/ask.js (R13) — глобальное имя ищет оболочка R01
window.BirgeIdeas = { mount(root, opts) { … return { destroy(), setLang(lang) }; } };   // R06: #ideas и #projects
window.BirgeAsk   = { mount(root, opts) { … return { destroy(), setLang(lang) }; } };   // R13: #questions (оба вида)
// opts: { api: {v2(method, path, body), ApiError}, lang, role: "resident"|"akimat", section, titleTag: "h2",
//         t(key, params), openTarget(kind, id), openSection(id), close() }
```

- Пункт меню появляется сам, когда модуль есть в сборке (без модуля — меню как сейчас). Подпись пункта — ключ меню R11,
  свой заголовок раздела модуль рисует `<h2>` (`idea.title`, `ask.title`).
- Ноутбук: колонка контента **до 720 px** по центру листа оболочки (лист 960, поля по 24); телефон — во весь экран, поля 16.
- Тексты — только `opts.t(key, params)`; числа — формами (`idea.votes`, `ask.votes`), даты — `BirgeI18n.formatDate`.
- Состояния — `BirgeUI.state(el, "loading" | "empty" | "error", {title, text, action})` из ui-kit; `"error"` без
  текста = «Сервермен байланыс жоқ» + «Қайталау» (`common.state.network_*`). Пустая вкладка — `BirgeUI.state(el, "empty",
  {title: t("idea.empty")})` / `ask.empty`, не пустой лист.
- `setLang(lang)` перерисовывает **и заголовок, и вкладки** (R09 «Обращения» на этом спотыкался — разбор 5).
- `destroy()` снимает таймеры и слушатели; со слоя карты (R06) снимает свои источники MapLibre.
- Компоненты ui-kit (все есть в витрине `web/civic/ui-kit/index.html`, раздел «2-толқын бөлімдері»):
  `bk-btn--primary` (одна на экран), `bk-btn` / `bk-btn--ghost` (второстепенные), **`bk-tabs` + `BirgeUI.tabs(el,
  onChange)`** (вкладки: `role=tablist/tab`, стрелки, затухание края на 375), `bk-card`, `bk-tag--demo`, `bk-banner`
  (правило — без плашки, серый текст с ⓘ; чистый дизайн 12 окт, `CLEAN_PASS.md`), **`<details class="bk-details">`** («Толығырақ»), `bk-field` + `bk-field__hint`,
  `bk-chip` (выбор объекта), `bk-toast`, `bk-idea-badge` + токен `--idea` (значок идеи). Свои стили — только раскладка.

### 3.2 Акимат — `#questions` (меню «Тағы → Тұрғындар сұрақтары»)
- Вкладки `ask.staff.queue` (с числом) · `ask.staff.top` · `ask.staff.answered`.
- «Тексеруде»: текст + район + «Жариялау» (главная) / «Себебін көрсетіп қабылдамау» (`ask.staff.reason_label`, обязательно).
- «Аптаның үздік 5 сұрағы»: строка `ask.staff.week` («Осы аптада жауап берілді: {n} / 5»); у каждого — голоса и форма
  ответа `ask.staff.answer_ru` / `ask.staff.answer_kk` (достаточно одного языка) → `ask.staff.answer_send`. Неделя — с понедельника 00:00 по Астане
  (UTC+5), топ фиксируется на момент ответа.
- Вход — та же сессия сотрудника оболочки (`opts.api` уже несёт CSRF); без входа — `proposal.need_staff`.

### 3.3 «Пульс района» — формат уже есть у R08, R13 даёт метод
R08 `ui/civic_akim/pulse.py` (в FINAL-2) уже показывает 1–5 тревог: `spike`, `spike_new`, `spike_city`, `new_hot`,
`metoo` — с текстами `akim.pulse.*` и `akim.pulse.reason.*` (в словаре). Метод R08 — «7 дней против среднего за 4 недели,
×2 и ≥ 5 сообщений». **R13 не меняет формат и тексты**, а:
1. проверяет метод на синтетической истории (`ml/civic_forecast/history.py`): сколько тревог в обычную неделю (цель — 0–2)
   и ловит ли он заложенные всплески (снегопад, отопление); порог/окно меняет только с этой таблицей;
2. если нужен свой расчёт — функция с тем же выходом `{kind, category, district, k, n, base, place, target}`, `k`
   округлён до 0,5; новые причины — только ключом словаря (пришлите `I18N-KEYS R13`, переведу).
Блок прогноза «На что обратить внимание в следующем месяце» — ключи `forecast.*` (в словаре), всегда с
`forecast.prototype` («прототип на синтетике»); показывать не больше 5 пунктов; без процентов на демо-экране акима,
кроме `forecast.risk` в «Толығырақ».

### 3.4 Чего НЕ должно быть
- Вопросы на карте; комментарии и ветки; имена жителей; рейтинги районов.
- Голос без ограничения «одно устройство — один голос» (R15); голос за отвеченный вопрос.
- «Әкімнің жауабы» в демо без метки «Үлгі»; ответы от имени реального акима с фамилией.
- Статистические термины в тревогах «Пульса» («z-score», «σ», «p-value»); тревога без ссылки на место.
