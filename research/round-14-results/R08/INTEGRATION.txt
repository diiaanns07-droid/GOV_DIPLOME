R08 · «Картина дня» для акима — как подключить к общей сборке (раунд 14)
=========================================================================

Мои пути: ui/civic_akim/, web/civic/akim/, tests/civic/R08/, research/round-14-results/R08/.
Чужие файлы я не менял. Ниже — что сделать владельцам соседних модулей. Применяет R01.

1. R01 · ui/web_server.py — маршрут API (CONTRACT §7)
------------------------------------------------------
    from ui.civic_akim.api import handle_get as akim_get        # рядом с импортом civic_heat
    ...
    # в do_GET, до общей обработки /api/civic/v1:
    if path == "/api/civic/v2/akim/summary":
        status, body = akim_get(path, parse_qs(parsed.query))
        self.json_reply(status, body)
        return

  - Только GET, без тела. Ответ без текстов жалоб и без данных жителей (тест test_r08_api.py::test_no_resident_texts_in_answer).
    Если «Картину дня» нужно показывать только сотрудникам акимата — проверка роли та же, что у модерации
    (решает R01; в ответе нет персональных данных, поэтому сейчас открыто, как /heat).
  - Ошибки: 400 {"error":"bad_request","field":"date|district"}; 500 {"error":"akim_failed"} — сервер не падает.
  - Источник данных подключается сам: ui.civic_heat.default_service() (R07) → его записи жалоб (R09).
    Если R01 настраивает тепловую карту явно (civic_heat.configure(source=…)), то после этого вызвать
        import ui.civic_akim as civic_akim
        civic_akim.configure()            # возьмёт уже настроенный civic_heat.default_service()
    либо civic_akim.configure(heat=…, records=…, objects=…, proposals=…).

2. R01 · ui/web_server.py — файлы страницы (явный список CIVIC_ASSETS, без листинга папок)
------------------------------------------------------------------------------------------
    CIVIC_ASSETS += ("akim/index.html", "akim/akim.js", "akim/akim.css", "akim/akim.i18n.json")
  .html нет в словаре типов — добавить ".html": "text/html". Страница ссылается на ../ui-kit/tokens.css,
  ../ui-kit/components.css, ../ui-kit/icons.svg, ../i18n/i18n.js, ../i18n/ru.json, ../i18n/kk.json —
  они должны быть в CIVIC_ASSETS (их уже добавляет R11/R01).
  Адрес страницы: /civic/akim/ (или /civic/akim/index.html). Пункт «Картина дня» в шапке оболочки
  (common.nav.day) — ссылка на этот адрес; ссылка «Карта» на странице ведёт на "/".

  Вариант «внутри оболочки» (без перехода на другую страницу):
    <link rel="stylesheet" href="/civic/akim/akim.css"> <script src="/civic/akim/akim.js"></script>
    const view = BirgeAkim.mount(элемент, { apiBase: "/api/civic/v2", mapHref: "/#target={kind}:{id}&days={days}", syncUrl: false });
    view.destroy() — при уходе с вкладки.

3. R01 + R07 · переход «горячее место → цель на карте»
-----------------------------------------------------
  Клик по строке «Горячие места» сначала отправляет отменяемое событие на document:
      "birge:open-target"  detail = {target: {kind, id, label_ru, label_kk}, days: 7, from: "akim"}
  Если оболочка открыла цель у себя — event.preventDefault(), перехода не будет.
  Иначе браузер идёт по ссылке mapHref, по умолчанию "/#target=<kind>:<id>&days=7"
  (по образцу существующего "#object=<id>" в shell.js). Нужно, чтобы карта R07/оболочка R01 понимали
  этот адрес: открыть карточку цели, период 7 дней (тогда число в карточке = числу в списке).
  Готовый ответ для карточки уже есть у R07: GET /api/civic/v2/heat/target?kind=…&id=…&days=7.

4. R07 · ui/civic_heat — просьба (минимальный patch)
---------------------------------------------------
  «Картина дня» берёт записи жалоб у того же HeatService, что отвечает карте, — поэтому числа совпадают.
  Сейчас для этого используются внутренние _records и _generation. Прошу публичный метод:

    --- a/ui/civic_heat/service.py
    +++ b/ui/civic_heat/service.py
    @@ class HeatService:
    +    def records(self, since=None):
    +        """Записи жалоб v2 — те же, по которым считается карта (для «Картины дня» R08)."""
    +        return self._records(since)
    +
    +    @property
    +    def generation(self) -> int:
    +        """Растёт при каждом invalidate(): по нему R08 сбрасывает свой кэш."""
    +        return self._generation

  Код R08 уже сначала ищет публичный records(), а _records — запасной путь (ui/civic_akim/sources.py).
  Если R07 поменяет порядок/фильтры в heat() — тест tests/civic/R08/test_r08_heat_match.py это поймает.

5. R09 · новые жалобы
---------------------
  После create / metoo / set_status R09 уже вызывает (или должен вызывать) ui.civic_heat.invalidate().
  Отдельно сбрасывать «Картину дня» не нужно: ключ её кэша включает поколение кэша карты (30 с максимум).
  Сроки: у R09 RESPONSE_DAYS — срок ПЕРВОГО ОТВЕТА (новое → принято); у R08 DEADLINE_DAYS
  (ui/civic_akim/deadlines.py) — срок ИСПРАВЛЕНИЯ, по нему «Просрочено» у акима. Оба — демо-нормативы.
  Если владелец решит, что «просрочено» = «нет первого ответа», поменять одну функцию _kpi() → at().

6. R06 · объекты с отставанием и предложения (prompt R06 п.5)
-------------------------------------------------------------
  Пока функций R06 нет, «Картина дня» показывает фикстуры ui/civic_akim/fixtures/objects_demo.json и
  proposals_demo.json (synthetic, demo: true, без координат). Как только в ui/civic_store появятся
  функции, они подхватятся сами (ищутся по именам по порядку):
     объекты:      akim_objects | lagging_objects | late_objects | objects_for_akim   (district=None) -> list[dict]
     предложения:  akim_proposals | list_proposals | proposals_for_akim               (district=None) -> list[dict]
  Поля объекта (CONTRACT §7): id, kind, title_ru, title_kk, district, stage, planned_end, forecast_end,
     delay_days, stale, updated_at, demo (+ geometry, если есть реальное место).
     delay_days и stale R08 досчитает сам, если их нет (forecast_end − planned_end; > 14 дней без обновления).
  Поля предложения: id, kind, title_ru, title_kk, district, status ("proposal"), created_at, votes_up, votes_down, demo.
  Можно и явно: civic_akim.configure(objects=lambda district, today: …, proposals=lambda district, today: …).

7. R11 · новые ключи перевода (сейчас лежат в web/civic/akim/akim.i18n.json)
--------------------------------------------------------------------------
  Общий словарь всегда главнее: перенесите ключи в web/civic/i18n/ru.json и kk.json, и файл можно удалить.
  ключ | ru | где на экране
  akim.updated | Данные на {time} | строка под заголовком (сегодня)
  akim.updated_end | Данные на конец дня | строка под заголовком (прошлый день)
  akim.compare_to | сравнение с {date} | строка под заголовком
  akim.date.today | Сегодня | кнопка возврата к сегодняшнему дню; кнопка в ошибке «дата в будущем»
  akim.district.all_city | Весь город | строка под заголовком без фильтра района
  akim.delta.new | неделю назад не было | изменение в карточке числа, если неделю назад было 0
  akim.delta.ratio | в {n} раз(а) больше (формы) | изменение ×2 и больше
  akim.kpi.week | За 7 дней: {n} | карточка «Новые обращения», нижняя строка
  akim.kpi.waiting | Ещё {n} ждёт/ждут ответа (формы) | карточка «В работе», нижняя строка
  akim.kpi.overdue_hint | Не исправлено в срок | карточка «Просрочено»
  akim.kpi.fixed_hint | Жители видят статус «исправлено» | карточка «Исправлено за неделю»
  akim.summary.title | Коротко о дне | заголовок блока сводки
  akim.hot.hint | За 7 дней · сколько человек сообщили, как на карте | под «Горячие места»
  akim.hot.empty | За 7 дней нерешённых жалоб нет | пустой список горячих мест
  akim.hot.open | Открыть на карте: {name} | aria-label строки горячего места
  akim.topics.hint | За 7 дней · человек | под «Темы»
  akim.topics.empty | За 7 дней жалоб нет | пустые темы
  akim.districts.hint | Весь город за 7 дней · человек | под «Районы»
  akim.districts.selected | выбран | метка у выбранного района
  akim.districts.pick | Показать район {name} | aria-label полосы района
  akim.late.empty | Все объекты идут по графику | пустой список отстающих
  akim.late.stale_title | Давно не обновлялись | подзаголовок в блоке объектов
  akim.late.stage | Этап: {name} | строка объекта
  akim.proposals.new | {n} новое/новых за неделю (формы) | блок предложений
  akim.proposals.votes | За: {up} · Против: {down} | строка предложения
  akim.proposals.empty | Новых предложений нет | пустой блок предложений
  akim.proposals.new_badge | новое | метка нового предложения
  akim.unavailable | Карта жалоб пока не отвечает. Числа появятся, когда она заработает. | блоки без R07
  akim.demo_note | Числа посчитаны по примерам жалоб и объектов, а не по настоящим обращениям | рядом с меткой «Пример»
