R01 · раунд 14 · RUN — как запустить Birge на Windows с нуля

Ветка R01: claude/sharp-dijkstra-0t87gl (актуальный SHA сборки — research/handoffs/astana/R01/round14/STATUS.md).

=====================================================================================================
1. Первый запуск на ноутбуке владельца (Windows 10/11)
=====================================================================================================
1) Нужен Python 3.11–3.14 (https://www.python.org/downloads/, галочка «Add python.exe to PATH»). Интернет нужен
   только для первого pip install.
2) Получить сборку:
       cd C:\Users\LEGION\Desktop\hackalem\hack-d3b2c613-stupits
       git fetch origin
       git switch --detach origin/claude/sharp-dijkstra-0t87gl      (или нужный SHA сборки B1/B2/FINAL)
3) Запуск одной командой (двойной щелчок или из консоли):
       run-city.bat
   Что делает: создаёт .venv, ставит зависимости (первый раз несколько минут), загружает СИНТЕТИЧЕСКИЙ демо-срез
   Астаны в отдельную базу .runtime\round11-local.sqlite3 и открывает http://127.0.0.1:8611/
   В консоли должно быть:
       civic-v1: store=ready, feedback=ready, scenarios=ready, assistant=ready
       civic-demo: R06 synthetic projects 5 (new 5), object stages …
       civic-v2: ready R04, R06, R07, R08, R09, R12, R13
       Birge: http://127.0.0.1:8611
   Остановить — Ctrl+C. Порт занят — закрыть прежнее окно или:  set PORT=8612 && run-city.bat

3б) Карта без интернета (офлайн-подложка Codex/OFFLINE, в сборке с ночи 10→11 окт): положите архив тайлов Астаны
   (10 МБ, не в Git) в  <папка сборки>\data\civic\astana\tiles\astana.pmtiles
   — на ноутбуке он уже есть: C:\Users\LEGION\Desktop\hackalem\birge-offline\data\civic\astana\tiles\astana.pmtiles
   (SHA256 7c8343ad…07949). Скачать заново — download_tiles.ps1 из ветки claude/r14-offline (research/round-14-results/
   OFFLINE/RUN.txt). Есть архив — карта всегда локальная (улицы, подписи, 3D-здания); нет — OpenFreeMap из интернета,
   без интернета — упрощённый фон с осями улиц. Проверка: http://127.0.0.1:8611/civic/offline/status.json → available: true.
4) Демо-данные сервер готовит сам при CIVIC_DEMO=1 (run-city.bat): этапы демо-объектов и 5 демо-предложений R06,
   3 синтетические жалобы «Освещение» у остановки «Хан Шатыр» (для шага «Я тоже»). Всё помечено «Пример»; повторный
   запуск ничего не дублирует. Поэтому первая жалоба на показе получит номер B-0004. Ручной seed-r14-demo не нужен.
5) Вход сотрудника акимата (нужен для «Взять в работу», этапов объектов, предложений; один раз):
       .venv\Scripts\python -m ui.civic_store --db .runtime\round11-local.sqlite3 create-editor operator
   Пароль вводится скрыто. В интерфейсе: «Для сотрудников» → логин и пароль.

=====================================================================================================
2. Что пользователь может сделать сейчас (сборка B2 — SHA в STATUS.md)
=====================================================================================================
- Шапка Birge: «Карта | Картина дня», «Акимат | Житель», «ҚАЗ | РУС» (выбор запоминается). Ниже 1024 px — ≡ Меню.
- Житель: «Сообщить о проблеме» → место на карте → «Это здесь? …» (остановка, участок улицы или двор — R12) → текст;
  категория подсказывается (R04 + словарь R03), похожие обращения — «Я тоже» → номер обращения (B-0004 на демо-базе);
  «Мои обращения» в шапке (на телефоне — в меню ≡).
- Карта жалоб (панель справа): районы → дворы/участки/остановки, фильтры, «Горячие места», карточка цели; демо-жалобы
  помечены «Пример».
- Акимат: внизу карты «Что построить?» (R05): сквер, площадка, спортплощадка, остановка, освещение улицы → поставить на
  карту → «Поставить» (нужен вход сотрудника) → объект «строится» в 3D с табличкой «Проект · 2027». Житель в карточке
  проекта голосует «За / Против» (один голос с устройства, R06). Акимат может «Удалить» (проект снимается).
- «Картина дня»: KPI, сводка, темы, районы, горячие места, объекты с отставанием и предложения (R06 после шага 4).
  Карточка цели: «Взять в работу», «Отметить исправленным» (после входа) → цель зелёная «исправлено».
- Прогноз проблемных мест (R13) — только API: /api/civic/v2/forecast (прототип на синтетике, на экран не выведен).
- Старые режимы: только по ссылке …/#training и …/#school; инструменты раунда 13 — …/?tools=all.
- API v2: http://127.0.0.1:8611/api/civic/v2/modules — какие модули ролей подключены.

Подложка карты (улицы, 3D-здания) грузится с OpenFreeMap — нужен интернет; без него — упрощённый фон с сообщением.

3. Проверки (разработчику; облако или ноутбук с Node 20+ и Playwright)
=====================================================================================================
    python -m pytest -q tests                              весь набор (на B2: см. BUILD_LOG.md)
    python -m pytest -q tests/civic/R01                    шлюз v1/v2 и стыки R01
    bash tests/civic/R01/run_checks.sh <папка>             всё сразу: pytest, web_check, node, браузер
    node tests/civic/R01/browser/r14_shell.cjs <папка>     шапка Birge: 1366 и 375, ru и kk (скриншоты в папке)
    node tests/civic/R01/browser/r14_b2.cjs <папка>        путь демо B2: предложение в 3D, голос жителя, «Удалить»
Тесты R03 запускайте в общем прогоне (pytest tests) или отдельно (pytest tests/civic/R03/round14), не списком
папок вместе с другими — см. INTEGRATION.txt §9.
Windows без bash: те же команды python/node по одной (run_checks.sh — список шагов).

=====================================================================================================
4. Если что-то не так
=====================================================================================================
- «Порт занят» — другое окно приложения открыто; закройте его или задайте PORT.
- Белая страница / нет шапки — Ctrl+F5 (старый кэш браузера); проверьте, что консоль сервера без ошибок.
- civic-v1: store=unavailable — не установлены зависимости (.venv\Scripts\python -m pip install -r requirements.txt).
- Сбросить демо-базу: закрыть приложение, удалить .runtime\round11-local.sqlite3*, снова run-city.bat.
