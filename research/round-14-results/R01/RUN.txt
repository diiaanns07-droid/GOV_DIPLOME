R01 · раунд 14 · RUN — как запустить Birge на Windows с нуля

Ветка R01: claude/sharp-dijkstra-0t87gl (актуальный SHA сборки — research/handoffs/astana/R01/round14/STATUS.md).

=====================================================================================================
1. Первый запуск на ноутбуке владельца (Windows 10/11)
=====================================================================================================
1) Нужен Python 3.11–3.14 (https://www.python.org/downloads/, галочка «Add python.exe to PATH»). Интернет нужен
   только для первого pip install.
2) Получить сборку:
       cd C:\Users\LEGION\Desktop\hackalem\hack-d3b2c613-stupits
       git fetch origin
       git switch --detach origin/claude/sharp-dijkstra-0t87gl      (или нужный SHA сборки B1/B2/FINAL)
3) Запуск одной командой (двойной щелчок или из консоли):
       run-city.bat
   Что делает: создаёт .venv, ставит зависимости (первый раз несколько минут), загружает СИНТЕТИЧЕСКИЙ демо-срез
   Астаны в отдельную базу .runtime\round11-local.sqlite3 и открывает http://127.0.0.1:8611/
   В консоли должно быть:
       civic-v1: store=ready, feedback=ready, scenarios=ready, assistant=ready
       civic-v2: ready none yet            (по мере подключения модулей ролей здесь появятся R04, R06, R07, R08, R09, R12)
       Birge: http://127.0.0.1:8611
   Остановить — Ctrl+C. Порт занят — закрыть прежнее окно или:  set PORT=8612 && run-city.bat

4) Вход сотрудника акимата (нужен для «Взять в работу», этапов объектов, предложений; один раз):
       .venv\Scripts\python -m ui.civic_store --db .runtime\round11-local.sqlite3 create-editor operator
   Пароль вводится скрыто. В интерфейсе: «Для сотрудников» → логин и пароль.

=====================================================================================================
2. Что пользователь может сделать сейчас (сборка после I0)
=====================================================================================================
- Шапка Birge: «Карта | Картина дня», «Акимат | Житель», «ҚАЗ | РУС» (выбор запоминается в браузере).
  На телефоне (375 px): ≡ Меню → разделы и вид; ҚАЗ/РУС всегда видны.
- Карта: опубликованные записи (все — синтетические «Демо»), карточка записи, сообщение жителя о проблеме с
  квитанцией, кабинет сотрудника (редактор), модерация сообщений — модули раунда 13.
- «Картина дня»: экран R08; пока модуль не сдан — понятное «скоро появится» и кнопка «Вернуться к карте».
- Старые режимы: только по ссылке http://127.0.0.1:8611/#training («Учебная модель») и …/#school («Школы»);
  кнопка «Город» возвращает на карту Birge.
- API v2: http://127.0.0.1:8611/api/civic/v2/modules — какие модули ролей уже подключены.

Подложка карты (улицы, 3D-здания) грузится с OpenFreeMap — нужен интернет; без него — упрощённый фон с сообщением.

3. Проверки (разработчику; облако или ноутбук с Node 20+ и Playwright)
=====================================================================================================
    python -m pytest -q tests                              весь набор (на I0: 1384 passed, 12 skipped)
    python -m pytest -q tests/civic/R01                    шлюз v1/v2 и стыки R01

    node tests/civic/R01/browser/r14_shell.cjs <папка>     шапка Birge: 1366 и 375, ru и kk (скриншоты в папке)
Windows без bash: те же команды python/node по одной (run_checks.sh — список шагов).

=====================================================================================================
4. Если что-то не так
=====================================================================================================
- «Порт занят» — другое окно приложения открыто; закройте его или задайте PORT.
- Белая страница / нет шапки — Ctrl+F5 (старый кэш браузера); проверьте, что консоль сервера без ошибок.
- civic-v1: store=unavailable — не установлены зависимости (.venv\Scripts\python -m pip install -r requirements.txt).
- Сбросить демо-базу: закрыть приложение, удалить .runtime\round11-local.sqlite3*, снова run-city.bat.
