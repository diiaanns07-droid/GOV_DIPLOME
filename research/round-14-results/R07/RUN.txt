R07 · Тепловая карта объектов — как запустить и проверить (Windows / Linux, Python 3.11+, без внешних библиотек)

1. Демо отдельно от общей сборки (пока R01 не подключил маршруты):
     python -m ui.civic_heat.devserver
     открыть http://127.0.0.1:8617/civic/heat/demo.html
   Параметры адреса: ?lang=kk|ru  &role=akimat|resident  &view=nura|city|stops  &target=segment:osm-w1181261286-8  &days=7|30|90  &basemap=online
   Глубокая ссылка (как из «Картины дня»): demo.html#target=segment:osm-w1181261286-8&days=7
   Подложка по умолчанию офлайн — настоящие улицы OSM (без подписей улиц). С интернетом: &basemap=online (OpenFreeMap).

2. Что может сделать пользователь:
   - Акимат: видеть, ЧТО краснеет — участок улицы (линия по форме улицы из OSM), квартал (заливка), остановку (ореол + значок с числом);
     на мелком масштабе — районы с числом; фильтры: категория (12), период 7/30/90 дней, район, «Сбросить»;
     «Горячие места» → карточка цели: «Сообщили 13 человек · за 30 дней», статус и кнопки «Взять в работу» /
     «Отметить исправленным» (цель становится зелёной «исправлено» на 7 дней), «Что пишут жители» (группы похожих
     текстов с числом людей, у примеров метка «Пример»), график по дням, о чём сообщают.
     Легенда — на карте. Пустой фильтр: «За 7 дней жалоб нет» + «Показать 30 дней» / «Сбросить фильтры».
   - Житель (переключатель «Житель»): та же карта мягче, в карточке — «Я тоже» (один раз с устройства, ключ birge.device);
     тексты жалоб жителю не показываются.
   - Кнопка «Пример жалобы» добавляет синтетическую жалобу на выбранную цель: цвет плавно меняется, на цели пульс.
   - Ошибки: «Нет связи · Повторить»; лимит действий (429) и «нужен вход» (401/403) — понятным текстом без «Повторить».
   ҚАЗ / РУС — в шапке, выбор запоминается. Все жалобы — demo (synthetic); места настоящие (OSM):
   остановки «Хан Шатыр», «Центр материнства и детства»…, дворы ЖК «Evolution», «Алматау»…, детские и контейнерные площадки.

3. Проверки:
     python -m pytest tests/civic/R07 -q                    # расчёт, API, точность по OSM, скорость, словарь ru/kk
     python -m ui.civic_heat.devserver &                     # затем браузерные проверки и скриншоты:
     NODE_PATH=$(npm root -g) node tests/civic/R07/browser/shots.js   # Playwright + Chromium, 50 сценариев → screens/ + CHECKS.json
   Перед браузерными проверками перезапустить devserver: сценарий «пульс» добавляет жалобы, и числа следующего прогона сдвигаются.
   В каждом кадре: нет ошибок консоли и прокрутки вбок, нет ключей heat.* и слова «демо», зона нажатия ≥ 48 px, видимая высота
   кнопок ≥ 44 px, контраст главных кнопок ≥ 4,5, легенда на карте. Отдельно: выбор места жалобой по значку, клавиатура
   (одна остановка Tab на значки, стрелки, Esc), загрузка / нет связи / «Повторить», лимит 429 и 403, наклон 3D,
   «меньше движения», легенда телефона в одну строку, слабый id устройства R05 не перенимается.
   Проверка точности карты R10 (только чтение):  python3 -I <ветка R10>/tests/civic/R10/accuracy.py --root .   (R07: 7/7 PASS)
   Проверка демо-чисел кодом R08 (нужен модуль R08 ui/civic_akim — сборка R01 или копия ветки R08):
     python tests/civic/R07/tune_demo_seed.py <папка, где лежит ui/civic_akim> 10   # ожидается «OK seed 20261014 …»

4. Пересобрать фикстуры из OSM (данные LOCAL-1 data/civic/astana/osm-objects/ уже в ветке):
     python -m ui.civic_heat.build_fixtures                  # ui/civic_heat/fixtures/targets_demo.json, web/civic/heat/fixtures/basemap-*.geojson
     python -m ui.civic_heat.demo_seed                       # сводка демо-набора (483 жалобы, 952 человека, 54 цели)

5. Подключение к ui/web_server.py и оболочке — INTEGRATION.txt (патч проверен на настоящем сервере, см. DELIVERY.json).
