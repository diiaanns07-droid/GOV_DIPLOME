R12 · раунд 14 · как запустить и проверить (из корня репозитория, ветка claude/tender-brahmagupta-ef5ztl)
Нужно: python3 (только stdlib; для тестов — pytest), Node 22, Playwright + Chromium (локально или `npm root -g`).
Без Playwright браузерные проверки пропускаются (NOT_RUN). Ничего не пишется в репозиторий, кроме явных команд сборки.

1. ДВИЖОК ТОЧНОСТИ (engine/civic_geo)
   python3 -m pytest -q tests/civic/R12/test_civic_geo.py                  # 25 тестов: фикстура + настоящий граф
   python3 -m engine.civic_geo report                                      # отчёт точности по всем объектам карты
   python3 -m engine.civic_geo report --json research/round-14-results/R12/accuracy_report.json
   python3 -m engine.civic_geo report --objects <выгрузка записей {items:[...]}>   # линии из хранилища идут по улице?
   python3 -m engine.civic_geo bench 3000                                  # время ответа /targets
   python3 -m engine.civic_geo targets 71.4289 51.1716 roads               # кандидаты привязки жалобы
   python3 -m engine.civic_geo segment 71.4251,51.1712 71.4326,51.1719 --kind road   # участок улицы по графу

2. ПЕРЕСБОРКА ДАННЫХ (data/civic/astana/geo)
   python3 -m engine.civic_geo build-way-tags      # тип дороги и казахские имена из снимка пешеходной сети
   python3 -m engine.civic_geo build-data          # objects/yards/cells/SOURCE (после LOCAL-1 — полные данные)
   python3 -m engine.civic_geo snap-demo           # demo_snapped.json + копия web/civic/map/demo_snapped.json

5. ЧТО ТЕПЕРЬ МОЖЕТ ПОЛЬЗОВАТЕЛЬ
   Житель/акимат: «перекрытая улица» на карте идёт точно по оси улицы Сакена Сейфуллина (форма OSM), а не напрямую
   через дома; запись без точного места видна мягкой областью «примерное место»; при наклоне 3D дома закрывают линию,
   значки остаются сверху; в карточке написано «Участок улицы по карте OSM: …».
   Сотрудник: «Участок улицы» — два нажатия (начало прилипает к оси, конец — линия строится по улице), «Готово»;
   «Проезжая часть / Тротуар»; точка рядом с остановкой ставится точно на объект OSM одним нажатием; «Выбрать двор»
   выделяет двор OSM целиком (538 дворов OSM). Нарисовать линию «от руки» больше нельзя. У сохранённой записи —
   блок «Этап работ» R06 (если на странице подключён stage-editor.js).
   Соседи: /targets даёт 1–3 кандидата привязки жалобы за < 1 мс; target_geometry даёт форму любой цели по id.
