1. R01 · API v2 (ui/web_server.py, таблица V2_HANDLERS)
=====================================================================================================
Уже работает без правок: GET /targets?lon&lat&category -> engine.civic_geo.targets(lon, lat, category=None)
  - category необязательна: без неё — по одному лучшему кандидату каждого вида (объект / участок / двор).
  - ответ {"candidates":[{"target":{kind,id,label_ru,label_kk,...}, "distance_m", "geometry", "point", "approximate"}]}
  - ошибки — исключение с status=400, code, message (по-русски) — как требует шлюз.

Добавить строки (все GET, только чтение, без сессии сотрудника):
  R01: GET /street-segment?from=lon,lat&to=lon,lat[&kind=road|foot] -> engine.civic_geo.segment_between(from_point, to_point, kind=None)
  R01: GET /street-snap?lon&lat[&kind=road|foot]                   -> engine.civic_geo.street_snap(lon, lat, kind=None)
  R01: GET /objects-near?lon&lat                                    -> engine.civic_geo.objects_near(lon, lat)
  R01: GET /yard?lon&lat                                            -> engine.civic_geo.yard_at(lon, lat)
  R01: GET /geo/status                                              -> engine.civic_geo.geo_status()
  from/to передавать строкой «lon,lat» (или списком [lon, lat]); kind — "road" | "foot" | пусто.
  Если удобнее одним маршрутом: engine.civic_geo.api.handle(path_без_префикса, query_как_parse_qs) -> (код, тело) | None.
Прогрев (необязательно, чтобы первый житель не ждал ~1,7 с): при старте сервера в фоновом потоке
  threading.Thread(target=importlib.import_module("engine.civic_geo.api").warm_up, daemon=True).start()
Редактор R12 обращается к этим маршрутам сам (fetch same-origin, префикс /api/civic/v2; опция geoPrefix).
Пока маршрутов нет — кнопки «Участок улицы» и «Выбрать двор» пишут «Привязка к улицам на этом сервере не
подключена» и линию не рисуют; точка и «Площадь по углам» работают.

линию сплошной, а отчёт точности — отличать её от старых линий «от руки» без проверки по графу.

каждая LineString должна идти по улице (≤ 5 м от рёбер графа); для приёмки R10.
Демо-срез: если ваш seed берёт data/civic/astana/demo_synthetic.json, можно взять геометрию линий из
data/civic/astana/geo/demo_snapped.json (items[id].geometry при status=snapped) — тогда в хранилище сразу линии по улице.
