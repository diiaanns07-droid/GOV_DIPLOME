# K06, раунд 5 (REVIEW): числа и подписи в демо city-evidence

Проверяемая сборка (baseline): `claude/beautiful-clarke-sbzomj` @ `0bf27deb8549b325b34a9610402613d745544edb`,
`prototypes/city-evidence/`. Данные — Overture/OSM, по одному квадрату 2×2 км в Шымкенте и Астане (вторичные, не реестр).

## Файлы
- `extract_build.py` — побайтное извлечение `prototypes/city-evidence` из любого коммита (`git show` → `write_bytes`,
  проверка git blob id), манифест SHA256 в `_extract_manifest.json`.
- `audit_numbers.py` — аудит `--app-root DIR` или `--url URL`; сохраняет наблюдаемые значения и источник (файл + SHA256).
- `test_audit_numbers.py` — 11 тестов: baseline без FAIL, 8 внедрённых дефектов дают FAIL, честная подпись — PASS, режим `--url`.
- `geo_oracle.py` — WGS84-оракул (Vincenty), побайтная копия из K06 раунда 4 @ 33684f9 (sha256 94fa2654…).
- `rendered_labels.cjs` + `rendered_check.py` — проверка ОТРИСОВАННОЙ страницы (Playwright Chromium):
  сводка среза, карточка дороги за краем и внутренней дороги, «расстояние от точки», весь видимый текст.
- `out/baseline_0bf27de.json`, `out/baseline_0bf27de_url.json` — аудит кода и данных (`--app-root` / `--url`).
- `out/rendered_baseline_0bf27de.json`, `out/rendered_baseline_0bf27de_url.json` — отрисованные подписи (`file://` / `--url`).

## Проверки аудита (по каждому городу)
| ID | Что |
|---|---|
| N1 | число записей: `counts` = длина массива = наблюдения K05 |
| N2 | подписи количеств: «записей в срезе / квадрате», «не реестр города»; нет «школ в городе» |
| N3 | мощность, официальный реестр, население — `null` (неизвестно), а не 0 |
| N4 | число сегментов и флаг «выходит за край», пересчитанные по координатам |
| N5 | км дорог: полная геометрия и длина внутри квадрата; если сумма показана, подпись должна говорить «за краем / вся геометрия» |
| N6 | длина сегмента и оракул WGS84 (допуск 0,5 % + округление); пометка «вся линия, выходит за квадрат» |
| N7 | расстояние от точки: формула app.js и оракул; подписи «по прямой», «нижняя граница пешего пути»; нет минут |
| N8 | `data.js` и закреплённые `inputs/k10` (SHA256, длины, bbox) — только в режиме `--app-root` |

## Результат baseline 0bf27de — 12 PASS, 4 WARN, 0 FAIL
| Город | N5 км дорог: полная геометрия / внутри квадрата | N6 |
|---|---|---|
| Шымкент | 125,54 (оракул 125,66) / **108,59** — за краем 17,07 км (13,6 %) | WARN |
| Астана | 156,18 (оракул 156,48) / **140,71** — за краем 15,77 км (10,1 %) | WARN |

- **N5 WARN.** `road_km_full_geometry` в UI сейчас не показывается, имя поля честное. Это скрытый риск: при выводе
  суммы с подписью «в квадрате» она завышена на 10–14 %. Тест 3b ловит такую подпись.
- **N6 WARN.** В карточке дороги длина подписана «геодезическая, K10», но K10 считает по сфере (гаверсинус).
  Отклонение от WGS84 — медиана −0,08 % / −0,20 %, в пределах допуска. Точнее подписать «по сфере (K10)». Число верно.
- Количества (N1–N3) и расстояния по прямой (N7) подписаны корректно: «записей в срезе», «не реестр города»,
  «Расстояние по прямой — нижняя граница пешего пути, не время в пути»; минут нет; мощность и население `null`.

### Отрисованная страница baseline — 12 PASS
| Город | Сводка среза (показано = пересчитано) | Самая длинная дорога за краем: показано / внутри квадрата | Расстояние от точки |
|---|---|---|---|
| Шымкент | 55 записей, 1 084 сегмента, 136 за краем | «2,83 км (вся линия, выходит за квадрат)» / **308 м** внутри (89 % вне) | 8 строк, «По прямой», отклонение от WGS84 в пределах округления |
| Астана | 65 записей, 1 326 сегментов, 143 за краем | «1,42 км (вся линия…)» / **528 м** внутри (63 % вне) | 8 строк, то же |

- Карточка дороги честно помечает «вся линия, выходит за квадрат», но длину внутри квадрата не показывает:
  у отдельной линии разница бывает в 9 раз. Предложение (не реализовано): добавить строку «внутри квадрата ≈ N м».
- В видимом тексте нет минут пешком и нет утверждений «в городе»; количества — «записей среза».
- Проверка мутантом: удалить пометку «вся линия…» и заменить «в срезе» на «в городе» → R1 и R2 FAIL в обоих городах.

Предупреждения (WARN) — это не исправления и не дефекты новой версии; новая версия не проверялась.
