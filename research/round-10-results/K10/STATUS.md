## Ограничения

- **Нет ни одной официальной сверки.** known_public — вывод K10 по двум признакам: геометрия школы в OSM и номерное название общеобразовательной школы. Закрепление территорий, правила приёма, вместимость, собственность по реестру — `not_fetched`.
- Точка школы — центр участка или здания, не вход. Расстояния справочного расчёта — по прямой.
- Точки анализа взяты только из классифицированных жилых зданий OSM. В двух ячейках на северо-востоке таких нет. Большинство зданий в bbox (2 089 из 2 455 по центру контура) без класса.
- Гипотезы A и C попадают на контур существующего здания (QA `on_existing_building_footprint`): это точки сравнения, не места строительства.
- Множитель 1,5 для буфера — допущение. Overture `2026-09-23.1` со временем удаляется из бакета; повторяемость обеспечивают закреплённые `inputs/`.
- Сырые выгрузки (6–22 МБ) не в Git — только их sha256 и provenance.
