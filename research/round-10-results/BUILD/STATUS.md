## Этап 1 — сквозной путь «Доступность школ» (сделан)

Что работает на основной странице (одна MapLibre-карта, без iframe и второго canvas):

- «Городское планирование» теперь сразу открывает **Доступность школ**: верхняя полоса (город, вопрос, 3 показателя с изменением к «Сейчас»), нижняя полоса действий (Место A, Место B, Подобрать лучшее, Сравнить; Сейчас / A / B / Разница), одна контекстная карточка справа (на 390 px — нижний лист), легенда формами.
- Прежний план v2 / Парето / устойчивость сохранены как «Расширенный режим» (кнопка в полосе; возврат «← Доступность школ»). Учебная модель (52,56) не затронута; возврат к симулятору скрывает все новые слои.
- Расчёт: `web/govtech/school/case.js` (school-access-case-v1): кейс из закреплённого среза Overture, матрица по прямой (haversine, мм), `compareCase`, факты, `case_digest` (канонизация `sac-canon-v1`, порядок записей не влияет), экспорт/импорт с проверкой digest и снимка.
- Карта: линии «точка → ближайшая школа» — настоящий слой MapLibre (`sc-links-*`), данные слоя пересобираются при Сейчас/A/B; школы — слой `sc-schools-*`; точки сетки (квадраты) и места-гипотезы (пунктирные ромбы) — SVG поверх той же карты, кликабельны. «Разница» окрашивает точки: ближе / без изменений / неизвестно.
- Выбор школы показывает её связи и происхождение (категория, уверенность, QA, допуск и вместимость = неизвестно, источник = вторичный); её можно исключить/включить — все цифры пересчитываются, digest меняется.
- Точки анализа — равномерная сетка 5×5 в рамке среза (derived, равные веса), подписаны «не жители». Места A/B — синтетическая сетка 3×4 или своё место щелчком внутри рамки (hypothesis), стоимость = нет данных, участок = не проверен. Бюджета нет.
- Вывод сравнения собирается кодом из чисел: правило lexicographic [неизвестные, сумма, максимум]; если по другим показателям выигрывает другой вариант — это сказано. Помечено «по шаблону, не AI».
- Состояние кейса (A/B, свои места, порог, ручные включения) переживает F5 (localStorage, восстановление сверяется со snapshot). Между городами ничего не переносится.

Правило школ по умолчанию `overture-school-category-v1`: категории elementary/middle/high_school без QA CATEGORY_DOUBT. Шымкент: 5 из 15 записей, Астана: 3 из 8 (например, «Гимназия №6» в Overture — place_of_learning, по умолчанию не в расчёте, включается вручную). Это правило данных, не проверка на месте.
