2. ЧТО СДЕЛАТЬ В КАБИНЕТЕ (приёмка руками, 5 минут)
   a) «+ Новый объект». Порядок формы: 1. Что это -> 2. Место -> 3. Сроки -> 4. Ответственный и стоимость
      -> 5. Источники. Внизу всегда «Создать черновик» и «Как увидят жители».
   b) Ошибка: впишите стоимость, не выбрав «Что это за сумма» и источник -> «Создать черновик».
      Ошибка у поля, ссылки на поля в сообщении, текст на месте, на сервер ничего не ушло.
      Очистите стоимость -> сообщение сменится на «Отмеченные ошибки исправлены — можно сохранять».
   c) Место: «Место известно приблизительно» -> «Точка» -> щёлкнуть по карте -> галочка «Расположение проверено».
      Линия: щелчки вдоль улицы -> «Готово» (Enter). Площадь: углы двора -> «Готово», контур замкнётся сам.
      Esc или «Отмена» — выйти без изменений; Backspace — убрать последнюю точку. Точка вне Астаны, линия
      короче 5 м, площадь на одной прямой или «восьмёркой» не принимаются — объяснение под инструментом.
      Нарисованная линия НЕ привязывается к улицам и маршрутам симулятора.
      «Место неизвестно» — запись будет только в списке; нарисованное останется в форме, но не уйдёт на сервер.
   d) Сроки: пустая дата = «неизвестно» (сегодняшняя не подставляется); недописанная дата — ошибка.
      Под актуальным сроком: «Жители увидят: …».
   e) «Создать черновик» (двойной щелчок тоже создаёт одну запись) -> «Как увидят жители» -> «Опубликовать…»
      -> причина (кнопка-подсказка или свой текст) -> «Подтвердить публикацию». Публикация — только этим действием.
   f) Перенос срока опубликованной записи: «Плановое окончание — актуальное» -> новая дата. Под полем:
      «первоначально обещали …, перенос на N дн.» и «сохранено X -> станет Y». Без причины не сохранится.
      «Перенос срока:» без продолжения причиной не считается. Затем «Опубликовать изменения…».
   g) «История изменений»: кто, когда, причина и «было -> стало» для сроков/статуса/суммы/точности места.
   h) Обрыв связи/сбой сервера: сообщение и «Повторить», форма не очищается. Истёкшая сессия: вход прямо в
      форме. Конфликт версий: выбрать «Перенести мои правки…» или «Отказаться…» (спросит подтверждение).
   i) Перезагрузка вкладки (F5) с незаполненной формой: в списке «локальная копия, не на сервере» ->
      «Вернуться к правке» -> «Восстановить правки». Копия живёт только в этой вкладке (sessionStorage), без пароля,
      токенов и CSRF; удаляется после сохранения, «Удалить из памяти», выхода или закрытия вкладки.

3. В ОБЛАКЕ / LINUX (так проверялось здесь)
   Временная база ВНЕ репозитория (рабочую БД не трогаем):
     export CIVIC_DB_PATH="$(mktemp -d)/civic.sqlite3"
     python3 -B -m ui.civic_store init
     python3 -B -m ui.civic_store seed-demo --package data/civic/astana/demo_synthetic.json
     python3 -B -m ui.civic_store create-editor staff1            # пароль спросят; без TTY: --password-stdin
     python3 -B app.py --host 127.0.0.1 --port 8611
   Открыть http://127.0.0.1:8611/ . Подложка OpenFreeMap в этой среде закрыта прокси — карта на простом фоне,
   отметки и щелчки работают.
