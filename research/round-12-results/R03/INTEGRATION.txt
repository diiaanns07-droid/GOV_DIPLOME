3. API R02 — изменений не требуется
   Список теперь запрашивается как GET /objects?limit=100, затем ?cursor=..&limit=100 (R02: limit 1–100,
   по умолчанию 50). Раньше при 50 записях на страницу и предохранителе в 20 страниц список молча обрезался на
   1000 записях; теперь предел 2000, и при достижении предела это показывается. Если сервер отвечает 400/422 на
   параметр limit, первая страница повторяется без него. Только GET, никогда /staff.

4. ДАННЫЕ И ЧЕСТНОСТЬ (что модуль ожидает от DTO, не меняя его)
   Стоимость показывается, только если budget.source_id указывает на источник записи или источник покрывает
   поле budget.amount_kzt; ответственный — только если источник покрывает responsible (или его подполе).
   Иначе — обычный текст «не подтверждено источником», без суммы. У демонстрационных записей тенге не
   показывается никогда. Даты: «Изначально — до» / «Сейчас — до» / «Фактически»; новый срок, которого нет в
   записи, не придумывается («новый срок не опубликован»).
   Желательно (не обязательно, текущий DTO не ломается): если R02/R05 начнут отдавать для источника поле
   fields с путями вида "responsible.organization", "budget.amount_kzt", "schedule.current_planned_end",
   карточка автоматически покажет эти сведения как подтверждённые. Других новых полей не требуется.
