R03 · round 12 · Публичная карта, полезные карточки и понятные фильтры — как запустить и проверить

Ветка claude/zen-mendel-e79iiv, база 56538a3a (codex/govtech-main-interface). Все команды — из корня репозитория.
Нужны: python3 (stdlib), Node 22, Playwright 1.56 с Chromium (берётся из локального node_modules или из `npm root -g`).
Без Playwright браузерные тесты пропускаются и считаются NOT_RUN, не PASS.

1. ПРОВЕРКИ R03

   node --test tests/civic/R03/core.test.mjs
       Чистая логика civic-v1: даты, перенос срока, стоимость/ответственный только с источником, строка
       «Откуда сведения», фильтры и счётчики, период, видимая область.

   node --test --test-concurrency=1 tests/civic/R03/browser.test.mjs
       Стенд с mock API в Chromium: список, карточка, фильтры, пустая улица, перекрывающиеся объекты,
       «Скопировать ссылку», клавиатура/Escape/фокус, 320/390/1440, 500 и 2000 синтетических объектов
       (генерируются внутри теста, в реестр не попадают), mount/destroy два раза подряд, onData/onSelect.
       Скриншоты стенда — только если задать R03_SHOTS=research/round-12-results/R03/screenshots.

   node --test --test-concurrency=1 tests/civic/R03/r02_readonly.test.mjs
       Тот же модуль поверх настоящего CivicService R02 (извлекается из коммита 6a28de2 через git archive во
       временную папку): только опубликованные записи, история переноса с причиной, без тенге у демо, только GET.

   Проверка R01 на всём приложении (общий P0-сценарий R01, ничего не пишет в репозиторий):
   NODE_PATH=$(npm root -g) node tests/civic/R01/browser/p0_flow.cjs /tmp/r03-p0
       Результат этой ветки и чистой базы 56538a3: research/round-12-results/R03/runs/ (одинаковые 2 FAIL — в
       файлах R01, см. INTEGRATION.txt, п. 6).

2. СТЕНД R03 (руками, без бэкенда)

   node tests/civic/R03/serve.mjs 8765
   открыть http://127.0.0.1:8765/tests/civic/R03/stand/
   Параметры адреса: ?today=2026-10-06 (часы для сроков), ?persist=0 (не помнить фильтры), ?maxpage=5 (размер
   страницы mock API), ?api=real (только вместе с r02_readonly_server.py). Данные стенда —
   tests/civic/R03/fixtures/*.json: тестовые записи (в т.ч. «с источником» для проверки показа стоимости и
   ответственного), не сведения о реальных работах; в рабочий реестр они не попадают.

3. НАСТОЯЩЕЕ ПРИЛОЖЕНИЕ (как его видит житель)

   DB=$(mktemp -d)/civic.sqlite3
   CIVIC_DB_PATH=$DB python3 -B -m ui.civic_store --db "$DB" init
   CIVIC_DB_PATH=$DB python3 -B -m ui.civic_store --db "$DB" seed-demo --package data/civic/astana/demo_synthetic.json
   CIVIC_DB_PATH=$DB python3 -B app.py --host 127.0.0.1 --port 8000
   открыть http://127.0.0.1:8000/  (режим «Город»)
   Подложка OpenFreeMap в этой среде заблокирована (403 прокси), поэтому карта открывается на офлайн-подложке
   R01 — это не ошибка модуля. Реальных опубликованных записей в базе нет: все 7 — демонстрационные (R05).

4. ЧТО МОЖЕТ СДЕЛАТЬ ЖИТЕЛЬ

   - Открыть «Город» и сразу увидеть: сколько записей, что все они демонстрационные, и не менее трёх карточек
     без прокрутки (фильтры свёрнуты, активные видны «плашками» с крестиком).
   - Открыть карточку и в первых строках прочитать: «Сейчас» (статус и откуда он), «Когда закончат» (срок,
     «перенесён на N дней» или «новый срок не опубликован»), «Кто отвечает» (только если это подтверждено
     источником), «Откуда сведения». Ниже — причина переноса, сроки «изначально / сейчас / фактически»,
     стоимость (только с источником), источники и свёрнутые «Подробнее о сведениях».
   - Найти улицу (поиск R01). Если записей рядом нет, видно «В видимой части карты нет опубликованных записей.
     Это не значит, что здесь не ведутся работы: реестр неполный.» и кнопку «Показать записи по всему городу».
   - Отфильтровать по видимой части карты, виду работ, периоду, статусу, наличию источника, скрыть планы с
     прошедшим сроком; числа в списке и в вариантах фильтров считаются по тем же правилам.
   - Нажать на место, где лежат несколько объектов: появится «Здесь N объектов рядом» со списком; выбрать нужный,
     вернуться («Отмена» или Escape), «Приблизить все».
   - Вернуться из карточки в список на то же место прокрутки; скопировать ссылку на объект (если буфер обмена
     недоступен — ссылка показывается в поле для ручного копирования).
   - Всё это — с клавиатуры и на экране 320 px; кнопка «Задать вопрос по объекту» ведёт в форму R06.
