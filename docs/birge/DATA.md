# Birge · данные

> Документ R14 (раунд 14), 10 октября 2026, обновлён ночью 10→11.10 (появились llm_v1 и погода Open-Meteo). Все наборы данных проекта: источник, дата, лицензия, размер,
> **что реальное, что синтетическое**, кто использует. Числа — из `SOURCE.json`/`manifest*.json` наборов (ссылки в таблицах),
> часть пересчитана агентами R14 по файлам (помечено «подсчёт R14»).
>
> Обозначения: **real** — реальные открытые данные; **derived** — вычислено из real (тот же источник и лицензия);
> **synthetic** — создано программой или агентом, не наблюдение; **demo** — учебные данные ТЗ хакатона.
> Правило проекта: synthetic никогда не переименовывается в real; записи жалоб с `demo: true` в интерфейсе подписаны «Пример» / «Үлгі».

## 6. Тексты людей (Google-форма, LOCAL-6) — real, не в Git

- Форма «Помогите сделать город удобнее · Қаланы ыңғайлы етуге көмектесіңіз»: текст жалобы, язык, район (необязательно), **обязательный флажок согласия** на анонимное использование для исследования и обучения ИИ. Участники — знакомые владельца (удобная выборка, не репрезентативная).
- Цель — 200–400 текстов к 13 октября; порог для оценки модели v2 — 200 размеченных текстов.
- Обработка: CSV → `private/` → `python -m ml.labeling.import_form` (согласие → обезличивание регулярными выражениями: ссылки, email, ИИН, номера, телефоны, госномера, адреса, имена по явным шаблонам → дедупликация → язык → от времени остаётся дата → id `f-<sha1>`) → `private/*.jsonl` → разметка в `web/labeling/` → `private/labels_*.jsonl`.
- **В Git попадают только числа** (метрики, счётчики). Тесты R03 проверяют, что тексты людей не попадают в `results/`.
- Ограничение: обезличивание на регулярных выражениях может пропустить имена и адреса без номеров — сырые тексты не публиковать.
