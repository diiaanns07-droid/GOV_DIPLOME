## Правила для того, кто продолжает

1. Каждое число — из `research/round-14-results/R14/FACTS.md` (там указан файл, ветка и SHA источника). Нового числа нет в FACTS — сначала добавить его туда с источником.
2. Синтетику называть синтетикой; NOT_RUN / NOT_EVALUATED не превращать в результаты.
3. Большие куски кода в текст не вставлять — описывать решения; при необходимости — приложение со ссылкой на файл.
4. Шаблон промпта для ChatGPT/Codex — `docs/birge/CONTINUE_WITH_GPT.md` §3.7 (глава) и §3.8 (источники).
