# tests/e2e — приёмка Birge (R10, раунд 14)

| Файл | Что делает |
|---|---|
| `run_acceptance.cjs` | **всё одной командой** для сборки R01 (B1/B2/FINAL): сервер с временной базой → точность карты → сценарий демо → UX по экранам → `SUMMARY.md` |
| `demo_flow.cjs` | 6 шагов CONTRACT §0 двумя слоями: **API** v2 (какой модуль не подключён) и **UI** в Chromium, 1366×768 и 375×812, ҚАЗ и РУС |
| `ux_screens.cjs` | UX-чек-лист UX_BRIEF по списку экранов (`screens_build.json` для сборки; для стендов ролей — свой JSON) |
| `ux_lib.cjs` | общие правила экрана: прокрутка вбок, ключи перевода, технические слова, шрифт < 14 px, зоны нажатия < 40 px (значки на карте ≥ 24 px), русские строки в ҚАЗ, Tab до главной кнопки (≤ 40 или через «Перейти к главной кнопке») |
| `screens_build.json` | экраны сборки: главная карта, «Картина дня» (`#day`), страницы модулей (если сервер их отдаёт; иначе NOT_RUN) |
| `map_baseline.cjs` | **эталон карты** (POLISH_WAVE_2 правило 7): вид по умолчанию житель/акимат × 1366/375 × ru/kk — кадр PNG, видимые слои, значки, кнопки по зонам, меню, камера; загрузка (медиана 3 окон), запросы, плавность, отклик интерфейса, карточка места, API |
| `compare_baseline.cjs` | новый прогон против эталона (`research/round-14-results/R10/baseline_8e67c65/`): «НЕ ХУЖЕ» / «ХУЖЕ», FAIL и СМОТРЕТЬ, кадры `diff-*.jpg`; `--control` — свежий 8e67c65 на той же машине для времени |
| `wave_checks.cjs` | **новые пункты POLISH_WAVE.md / POLISH_WAVE_2.md**, написаны до поставок: W1-3 срочные 104/112, W2-1 «исправлено → житель подтвердил → зелёный», W2-2 паспорт, W2-4 «Рядом», W2-6 QR, W2-7 идеи, P-12 меню ≤ 5. Нет кода роли в сборке — **ЖДЁТ** (не FAIL) |
| `r10_lib.cjs` | общие помощники трёх скриптов выше (сервер сборки, API, словари, поиск по видимым словам) |
| `fixtures/regress_inject.js` | отрицательный контроль сравнения: новый слой по умолчанию, свои значки, +1.5 с к тепловой карте → должно быть «ХУЖЕ» |

Элементы ищутся по видимым словам из словарей R11 (`web/civic/i18n/*.json`), а не по классам — тест не ломается от
вёрстки. Реальная точка сценария — остановка «Хан Шатыр» (`osm-node-4109037549`, Нура); тексты жалоб синтетические.

Что проверяет `demo_flow.cjs` (с 11 окт, ночь):
- **API** (CONTRACT §7): шлюз; `/targets`; `/classify` ru/kk/смесь и текст DEMO_SCRIPT → «Освещение»; `/similar` сразу
  после старта (B-032) и на чистой базе — есть ли похожие для «Я тоже» (B-030); жалоба §5; «Я тоже»; `/heat` и смысловой
  зум; `/akim/summary`; вход сотрудника; предложения и голос; статусы «в работу → исправлено».
- **UI** — как ведущий по DEMO_SCRIPT R01, только видимые элементы: шапка и ҚАЗ ↔ РУС (язык сохраняется после
  перезагрузки, ҚАЗ полный — на экране и во всей странице), шрифт / зоны нажатия / тех. слова; Tab → «Перейти к главной
  кнопке» → Enter; «Сообщить о проблеме» → нажатие по значку остановки → «Это здесь?» → текст «Аялдамада жарық жоқ…» →
  «Похоже на: Освещение» → «Отправить» / «Я тоже»; тепловая карта у акимата (цвет + число + легенда) и фильтры
  «Освещение / 30 дней → Сбросить»; «Горячие места» → три места по очереди — значок выбранного места виден и ничем
  не закрыт (B-040); «Картина дня»; вход «Для сотрудников» → «Что построить?» → «Сквер» → «Поставить» →
  житель «За» → «Удалить»; карточка остановки (значок места не закрыт) → «Взять в работу» → «Отметить исправленным» → Esc закрывает карточку → «Мои обращения»
  у жителя — статус «Исправлено» (по имени шкалы этапов).
- **«Нет связи» (шаг E)** — в отдельном окне браузера обрываются запросы `/heat`, `/complaints/mine`, `/akim/summary`:
  ждём понятное сообщение и «Повторить», после восстановления — данные.
- Тест меняет временную базу как ведущий (проект ставится и удаляется, жалобы у «Хан Шатыра» отмечаются исправленными).
  Сервер — с `CIVIC_DEMO=1`, как run-city.bat; `--no-demo` — без синтетического набора тепловой карты.
- `ux_lib.cjs` считает только то, что видит человек: элемент в окне и не закрыт другой панелью; ҚАЗ — отдельно «на экране»
  и «вся страница с прокруткой панелей»; надписи, частично закрытые другой панелью (B-039); короткие надписи (≤ 24 знаков),
  обрезанные многоточием (B-042); контраст текста ≥ 4.5:1, крупного ≥ 3:1 (UX_BRIEF правило 2, B-047).
- Малые телефоны: `run_acceptance.cjs ... --sizes 360x800,375x667` (те же проверки на других размерах).
- `demo_reset_check.cjs` — демо «как в первый раз» (B-048, B-049): после репетиции и перезапуска как run-city.bat и
  через две недели после первого запуска у «Хан Шатыра» есть похожие жалобы (иначе на шаге 2 нет «Я тоже»). Только API,
  своя временная база, ~1 мин; запускается и из run_acceptance.cjs (`--no-reset` — пропустить).
- `demo_flow.cjs --inject-css <файл>` — проверить предлагаемую правку CSS без изменения сборки (не приёмка).
- С 12 окт `demo_flow.cjs` пишет время каждого шага по вариантам (`timing` в RESULT.json, таблица в конце RESULT.md) —
  для сравнения «то же время» с эталоном 8e67c65.
- `run_acceptance.cjs` запускает и `wave_checks.cjs` (`--no-wave` — пропустить); с `--baseline <папка эталона>
  [--control <прогон 8e67c65 здесь же>]` — ещё `map_baseline.cjs` и `compare_baseline.cjs` (раздел 7 SUMMARY.md).

    # Python 3.11+ с pytest, Node 20+, Playwright с Chromium
