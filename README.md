# Birge «Бірге — вместе» · GOV_DIPLOME

Платформа обратной связи жителей и акимата Астаны: жалобы на карте и «Я тоже», тепловая карта «где болит сильнее»,
«Картина дня» для акима, проекты акимата в 3D с голосованием жителей, «Мой двор» и «Сделаем вместе», штаб ведомств и
кризисный штаб, ИИ-разбор пачки обращений. Интерфейс на казахском и русском (ҚАЗ · РУС). Дипломный проект.

В том же приложении остался исходный хакатонный симулятор **«Аким на 5 часов»** (адрес `#training`): его описание,
скриншоты и чек-лист жюри — [README_akim5h.md](README_akim5h.md).

## Что в main

- **Код** — итоговая сборка раунда 15 **FINAL-6** (`63bb6e6d`, тестировщик R10: «можно показывать: ДА») и правки после неё.

    на карте: видны с 12-го масштаба на плоской и наклонённой карте, без кнопок и слоёв (поправка П1 их убирала;
    `web/civic/build3d/build3d-landmarks.js`);
  - макеты проектов — павильон остановки, фонари, сквер, площадки — стоят на карте и без слоя «Проекты» (объёмный вид,
    с 15-го масштаба); щелчок по макету включает слой и открывает карточку проекта;
  - кризисный штаб: кнопки «Показать на карте / Хроника / Закрыть с итогом» сразу под заголовком (на 1024 px «Закрыть
    с итогом» уходила за край листа — R17);
  - модерация: казахский текст латиницей со словом «joba» («жоба» — проект: jobasy, jobany, jobalar) больше не считается
    грубым и не прячется звёздочками;
  - `run-city.bat` при первом запуске предлагает создать сотрудника `operator` (вход «Для сотрудников»), пока в базе
    нет ни одного;
  - данные, которые не дошли до сборок: корпус `ml/datasets/llm_v1/` (3 979 текстов gpt-4.1-mini) и `DATASHEET.md`,

- **Отчёты всех ролей раундов 14 и 15** — `research/round-14-results/`, `research/round-15-results/`,

Ветки ролей на GitHub остаются как история. Всё, что в них было по раундам 14–15, есть в `main`; отдельный прототип

## Запуск на Windows

Нужно: **Python 3.11–3.14** (при установке с python.org — галочка «Add python.exe to PATH»), **Git**, Chrome или Edge.
Интернет — для первой установки пакетов и для подложки карты (без него карта рисуется упрощённым фоном).

Новый компьютер:

```bat
git clone https://github.com/diiaanns07-droid/GOV_DIPLOME.git
cd GOV_DIPLOME
run-city.bat
```

Папка с проектом уже есть (например, `C:\Users\LEGION\Desktop\hackalem\hack-d3b2c613-stupits`):

```bat
git fetch origin
git switch main
git pull
run-city.bat
```

`run-city.bat` сам создаёт `.venv` и ставит зависимости (первый раз — несколько минут), загружает синтетический демо-мир
Астаны в `.runtime\round11-local.sqlite3` и открывает **http://127.0.0.1:8611/**. Для проектора —
**http://127.0.0.1:8611/?show=1**. Остановить — `Ctrl+C`. В консоли должно быть:

```
civic-world: R09 743, R06 55, R16 42, R17 3, R13 24, R12 39 (новых 0), R07 6
civic-v2: ready R01, R03, R04, R06, R07, R08, R09, R12, R13, R16, R17
Birge: http://127.0.0.1:8611
```

Вход сотрудника акимата: аватар справа вверху → «Для сотрудников» → `operator` и пароль, заданный при первом запуске
(создать вручную: `.venv\Scripts\python -m ui.civic_store --db .runtime\round11-local.sqlite3 create-editor operator`).
Ключ OpenAI для Birge не нужен.

Linux / macOS: `CIVIC_DEMO=1 PORT=8611 CIVIC_DB_PATH=.runtime/round11-local.sqlite3 bash run.sh`.

Подробно (частые ошибки, модели, архив карты без интернета) — [docs/birge/RUNBOOK.md](docs/birge/RUNBOOK.md).

## Проверки

```bat
.venv\Scripts\python -m pytest -q          :: весь Python (больше 5 200 тестов, ~10 минут)
.venv\Scripts\python check.py              :: эталоны хакатонного движка «Аким на 5 часов»
```

Полный набор сборки (pytest, HTTP, Node и браузерные проверки; нужны Node.js 20+ и Playwright) —
`bash tests/civic/R01/run_checks.sh <папка>`; приёмка R10 — `bash tests/e2e/acceptance_r15.sh`.

## Где что лежит

| Путь | Что |
|---|---|
| `app.py`, `ui/web_server.py` | сервер: страница, API v1/v2 (`/api/civic/v2/*`), модули ролей |
| `ui/civic_*` | модули сервера: база и вход сотрудника (`civic_store`), жалобы (`civic_feedback`), тепловая карта (`civic_heat`), «Картина дня» (`civic_akim`), ведомства и кризис (`civic_agencies`), двор и инициативы (`civic_together`), встречи и вопросы (`civic_meetings`, `civic_qa`), ИИ-разбор и модерация (`civic_ml_api`), прогноз (`civic_forecast`) |
| `web/`, `web/civic/` | интерфейс: оболочка Birge, карта, экраны разделов, ui-kit и словари ҚАЗ / РУС (`web/civic/i18n/`) |
| `engine/` | движок «Аким на 5 часов», геоданные и привязка к объектам (`civic_geo`), сценарии (`civic_scenarios`) |
| `agent/` | советник хакатона и «Спросить Birge» (`civic_assistant`) |
| `ml/` | классификатор обращений, поиск повторов, прогноз; датасеты и разметка |
| `data/` | данные Астаны: районы, объекты OSM, демо-мир, ориентиры |
| `docs/birge/` | архитектура, модули, данные, запуск; `docs/diploma/` — текст диплома; `docs/gton/` — презентация Gton |
| `research/` | пакеты раундов 3–15, результаты и статусы ролей ([research/README.md](research/README.md)) |
| `tests/` | тесты движка, модулей ролей (`tests/civic/<роль>/`) и сквозные (`tests/e2e/`) |

Данные OpenStreetMap — © участники OpenStreetMap, ODbL 1.0. Синтетические данные в интерфейсе помечены «Пример».
