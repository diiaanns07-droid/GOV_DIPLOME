# Городское планирование в основном интерфейсе

Запуск — корневой `run.bat` или `.venv/Scripts/python.exe -B app.py --host 127.0.0.1 --port 8501`.
Открыть `http://127.0.0.1:8501/`, нажать **Городское планирование** в верхней панели.

Сохранены светлый интерфейс, одна MapLibre-карта, здания в 3D и исходный учебный симулятор.
Планирование переключается между Шымкентом и Астаной; данные — по одному участку примерно 2×2 км.
Это отдельная модель: никакие новые расстояния и условные бюджеты не подставляются в учебный Astana Score.

## Что проверить

1. **План → Демо-набор → Найти точные оптимумы → Применить**. На общей карте видны контрольные точки, кандидатные места и линии до ближайших записей/выбранных объектов.
2. **Устойчивость → Добавить случай**. Отметить хотя бы одну запись, затем **Сравнить три плана**. Исключение условное, не сообщение о закрытии учреждения.
3. **Данные**: исходные записи, источники, QA. Клик по исходной точке карты открывает её сведения.
4. JSON/HTML доступны в соответствующей вкладке. Пример файла устойчивости: `tests/govtech/examples/astana-synthetic-resilience.json` (явно синтетические точки, кандидаты и стоимости).
5. **Вернуться к симулятору**: учебные проекты и результаты сохранены; слои среза скрываются, камера возвращается.

На карте: кнопка **3D** приближает участок до масштаба объёмных зданий, **Весь участок** возвращает охват среза.
В режиме постановки Enter на карте ставит точку в центре участка; Escape прекращает постановку. Мышью можно выбрать любое место внутри рамки.

## Устройство

- `shell.js` — адаптер существующей MapLibre-карты к интерфейсам планировщика, управление режимами и городами.
- `shell.css` — оформление через цвета и компоненты исходного сайта, desktop и мобильная панель.
- `core/` — закреплённые данные и модули BUILD `d18847f9e7c18fcfae3349c0b223b023d359a838`; происхождение и хэши в `SOURCE_MANIFEST.json`.
- Математика `plan.js`, `resilience.js`, `whatif.js`, `facts.js` и данные перенесены побайтно. Две адаптации UI описаны в манифесте.
- `ui/web_server.py` раздаёт только явно перечисленные новые файлы, без общего доступа к каталогу проекта.
- Второй сайт, iframe и порт 8765 для этого режима не нужны.

## Проверки

```text
.venv/Scripts/python.exe -m pytest -q -p no:cacheprovider
.venv/Scripts/python.exe -B -m ui.web_check
node tests/govtech/plan.cjs
node tests/govtech/resilience.cjs
node tests/govtech/whatif.cjs
```

Node-проверки используют независимые ожидаемые значения из BUILD. В них изменён только путь к модулям.
Основной UI проверяется через браузер: оба города, применение плана, устойчивость, импорт/отказ, возврат, ширина 390 и 1440 пикселей.

Карта-подложка и объёмные здания требуют доступа к OpenFreeMap. Расчёты и сохранённые срезы работают локально без LLM/API-ключа.
При недоступной карте можно использовать демо-наборы и импорт JSON. Новые объяснения — проверяемые шаблоны, не ответы LLM.
Обычный план допускает 16 кандидатов, устойчивость — 12 кандидатов и до 7 пользовательских случаев. Расстояния по прямой, стоимости условные.
