# Уточнения ↔ категории: найдёт ли житель нужный чип (R03)

Чипы уточнений показываются после категории (POLISH_WAVE п. 2), модель предсказывает только категорию. Если текст про уточнение модель отнесёт к другой категории, нужного чипа житель не увидит.
