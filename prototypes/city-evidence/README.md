# Городские данные: Шымкент / Астана (демо BUILD, раунд 5)

Демо открытых вторичных данных (Overture Maps 2026-09-23.1) для **двух квадратов ~2×2 км** — по одному в Шымкенте и Астане. Это не целые города, не официальный реестр, не учебная модель STUPITS. Пешеходная проходимость не утверждается. Объяснение — шаблон, а не ответ LLM. Основной сайт (корневые `web/`, `agent/`, `engine/`, `data/`, `run.bat`) не меняется.

## Запуск (Python 3, только стандартная библиотека, без сети и ключей)

Linux / macOS:
```bash
cd prototypes/city-evidence
python3 serve.py            # → http://127.0.0.1:8765/   (python3 serve.py 8765 --open — открыть браузер)
```
Windows: двойной щелчок по `prototypes\city-evidence\run-demo.bat` или в консоли:
```bat
cd prototypes\city-evidence
py -3 serve.py 8765 --open
```
Можно и просто открыть `web/index.html` в браузере (file://).
**Проверено только на Linux.** `run-demo.bat` и команды Windows автором не запускались.

## Что на экране
- Шымкент / Астана: при смене города сбрасываются выбор, точка, подсказка и ожидающее объяснение.
- Слои объектов и дорог, фильтр 7 категорий, раскраска дорог по данным о проходе пешком. Расстояния — только по прямой.
- **QA-метки:** группа записей с одинаковыми координатами (в Шымкенте 10 записей в точке 69.5958, 42.3167) обведена на карте. В карточке объекта — список остальных записей этой точки, кандидаты в дубликаты и сомнение в категории с правилом и причиной. Записи не удаляются.
- Район по правилу K03 v2. Неоднозначный район не присваивается, показываются кандидаты.
- Каталог фактов и «Объяснить срез». «0 записей» означает ноль в полном ответе запроса по квадрату; «нет данных» — значение неизвестно, причина указана.
- Источники: атрибуция по `sources[]` записей (K08), ссылки на `web/attribution/ATTRIBUTION.md` и тексты лицензий.
- Клавиатура: Escape сбрасывает выбор; на карте в фокусе стрелки сдвигают её, «+»/«−» меняют масштаб, в режиме точки Enter ставит точку.

## Проверка
```bash
cd prototypes/city-evidence
python3 tools/check_all.py [--log check.json]     # входы, пакет K10, контракт, сборка, каталог фактов, unit-тесты
NODE_PATH="$(npm root -g)" node tests/smoke.cjs   # браузер (Playwright + Chromium), отдельно
```
`check_all` без shapely/pyproj помечает пересборку `evidence.js` как SKIP, а не как PASS. Полная проверка: `pip install -r requirements-build.txt`. Без сети после установки зависимостей.

## Ограничения
- Квадраты выбраны по максимуму объектов: это не репрезентативная выборка и не сравнение городов.
- Районы — OSM/Overture, юридически не проверены. Совпадающие координаты делают район записи ненадёжным.
- Права прохода у большинства сегментов неизвестны, маршрутного режима нет. Длины — геометрические длины сегментов K10.
- Казахские подписи — черновик. Грамматика единиц шаблонная («1 записей»).
- K08 F5: в Астане 26 источников ссылаются на `routes`, колонка не извлечена; восстановить из пакета нельзя.
