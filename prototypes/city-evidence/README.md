# Городские данные: Шымкент / Астана (демо BUILD, раунд 4)

Демо-просмотрщик открытых вторичных данных (Overture Maps 2026-09-23.1) для двух небольших квадратов ~2×2 км — по одному в Шымкенте и Астане. Не целые города, не официальный реестр, не учебная модель STUPITS. Основной сайт (`web/`, `agent/`, `engine/`, `data/` в корне) не меняется.

## Запуск с чистого checkout

Нужен только Python 3 (стандартная библиотека). Сеть и API-ключ не нужны.

```bash
cd prototypes/city-evidence
python3 serve.py            # → http://127.0.0.1:8765/
# или просто открыть web/index.html в браузере (file:// тоже работает)
```

`web/data.js` уже собран и закоммичен. Пересборка из закреплённых входов (проверяет SHA256 по манифесту K10):

```bash
python3 tools/build_data.py
python3 inputs/k10/scripts/offline_check.py     # независимая проверка пакета K10: "ok": true
```

Повторное копирование входов из git-объектов (нужен `git fetch` веток из `source_manifest.json`): `python3 tools/copy_inputs.py` (из корня репозитория).

## Проверки

```bash
NODE_PATH=$(npm root -g) node tests/smoke.cjs   # Playwright + Chromium, file://; скриншоты → research/round-4-results/BUILD/smoke/
```

Проверено на Linux (контейнер Claude Code, Python 3.11, Node 22, Playwright 1.56 Chromium). Windows/macOS не проверялись.

## Что на экране

- переключатель города; при смене сбрасываются выбранный объект, точка, подсказка и отложенные объяснения;
- слои «Объекты» и «Дороги», фильтр 7 категорий, раскраска дорог по данным о проходе пешком;
- карточка объекта (источник, лицензия, дата, confidence; «мощность — нет данных»), карточка дороги;
- таблица записей среза; расстояние от точки только **по прямой** с подписью;
- раскрываемая карточка источников с версиями и SHA256.

## Ограничения

- Число строк = число записей Overture в квадрате, не число объектов города, не мощность и не обеспеченность.
- У большинства сегментов права прохода пешком неизвестны: время пешком, изохроны и «недостижимо» не показываются.
- Районная привязка в этапе 1 не выполняется (колонка «Район» — «не определён»).
