# data/civic/astana/landmarks — ориентиры Астаны для 3D-вида (R05, раунд 15)

`landmarks.json` — пять ориентиров, которые модуль 3D (`web/civic/build3d/`) показывает **условными моделями** при
наклоне карты (3D-вид) с 13-го масштаба: Байтерек, Хан Шатыр, Ақорда, «Нұр Әлем», Дворец мира и согласия.
Копия для браузера — `web/civic/build3d/data/landmarks.json` (файлы одинаковые, их пишет один инструмент).

## Откуда координаты

Только из данных OSM в репозитории. Контуров самих зданий в репозитории нет (выгрузка LOCAL-1 брала площадки,
остановки, парки, дворы), поэтому центр каждого здания выводится из снимка пешеходной сети
`data/civic/astana/osm-walking/overpass.json.gz` (OSM на 2026-05-06) — по дорожкам и проездам, которые обходят здание:

| Ориентир | Способ | Линии и узлы OSM | Проверка |
|---|---|---|---|
| Байтерек | центр круглой площади | way 258818019 (кольцо r = 42 м) | внешнее кольцо 258818051 — 0,6 м; входы 2389116250 / 2389116244 — 5,7 / 7,4 м |
| Хан Шатыр | центр эллипса кольцевого проезда | way 164938029 (43 точки) | вход в шатёр 13294095201 — 95 м от центра (≈ радиус основания) |
| «Нұр Әлем» | средний центр 5 колец ЭКСПО | ways 455013941/2/3, 1461824179/80 | разброс центров колец 1,1 м |
| Ақорда | центр пустого места между дорожками | ось — сады 329669144 и 329669208 | центр в 2 м от оси садов |
| Дворец мира и согласия | узел с именем здания | node 5009488810 | центр пустого квадрата дорожек — 4,6 м |

Подробности (радиусы, разброс, площади) — в поле `coords` каждой записи. Поворот Хан Шатыра — по большой оси
кольца (13,3°), Ақорды и пирамиды — по оси садов Ақорды (14,1°): это та же ось бульвара Нұржол.

**Пометка `check: "LOCAL-13"`** у каждой записи: это вывод по соседним линиям, а не контур здания. На ноутбуке Codex
выгружает контуры зданий через Overpass (задача LOCAL-13 в `research/round-15-results/R05/INTEGRATION.txt`) и сверяет
центр; расхождение больше 10 м — поправить запись и пересобрать.

## Модели — условные

Высоты (`height_m`) и размеры (`size_m`) округлены по открытым описаниям; форма упрощена (low-poly). Это **не точные
копии зданий** — так и написано в «?» легенды карты (`note.ru` / `note.kk`). `mask_m` — где модуль прячет объёмные
здания подложки, чтобы они не прорастали сквозь модель.
