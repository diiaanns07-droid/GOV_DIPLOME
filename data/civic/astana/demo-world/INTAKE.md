# Набор «обращения за ночь» — паспорт (R02, раунд 15+, поправка П3)

Синтетические обращения жителей, «пришедшие за ночь», для **«ИИ-разбора пачки»** R04 (сцена 0 демо) и **эталон** к
ним — для честной оценки разбора (FACTS R14, диплом). Всё синтетическое (`demo: true`). Настоящие только места из
OpenStreetMap (ODbL) через карту R12: дворы, остановки, улицы, перекрёстки и парк, которые уже есть в демо-мире.

## Как сделан

- **Тексты написаны вручную для этого набора** (`demo_intake_texts.py`) — не шаблоны synth_v3: на synth_v3 учится
  классификатор R04 (`ml/civic_classifier_v2/config.py` SYNTH_V3_DIR), с ними оценка была бы завышена. Тест
  проверяет, что ни один текст не совпадает с корпусом synth_v3 и с жалобами мира.
- Генератор выбирает язык (ru 44 % · kk 30 % · вперемешку 16 % · латиница 10 %), шаблон (в группе — сначала
  неиспользованные), блок / подъезд / дом, «с какого часа» (у каждого жителя своё: «с 23:40», «с вечера»,
  «часов с одиннадцати»), приветствие по времени суток и концовку. Опечатки (12 %) — пропуск, перестановка, удвоение
  буквы — **не трогают названия мест**. Латиница — как пишут с телефона без кириллицы («v zhk grand champion net
  otopleniya», «altyn shar jk-da su joq»).
- **Место названо в самом тексте** так, как оно подписано на карте R12 (поиск карты `web/civic/map/search_index.json`):
  «ЖК Grand Champion», «остановка «Думан»», «на улице Сыганак», «Қорғалжын тас жолы мен Тұран даңғылының қиылысында».
  Нарочно трудные случаи: «Бухар Жырау De Luxe» в русском тексте при «Бұқар Жырау De Luxe» на карте; латиница;
  перекрёсток подписью светофора («Коргалжинское ш. и пр. Туран»).
- **Сцены демо не задеты**: нет остановки «Хан Шатыр» (шаг 2), двора сцены 7, улицы сцены 8 и снега в Нуре
  (сцена 9) — «Создать задачи» не меняет числа этих сцен.
- Детерминированно: `python3 -m ml.datasets.demo_intake --check` пересобирает оба файла байт в байт — **на тех же
  входах** (`inputs`: objects.json R12 247c24a8, yards.json a3ef7329, поиск карты, граф, мир dd0e7bba; это сборки R01
  FINAL-5 и новее). На других данных карты `--check` отвечает кодом 2 с причиной, тесты целей — пропуск с причиной.

## Эталон — как размечен

Разметка **правилами генератора R02, без прогона моделей R04 и без подгонки под их ответы**:

- **категория и уточнение** — у вида проблемы (`categories_v2`);
- **службы** — таблица Birge `ui/civic_feedback/v2/lifecycle.SERVICE_RULES` (= умолчания R08), ведущая `lead`;
  **две службы** — пары CONTRACT §5.1, как в демо-мире: раскоп и порыв трубы — Водоканал + дорожники; плитка после
  теплотрассы — Теплосеть + дорожники; газон после теплотрассы — Теплосеть + озеленение; упавшая опора с проводами —
  Электросети + освещение. Открытый люк по таблице — «Полиция» (опасное место): акимат может поправить таблицу;
  если разбор назовёт другую службу — это расхождение с таблицей Birge, эталон его честно покажет;
- **место** — цель карты R12 (`kind`, `id`, подписи), `accept_ids` (у остановки — все её стороны из поиска карты;
  у перекрёстка — светофор и участки двух его улиц не дальше 60 м: светофоров в поиске карты нет), у улицы —
  `street_ru`: верен любой участок той же улицы; `none` / `district` — места нет, верно «адрес уточнить»;
- **повторы** — одна проблема у одного места = одна группа; тексты без места — каждый своя группа; одно место
  с разными проблемами — разные группы (в ЖК Grand Champion: отопление, свет в подъезде, лифт, ночная стройка);
- **срочность** — явные классы (`labeling_ru.urgent`): нет отопления, нет воды, газ, огонь, открытый люк, провода,
  прямая опасность для детей. «Опасные» слова без такого класса (светофор, разбитое стекло павильона) — не срочно;
  благодарность за отопление и вопрос о сроке ремонта — «Другое».

## Как оценивать (метрики П3)

```
python3 -m ml.datasets.demo_intake_eval ответ.json          # ответ analyze() на тексты набора
python3 -m ml.datasets.demo_intake_eval ответ.json --json   # одной строкой — для FACTS R14
```

- **службы** — доля текстов, у задачи которых ведущая служба = эталону; полный набор служб; «две службы» — полнота
  и точность;
- **повторы** — попарная F1 (пара текстов в одной задаче ↔ в одной группе эталона) и доля групп с повторами,
  собранных ровно в одну задачу; число задач против 115 групп;
- **места** — доля текстов с местом, у задачи которых цель верна; у 18 текстов без места верно «адрес уточнить»;
- **срочность** — полнота по текстам и по группам (группа поймана, если не меньше половины её текстов — в срочных
  задачах), точность по текстам;
- **время** — `summary.ms` ответа.

Попарная F1 зависит от больших групп (в группе из 40 текстов — 780 пар из 1453): рядом всегда давать долю групп,
собранных точно. Ответ «как в эталоне» даёт 1.0 по всем метрикам; «каждый текст — своя задача» — F1 0 (тест).

## Ограничения (честно)

- **Синтетика.** Тексты написал один автор по своим шаблонам — язык живых жителей разнообразнее; на настоящих
  обращениях числа будут ниже. В FACTS и дипломе — с пометкой «синтетический набор R02».
- Казахские тексты — авторские, без вычитки носителем (R11 — по желанию); латиница — упрощённая (без ә, ғ, қ …).
- Повторы в группе похожи друг на друга сильнее, чем в жизни (общий банк фраз), — склеивать их легче.
- Места — только с названием в OSM; во дворах без названия жители пишут по-другому («двор дома 12»), таких нет.
- Время приёма — прошлая ночь (`day_at`); при показе раньше 07:30 часть времени «в будущем» — сдвиньте `now` на
  сутки назад: `materialize(items, now - timedelta(days=1))`.
