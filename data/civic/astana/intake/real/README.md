# Реальные записи (r05-intake-v1)

Один JSON-файл на объект по шаблону `../../templates/intake_record.template.json`.
Каждое значение поля (срок, статус, бюджет, организация, геометрия из источника) — отдельный `claim`
с `source_id` из `../../sources.json`, причём источник должен иметь `access_status: fetched`.

На 2026-10-06 каталог пуст: в среде R05 раунда 11 все казахстанские официальные и новостные сайты
были закрыты политикой egress (см. `sources.json` → `network_audit`). Пустой каталог — не утверждение,
что работ в Астане нет.
